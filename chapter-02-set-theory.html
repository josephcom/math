Everything Is a Set

Logic gave us the rules of argument. Set theory gives us the objects to argue about — and there is only one kind of object.

From the empty set and nine axioms come pairs, numbers, functions, infinity, and every space in the rest of this book.

Layer 1 · One primitive

Sets & Membership

A single undefined relation, and the paradox that forced the axioms.

Concepts & Definitions

  • Set — an undefined primitive: a collection considered as one object.

    A shopping bag is one thing, even though it holds six things. Nobody defines "bag" — you just use it.

  • Membership \(x \in A\) — the one primitive relation; "\(x\) belongs to \(A\)".

    Milk \(\in\) the shopping bag. That's the only kind of fact set theory starts with.

  • Roster notation \(\{a, b, c\}\) — a set given by listing its members.

    \(\{\text{tea}, \text{coffee}\}\). Order and repeats don't count: \(\{a,b\} = \{b,a\} = \{a,a,b\}\).

  • Set-builder notation \(\{x \in A : P(x)\}\) — the members of \(A\) satisfying \(P\).

    \(\{n \in \mathbb{N} : n \text{ is even}\}\) — "the ones in this bag that pass the test".

  • Empty set \(\varnothing\) — the set with no members.

    An empty bag is still a bag. This one object is where the entire universe is built from.

  • Subset \(A \subseteq B\) — every member of \(A\) is a member of \(B\).

    The cutlery drawer is a subset of the kitchen's contents.

  • Proper subset \(A \subsetneq B\) — a subset that misses something.

    The forks are a proper subset of the cutlery: no fork is missing, but a spoon is.

  • Superset \(B \supseteq A\) — \(B\) contains \(A\); the same statement read backwards.

    The kitchen is a superset of the drawer. Same fact, other end of the telescope.

  • Equality of sets — \(A = B\) means they have exactly the same members.

    Two guest lists are the same list if the same people are on them, however differently written.

  • Singleton \(\{a\}\) — a set with exactly one member.

    The box and the thing in the box are different objects: \(a \ne \{a\}\). One is a mug, one is a mug in a bag.

  • Disjoint sets — sets sharing no member.

    Vegetarians and meat-eaters at the same dinner: no overlap.

  • Family (indexed collection) \(\{A_i\}_{i \in I}\) — a set of sets labelled by an index set.

    One shelf per year of a diary. The years are the index; the shelves are the sets.

  • Russell's paradox — \(R = \{x : x \notin x\}\) cannot exist.

    "The barber shaves exactly those who don't shave themselves." Who shaves the barber? Nobody can — so no such barber, and no such set.

  • Proper class — a collection too big to be a set, e.g. "all sets".

    You can talk about everything, but you can't put everything in a bag and then put that bag on the shelf.

Theorems

  • Russell's paradox is fatal to naive comprehension: "for every property, the set of things with that property exists" is inconsistent.

    This is why Layer 2 has axioms at all: you may only filter an existing set, never conjure one from a description.

    Assume unrestricted comprehension and form \(R = \{x : x \notin x\}\). Ask whether \(R \in R\). If \(R \in R\) then \(R\) satisfies the defining property, so \(R \notin R\). If \(R \notin R\) then \(R\) satisfies the property, so \(R \in R\). Both cases contradict, so the assumption fails. \(\blacksquare\)

  • The empty set is a subset of everything: \(\varnothing \subseteq A\) for every \(A\).

    "Every member of the empty bag is also in yours" — there are none to check, so it's true.

    \(\varnothing \subseteq A\) unfolds to \(\forall x\,(x \in \varnothing \to x \in A)\). The antecedent \(x \in \varnothing\) is false for every \(x\), so each implication is vacuously true (Chapter 1, Layer 3). \(\blacksquare\)

  • The empty set is unique.

    There is only one way to have nothing. Two empty bags hold the same (no) things, so as sets they are equal.

    Let \(\varnothing_1, \varnothing_2\) both have no members. By the previous result each is a subset of the other, so by Extensionality \(\varnothing_1 = \varnothing_2\). \(\blacksquare\)

  • Double inclusion: \(A = B\) if and only if \(A \subseteq B\) and \(B \subseteq A\).

    The workhorse of every set proof: show each side is inside the other, then declare them equal.

    If \(A = B\) then \(x \in A \leftrightarrow x \in B\), giving both inclusions. Conversely the two inclusions give \(x \in A \to x \in B\) and \(x \in B \to x \in A\), i.e. \(x \in A \leftrightarrow x \in B\) for all \(x\); Extensionality then yields \(A = B\). \(\blacksquare\)

  • Transitivity of inclusion: \(A \subseteq B\) and \(B \subseteq C\) imply \(A \subseteq C\).

    Forks \(\subseteq\) cutlery \(\subseteq\) kitchen, so forks \(\subseteq\) kitchen.

    Let \(x \in A\). Then \(x \in B\) by the first inclusion, and \(x \in C\) by the second. As \(x\) was arbitrary, \(A \subseteq C\). \(\blacksquare\)

  • No universal set: there is no set containing every set.

    "Everything" is a proper class, not a set — the bag containing all bags would be inside itself.

    Suppose \(U\) contained every set. By Separation (Layer 2) the set \(R = \{x \in U : x \notin x\}\) exists, and Russell's argument applies verbatim to give a contradiction. Hence no such \(U\) exists. \(\blacksquare\)

Methods

  • Element chasing — to prove a set statement, take an arbitrary element and follow it.

    "Let \(x \in A \cap B\)…" — everything about sets ultimately reduces to one wandering element.

  • Double inclusion — prove \(A \subseteq B\) and \(B \subseteq A\).

    Two short arguments beat one clever one; this is how nearly every identity in Layer 3 is proved.

  • Venn diagram — draw overlapping regions to see what is being claimed.

    Excellent for finding the truth, useless as a proof — three sets already need care, four can't be drawn with circles.

Layer 2 · The rulebook

The ZFC Axioms

Nine careful rules that say which sets you are allowed to build.

Axioms

  • Extensionality — two sets with the same members are equal.

    A set is nothing but its contents: no hidden colour, no label, no order.

  • Empty set — \(\varnothing\) exists. (Often derived from Infinity plus Separation.)

    The first brick. Everything else is built out of it, including every number.

  • Pairing — for any \(a, b\), the set \(\{a, b\}\) exists.

    Any two things can be put in a bag together. With \(a = b\) you also get singletons.

  • Union — for any set of sets, the set of all their members exists.

    Tip every bag in the cupboard onto the table: what's on the table is a set.

  • Power set — for any \(A\), the set \(\mathcal{P}(A)\) of all subsets of \(A\) exists.

    All possible guest lists you could draw from one club — including the empty list and everyone.

  • Separation (subset schema) — \(\{x \in A : P(x)\}\) exists for any property \(P\).

    Filtering is safe; conjuring is not. This is the exact repair for Russell's paradox.

  • Replacement (schema) — the image of a set under a definable function is a set.

    Swap every item in the bag for something else, one for one: still a bag, never bigger.

  • Infinity — an inductive set exists: it contains \(\varnothing\) and is closed under \(x \mapsto x \cup \{x\}\).

    The one axiom that says "the counting never stops" — without it, only finite sets exist.

  • Foundation (regularity) — every non-empty set has a member disjoint from it.

    No bag contains itself, and no endless chain \(\cdots \in x_2 \in x_1 \in x_0\). The universe is built in layers, from the bottom.

  • Choice (AC) — for any family of non-empty sets there is a function picking one member from each.

    Infinitely many pairs of socks with no way to tell left from right — you still need some rule to grab one from each pair. Layer 9 is devoted to it.

Theorems — What the Axioms Immediately Give

  • Singletons exist: \(\{a\} = \{a,a\}\).

    Pairing with the same thing twice — the cheapest possible use of an axiom.

    Pairing applied to \(a\) and \(a\) yields a set whose members are exactly \(a\); by Extensionality this set is \(\{a\}\). \(\blacksquare\)

  • Binary unions and intersections exist: \(A \cup B\) and \(A \cap B\) are sets.

    Everything in either bag; everything in both bags.

    Pairing gives \(\{A,B\}\), and Union applied to it gives \(A \cup B\). For the intersection, Separation carves \(\{x \in A : x \in B\}\) out of \(A\). \(\blacksquare\)

  • Intersection of a non-empty family is a set: \(\bigcap \mathcal{F}\) exists when \(\mathcal{F} \ne \varnothing\).

    What every bag in the cupboard has in common. If the cupboard is empty the answer would be "everything" — which is not a set, hence the proviso.

    Pick any \(A \in \mathcal{F}\) and apply Separation inside it: \(\bigcap\mathcal{F} = \{x \in A : \forall B \in \mathcal{F},\, x \in B\}\). Non-emptiness of \(\mathcal{F}\) is what supplies the container \(A\). \(\blacksquare\)

  • No set contains itself: \(A \notin A\).

    A bag can't be inside itself, however you fold it.

    Suppose \(A \in A\). Consider \(\{A\}\), which exists by Pairing. Its only member is \(A\), and \(A \cap \{A\} \ni A\) is non-empty, so \(\{A\}\) has no member disjoint from it — contradicting Foundation. \(\blacksquare\)

  • No membership cycles: there is no chain \(A \in B \in A\), nor any longer loop.

    You can't have box A inside box B inside box A. The stacking always bottoms out.

    Given a cycle \(A_1 \in A_2 \in \cdots \in A_n \in A_1\), form \(S = \{A_1,\dots,A_n\}\) by repeated Pairing and Union. Every \(A_i \in S\) contains some \(A_j \in S\), so no member of \(S\) is disjoint from \(S\) — contradicting Foundation. \(\blacksquare\)

  • Separation is a consequence of Replacement.

    Nine axioms, but not all independent — the list is chosen for clarity, not economy.

    Given \(A\) and a property \(P\), define the class function \(F\) sending \(x \mapsto x\) if \(P(x)\) holds and \(x \mapsto a_0\) (some fixed element satisfying \(P\), if one exists) otherwise; if no element of \(A\) satisfies \(P\) the desired set is \(\varnothing\). Replacement applied to \(F\) on \(A\) returns exactly \(\{x \in A : P(x)\}\). \(\blacksquare\)

Methods

  • Build, never conjure — every new set must come from an axiom applied to sets you already have.

    "Let \(S\) be the set of all…" is only legal if you can name the bag you filtered it out of.

  • Check the axiom used — when a construction feels too easy, name the axiom licensing it.

    Products, functions and sequences all trace back to Pairing, Union, Power set and Separation.

Layer 3 · Combining

Operations on Sets

The algebra of and, or, not — now applied to collections.

Concepts & Definitions

  • Union \(A \cup B = \{x : x \in A \lor x \in B\}\).

    Guests invited by either host — invited twice still means one seat.

  • Intersection \(A \cap B = \{x : x \in A \land x \in B\}\).

    People on both guest lists.

  • Difference \(A \setminus B = \{x \in A : x \notin B\}\).

    My list, minus anyone on yours.

  • Complement \(A^{c} = U \setminus A\), relative to a fixed universe \(U\).

    "Everyone not invited" — only meaningful once you've fixed who "everyone" is.

  • Symmetric difference \(A \triangle B = (A \setminus B) \cup (B \setminus A)\).

    The people exactly one of us invited — the exclusive-or of guest lists.

  • Power set \(\mathcal{P}(A)\) — the set of all subsets of \(A\).

    \(\mathcal{P}(\{a,b\}) = \{\varnothing, \{a\}, \{b\}, \{a,b\}\}\): 2 things, 4 subsets.

  • Arbitrary union \(\bigcup_{i \in I} A_i\) — everything in at least one \(A_i\).

    Every book in the building = the union of every shelf.

  • Arbitrary intersection \(\bigcap_{i \in I} A_i\) — everything in all the \(A_i\).

    The books every branch of the library owns.

  • Ordered pair \((a,b) := \{\{a\},\{a,b\}\}\) — Kuratowski's trick.

    A set doesn't remember order, so order is faked: mark the first element by putting it in a box of its own.

  • Cartesian product \(A \times B = \{(a,b) : a \in A,\ b \in B\}\).

    Every (shirt, trousers) outfit from 3 shirts and 4 trousers: 12 pairs. This is where \(\mathbb{R}^n\) will come from.

  • \(n\)-fold product \(A_1 \times \cdots \times A_n\), with \(A^{n}\) when all factors agree.

    \(\mathbb{R}^3\) is triples of reals. Chapters 4 onward live here.

  • Partition — a family of non-empty, pairwise disjoint sets whose union is the whole.

    Slicing a cake: every crumb in exactly one slice, no slice empty.

  • Cover — a family whose union contains the set; overlaps allowed.

    Beer mats scattered to hide the table: they may overlap, they just have to leave no wood showing. Compactness (Chapter 8) is about covers.

Theorems — The Algebra of Sets

  • Commutativity & associativity: \(\cup\) and \(\cap\) are commutative and associative.

    Pouring bag A into B, or B into A, leaves the same pile.

    \(x \in A \cup B \iff x \in A \lor x \in B \iff x \in B \lor x \in A \iff x \in B \cup A\), using commutativity of \(\lor\) (Chapter 1, Layer 1); Extensionality concludes. Associativity follows the same way from associativity of \(\lor\), and the \(\cap\) cases from the corresponding \(\land\) laws. \(\blacksquare\)

  • Distributivity: \(A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\), and dually.

    "Invited by me, and by either of you" = "invited by me and you-1, or by me and you-2."

    \(x \in A \cap (B \cup C) \iff x \in A \land (x \in B \lor x \in C) \iff (x \in A \land x \in B) \lor (x \in A \land x \in C)\), by the distributive law for \(\land\) over \(\lor\); the last line says \(x \in (A\cap B) \cup (A \cap C)\). Double inclusion is thereby established in one chain of equivalences. The dual is the mirror argument. \(\blacksquare\)

  • De Morgan for sets: \((A \cup B)^{c} = A^{c} \cap B^{c}\) and \((A \cap B)^{c} = A^{c} \cup B^{c}\).

    "Not invited by either" = "not invited by him and not invited by her."

    \(x \in (A\cup B)^c \iff \neg(x \in A \lor x \in B) \iff \neg(x\in A) \land \neg(x \in B) \iff x \in A^c \cap B^c\), by De Morgan's law for \(\lor\). The second identity is the same computation with \(\land\). \(\blacksquare\)

  • General De Morgan: \(\bigl(\bigcup_i A_i\bigr)^{c} = \bigcap_i A_i^{c}\) and \(\bigl(\bigcap_i A_i\bigr)^{c} = \bigcup_i A_i^{c}\).

    "In no shelf" = "outside shelf 1, and outside shelf 2, and…" — however many shelves there are.

    \(x \in (\bigcup_i A_i)^c \iff \neg \exists i\,(x \in A_i) \iff \forall i\,(x \notin A_i) \iff x \in \bigcap_i A_i^c\), using the quantifier-negation law of Chapter 1, Layer 3. The second identity is dual. \(\blacksquare\)

  • Idempotence, identity, absorption: \(A \cup A = A\), \(A \cap U = A\), \(A \cup (A \cap B) = A\).

    Adding your own list to itself changes nothing.

    Each is the set translation of the corresponding propositional law of Chapter 1, Layer 1, obtained by replacing \(\lor,\land\) with \(\cup,\cap\) and reading membership as truth. For instance \(x \in A \cup (A\cap B) \iff x \in A \lor (x \in A \land x \in B) \iff x \in A\) by absorption. \(\blacksquare\)

  • Difference as intersection: \(A \setminus B = A \cap B^{c}\).

    "Mine but not yours" = "mine, and among the not-yours".

    \(x \in A \setminus B \iff x \in A \land x \notin B \iff x \in A \land x \in B^c \iff x \in A \cap B^c\). \(\blacksquare\)

  • Symmetric difference is associative, and \(A \triangle B = (A \cup B) \setminus (A \cap B)\).

    It behaves like addition modulo 2: elements cancel in pairs.

    Membership in \(A \triangle B\) means "in exactly one", i.e. the exclusive-or of \(x \in A\) and \(x \in B\). Since \(\oplus\) is associative on truth values (check the 8 rows), \(x \in (A \triangle B) \triangle C \iff\) an odd number of \(A,B,C\) contain \(x\) \(\iff x \in A \triangle (B \triangle C)\). The alternative formula says the same: in the union but not in both. \(\blacksquare\)

  • Monotonicity: \(A \subseteq B\) implies \(A \cup C \subseteq B \cup C\) and \(A \cap C \subseteq B \cap C\).

    A bigger guest list stays bigger after both lists get the same extra invitations.

    If \(x \in A \cup C\) then \(x \in A\) — hence \(x \in B\) — or \(x \in C\); either way \(x \in B \cup C\). If \(x \in A \cap C\) then \(x \in A \subseteq B\) and \(x \in C\), so \(x \in B \cap C\). \(\blacksquare\)

  • Power set of a finite set: \(|\mathcal{P}(A)| = 2^{|A|}\) when \(A\) is finite.

    3 toppings, 8 possible pizzas — each topping is an independent yes/no.

    Induct on \(n = |A|\). For \(n = 0\), \(\mathcal{P}(\varnothing) = \{\varnothing\}\) has \(1 = 2^0\) member. If \(|A| = n+1\), fix \(a \in A\); every subset either omits \(a\) — and these are exactly the subsets of \(A \setminus \{a\}\), of which there are \(2^{n}\) by hypothesis — or contains \(a\), and these are in bijection with the former by removing \(a\). So the total is \(2^n + 2^n = 2^{n+1}\). \(\blacksquare\)

  • Products distribute: \(A \times (B \cup C) = (A \times B) \cup (A \times C)\), and likewise over \(\cap\).

    Every shirt paired with (jeans or shorts) = (shirt, jeans) outfits together with (shirt, shorts) outfits.

    \((x,y) \in A \times (B \cup C) \iff x \in A \land (y \in B \lor y \in C) \iff (x\in A \land y \in B) \lor (x \in A \land y \in C)\), which says \((x,y) \in (A\times B) \cup (A \times C)\). The \(\cap\) case replaces \(\lor\) by \(\land\). \(\blacksquare\)

  • Kuratowski pairs work: \((a,b) = (c,d)\) if and only if \(a = c\) and \(b = d\).

    The whole point of the trick: it really does remember which came first.

    (\(\Leftarrow\)) Immediate. (\(\Rightarrow\)) Suppose \(\{\{a\},\{a,b\}\} = \{\{c\},\{c,d\}\}\). If \(a = b\), the left side is \(\{\{a\}\}\), forcing \(\{c\} = \{c,d\} = \{a\}\), so \(c = d = a = b\). Otherwise \(\{a\} \ne \{a,b\}\); since \(\{a\}\) is a member of the right side and has one element, \(\{a\} = \{c\}\), so \(a = c\); then \(\{a,b\} = \{c,d\} = \{a,d\}\) and \(b \ne a\) forces \(b = d\). \(\blacksquare\)

Methods

  • Translate to logic — replace \(\cup, \cap, {}^{c}\) by \(\lor, \land, \neg\) and use Chapter 1.

    Every identity above is a propositional law in disguise. Prove it once, in logic, and reuse it forever.

  • Chain of equivalences — write \(x \in \text{LHS} \iff \cdots \iff x \in \text{RHS}\).

    Both inclusions at once — as long as every step really is reversible.

  • Counting subsets — each element is an independent in/out choice.

    Encode a subset as a string of yes/no bits, and counting subsets becomes counting binary strings.

Layer 4 · Structure

Relations

Pairs, sorted: sameness, order, and everything in between.

Concepts & Definitions

  • Relation — any subset \(R \subseteq A \times B\); write \(aRb\) for \((a,b) \in R\).

    "Is a friend of" is just the set of all friend-pairs. Nothing more mysterious than that.

  • Domain & range — the first and second coordinates that actually occur.

    Among the friend-pairs: who has at least one friend, and who is at least one person's friend.

  • Inverse relation \(R^{-1} = \{(b,a) : (a,b) \in R\}\).

    "Is a parent of", reversed, is "is a child of".

  • Composition \(S \circ R\) — do \(R\), then \(S\).

    "Sibling of a parent" composes into "aunt or uncle".

  • Reflexive — \(aRa\) for all \(a\).

    "Is the same age as" — everyone qualifies with themselves.

  • Symmetric — \(aRb \Rightarrow bRa\).

    "Is married to" goes both ways. "Loves" sadly need not.

  • Antisymmetric — \(aRb\) and \(bRa\) imply \(a = b\).

    If I'm at least as tall as you and you're at least as tall as me, we're the same height.

  • Transitive — \(aRb\) and \(bRc\) imply \(aRc\).

    "Is an ancestor of" passes down the generations.

  • Equivalence relation — reflexive, symmetric and transitive.

    "Was born in the same month as" — it sorts everyone into twelve tidy groups.

  • Equivalence class \([a] = \{x : x \sim a\}\).

    All the March people, treated as one object called "March".

  • Quotient set \(A/{\sim}\) — the set of equivalence classes.

    The calendar of twelve months, made from a crowd of people.

  • Partial order \(\le\) — reflexive, antisymmetric, transitive.

    "Is a subfolder of": some folders are unrelated, and that's allowed.

  • Strict order \(<\) — irreflexive and transitive.

    "Is strictly cheaper than". Nothing is cheaper than itself.

  • Total (linear) order — a partial order in which any two elements are comparable.

    A queue: for any two people, one is definitely in front.

  • Well-order — a total order in which every non-empty subset has a least element.

    \(\mathbb{N}\) is well-ordered; \(\mathbb{Z}\) and \(\mathbb{R}\) are not — pick "all the negatives" and there's no smallest.

  • Upper bound, maximum, maximal — above everything; a greatest member; nothing strictly above it.

    A maximum beats everyone. A maximal element merely has nobody above it — in a partial order the two differ, and Zorn's lemma cares about the second.

  • Supremum & infimum — the least upper bound and greatest lower bound.

    The lowest ceiling that still clears the furniture. Chapter 3's completeness axiom is exactly a promise that this exists in \(\mathbb{R}\).

  • Chain — a subset that is totally ordered by the given order.

    One unbroken line of nested folders inside a branching tree.

  • Hasse diagram — a picture of a finite partial order, drawing only the direct links.

    The family tree of divisibility for 12: lines from 1 up to 2 and 3, and so on, without the redundant shortcuts.

Theorems

  • Equivalence classes partition: the classes of an equivalence relation are non-empty, pairwise disjoint, and cover \(A\).

    Twelve birth-month groups: everyone is in exactly one, none empty, none overlapping.

    Each \([a]\) contains \(a\) by reflexivity, so classes are non-empty and cover \(A\). Suppose \([a] \cap [b] \ne \varnothing\), say \(c \sim a\) and \(c \sim b\). By symmetry \(a \sim c\), and transitivity gives \(a \sim b\). Then for any \(x \in [a]\), \(x \sim a \sim b\) gives \(x \in [b]\), and symmetrically; so \([a] = [b]\). Hence distinct classes are disjoint. \(\blacksquare\)

  • Converse: every partition of \(A\) arises from exactly one equivalence relation.

    Cut the cake however you like, and "in the same slice" is automatically an equivalence.

    Given a partition \(\mathcal{P}\), define \(x \sim y\) iff some block contains both. Reflexivity holds since the blocks cover \(A\); symmetry is built into the definition; transitivity holds because blocks are pairwise disjoint, so the block containing \(x,y\) and the one containing \(y,z\) must coincide. Its classes are exactly the blocks, and any equivalence with those classes agrees with \(\sim\) pair by pair. \(\blacksquare\)

  • Suprema are unique when they exist.

    There can only be one lowest ceiling.

    Let \(s, s'\) both be least upper bounds of \(S\). Since \(s\) is an upper bound and \(s'\) is least among upper bounds, \(s' \le s\); by symmetry \(s \le s'\). Antisymmetry gives \(s = s'\). \(\blacksquare\)

  • A well-order is a total order, and has no infinite strictly decreasing sequence.

    There's always a first, so you can never keep stepping down forever.

    Totality: given \(a \neq b\), the set \(\{a,b\}\) is non-empty so has a least element, which is then below the other. Descent: an infinite strictly decreasing sequence \(a_0 > a_1 > \cdots\) has range a non-empty set with no least element, contradicting the well-ordering. \(\blacksquare\)

  • Transitive closure exists: every relation \(R\) has a smallest transitive relation containing it.

    "Parent of", closed up, becomes "ancestor of".

    The set of transitive relations on \(A\) containing \(R\) is non-empty (it contains \(A \times A\)) and is a subset of \(\mathcal{P}(A \times A)\), so its intersection exists by Layer 2. An intersection of transitive relations is transitive: if \((a,b)\) and \((b,c)\) lie in every member, so does \((a,c)\). That intersection contains \(R\) and is contained in every such relation, hence is the smallest. \(\blacksquare\)

  • Maximum \(\Rightarrow\) maximal, not conversely.

    In "is a subfolder of", two sibling folders can both be maximal, and neither is the maximum.

    If \(m\) is a maximum then \(x \le m\) for all \(x\); were \(m < y\) we would also have \(y \le m\), so antisymmetry gives \(y = m\), contradicting strictness — hence \(m\) is maximal. For the failure of the converse, order \(\{a,b\}\) by equality only: both are maximal, neither is a maximum. \(\blacksquare\)

Methods

  • Check the three properties — to prove "\(\sim\) is an equivalence", verify reflexive, symmetric, transitive in turn.

    Three short paragraphs, always in the same order. Never skip transitivity — it's the one that fails.

  • Quotient construction — build a new object as the set of equivalence classes.

    \(\mathbb{Z}\), \(\mathbb{Q}\), clock arithmetic and \(\mathbb{R}\) itself are all made this way in Layer 6 and Chapter 3.

  • Well-definedness check — when defining an operation on classes, verify the answer doesn't depend on the representative.

    "Add the fractions \(1/2\) and \(1/3\)" must give the same answer if you write them as \(2/4\) and \(2/6\).

Layer 5 · Maps

Functions

Relations with exactly one output — the workhorse of all later chapters.

Concepts & Definitions

  • Function \(f : A \to B\) — a relation pairing each \(a \in A\) with exactly one \(b\).

    A vending machine: one button, one snack, every time. Two snacks from one button would break it.

  • Domain, codomain, image — where it starts, where it may land, where it actually lands.

    \(f(x) = x^2\) on \(\mathbb{R}\): codomain \(\mathbb{R}\), image only \([0,\infty)\).

  • Injective (one-to-one) — different inputs give different outputs.

    Passport numbers: no two people share one.

  • Surjective (onto) — every element of the codomain is hit.

    Every seat in the theatre is taken — possibly some by more than one lap-sitter.

  • Bijective — injective and surjective; a perfect pairing.

    Every guest gets exactly one chair, every chair exactly one guest.

  • Composition \((g \circ f)(x) = g(f(x))\).

    Convert pounds to euros, then euros to yen — one machine made of two.

  • Identity function \(\mathrm{id}_A(x) = x\).

    The do-nothing machine. Useful precisely because it does nothing.

  • Inverse function \(f^{-1}\) — exists exactly when \(f\) is a bijection.

    The machine run backwards. It only works if nothing was lost and nothing was doubled up.

  • Image of a set \(f[S] = \{f(x) : x \in S\}\).

    Where this group of people ends up after the shuffle.

  • Preimage \(f^{-1}[T] = \{x : f(x) \in T\}\) — defined even when \(f\) has no inverse.

    "Who ended up in this room?" — a fair question even if several people did. Preimages behave far better than images, which is why topology (Chapter 8) is written with them.

  • Restriction \(f|_S\) — the same rule, on a smaller domain.

    \(x^2\) is not invertible on \(\mathbb{R}\), but restrict it to \([0,\infty)\) and \(\sqrt{\ }\) appears.

  • Sequence — a function \(\mathbb{N} \to A\), written \((a_n)\).

    A numbered list: item 1, item 2, item 3… Chapter 3 is built on these.

  • Indexed family — a function \(I \to \text{sets}\), written \(\{A_i\}_{i\in I}\).

    One box per label. The labels do the bookkeeping.

  • Function set \(B^{A}\) — the set of all functions \(A \to B\).

    \(\{0,1\}^{A}\) is "all ways to answer yes/no for each element" — and that's exactly \(\mathcal{P}(A)\) in disguise.

  • Characteristic function \(\chi_S(x) = 1\) if \(x \in S\), else \(0\).

    The guest list as a door policy: 1 means "let them in". These become the simple functions of Chapter 12.

Theorems

  • Composition is associative: \((h \circ g)\circ f = h \circ (g \circ f)\).

    Three conversions in a row: it doesn't matter which pair you bolt together first.

    Both sides are functions with the same domain and codomain, and for every \(x\), \(((h\circ g)\circ f)(x) = h(g(f(x))) = (h \circ (g\circ f))(x)\). Functions agreeing at every point are equal as sets of pairs. \(\blacksquare\)

  • Inverse exists iff bijective, and then it is unique.

    Undo is possible exactly when nothing was lost (surjective) and nothing was merged (injective).

    If \(f\) is a bijection, define \(g(b)\) to be the unique \(a\) with \(f(a) = b\) — existence by surjectivity, uniqueness by injectivity — then \(g \circ f = \mathrm{id}_A\) and \(f \circ g = \mathrm{id}_B\). Conversely, a left inverse forces injectivity (\(f(a)=f(a') \Rightarrow a = g(f(a)) = g(f(a')) = a'\)) and a right inverse forces surjectivity (\(b = f(g(b))\)). Uniqueness: if \(g, g'\) are both inverses then \(g = g\circ \mathrm{id} = g \circ (f \circ g') = (g\circ f)\circ g' = g'\). \(\blacksquare\)

  • Composition preserves injectivity and surjectivity.

    Two perfect pairings in a row make one perfect pairing.

    If \(f, g\) are injective and \(g(f(x)) = g(f(y))\), injectivity of \(g\) gives \(f(x) = f(y)\), then injectivity of \(f\) gives \(x = y\). If \(f, g\) are surjective and \(c\) is given, pick \(b\) with \(g(b) = c\) and \(a\) with \(f(a) = b\); then \(g(f(a)) = c\). \(\blacksquare\)

  • Backwards information: if \(g \circ f\) is injective then \(f\) is injective; if \(g \circ f\) is surjective then \(g\) is surjective.

    If the whole pipeline loses nothing, the first stage lost nothing. Says nothing about the second stage.

    If \(f(x) = f(y)\) then \(g(f(x)) = g(f(y))\), so injectivity of \(g\circ f\) forces \(x=y\). If \(c\) is in the codomain of \(g\), surjectivity of \(g \circ f\) gives \(a\) with \(g(f(a)) = c\), so \(f(a)\) is a preimage of \(c\) under \(g\). \(\blacksquare\)

  • Preimages respect everything: \(f^{-1}[\bigcup T_i] = \bigcup f^{-1}[T_i]\), \(f^{-1}[\bigcap T_i] = \bigcap f^{-1}[T_i]\), \(f^{-1}[T^{c}] = (f^{-1}[T])^{c}\).

    Preimages are perfectly behaved. Images are not — which is why continuity is defined with preimages.

    \(x \in f^{-1}[\bigcup_i T_i] \iff f(x) \in T_i\) for some \(i\) \(\iff x \in f^{-1}[T_i]\) for some \(i\). Replacing "some" by "all" gives the intersection case, and \(f(x) \notin T \iff x \notin f^{-1}[T]\) gives the complement case. \(\blacksquare\)

  • Images do not: \(f[A \cap B] \subseteq f[A] \cap f[B]\), with equality for all \(A,B\) iff \(f\) is injective.

    Two disjoint groups can still end up in the same room — so the shared destination isn't the destination of anyone shared.

    If \(y = f(x)\) with \(x \in A \cap B\) then \(y \in f[A]\) and \(y \in f[B]\), giving the inclusion. If \(f\) is not injective, take \(a \neq b\) with \(f(a)=f(b)\) and set \(A = \{a\}, B = \{b\}\): the left side is empty, the right is not. If \(f\) is injective and \(y \in f[A]\cap f[B]\), the preimages in \(A\) and in \(B\) must coincide, so \(y \in f[A\cap B]\). \(\blacksquare\)

  • Round trips: \(S \subseteq f^{-1}[f[S]]\) and \(f[f^{-1}[T]] \subseteq T\), with equality iff \(f\) is injective, resp. surjective.

    Go and come back and you may have picked up strangers; come back and go and you may not fill the room.

    \(x \in S \Rightarrow f(x) \in f[S] \Rightarrow x \in f^{-1}[f[S]]\). If \(f\) is injective and \(x \in f^{-1}[f[S]]\), then \(f(x) = f(s)\) for some \(s \in S\), so \(x = s \in S\). Similarly \(y \in f[f^{-1}[T]]\) means \(y = f(x)\) with \(f(x) \in T\), so \(y \in T\); and if \(f\) is surjective every \(y \in T\) has a preimage, which lies in \(f^{-1}[T]\). \(\blacksquare\)

  • \(\mathcal{P}(A)\) and \(\{0,1\}^{A}\) are in bijection.

    A subset is a yes/no answer for each element — the same object, written two ways.

    Map \(S \mapsto \chi_S\). It is injective, since \(\chi_S = \chi_T\) forces \(x \in S \iff x \in T\) and Extensionality gives \(S = T\); and surjective, since any \(g : A \to \{0,1\}\) is \(\chi_S\) for \(S = g^{-1}[\{1\}]\). \(\blacksquare\)

Methods

  • Prove injectivity — assume \(f(x) = f(y)\) and grind to \(x = y\).

    Always this shape. Never "assume \(x \ne y\)" unless you want a harder life.

  • Prove surjectivity — take an arbitrary \(b\) and construct an \(x\) with \(f(x) = b\).

    Solve the equation for \(x\); the solution is the proof.

  • Build the inverse explicitly — the cleanest way to prove a bijection.

    Show the two round trips give the identity and you're finished in two lines.

  • Work with preimages — whenever a proof about images turns ugly, try the preimage instead.

    The standing advice of Chapters 8–12.

Layer 6 · Counting

Numbers from Sets

Building \(\mathbb{N}\), \(\mathbb{Z}\) and \(\mathbb{Q}\) out of nothing at all.

Concepts & Definitions

  • Von Neumann natural — each number is the set of all smaller numbers: \(0 = \varnothing\), \(n+1 = n \cup \{n\}\).

    \(3 = \{0,1,2\}\). The number 3 literally is a bag holding three things — and \(m < n\) just means \(m \in n\).

  • Successor \(S(n) = n \cup \{n\}\).

    "Add yourself to your own list of predecessors." That's counting.

  • Inductive set — contains \(\varnothing\) and is closed under successor.

    A staircase with a bottom step and a next step for every step. The Axiom of Infinity says one exists.

  • \(\mathbb{N}\) — the intersection of all inductive sets: the smallest one.

    Take every possible staircase and keep only the steps common to all: exactly the counting numbers, nothing extra.

  • Peano axioms — 0 exists; \(S\) is injective; 0 is not a successor; induction holds.

    Four sentences that pin down counting. Here they are theorems, not assumptions.

  • \(\mathbb{Z}\) — pairs \((a,b)\) of naturals meaning \(a - b\), modulo \((a,b)\sim(c,d) \iff a+d = c+b\).

    "Owed 3, paid 5" and "owed 10, paid 12" describe the same debt: \(+2\).

  • \(\mathbb{Q}\) — pairs \((p,q)\), \(q \ne 0\), meaning \(p/q\), modulo \((p,q)\sim(r,s)\iff ps = rq\).

    \(1/2\) and \(2/4\) are two names for one class. The class is the number.

  • Ordered field — a set with \(+, \times\) and a compatible order obeying the usual laws.

    \(\mathbb{Q}\) is one. It is missing exactly one thing — no gaps — and that is Chapter 3's job.

  • Divisibility & primes — \(a \mid b\) means \(b = ac\); a prime has exactly two divisors.

    12 is \(2\times2\times3\), and there's no second way to write it. That fact is a theorem, not an accident.

Theorems

  • \(\mathbb{N}\) exists and is the least inductive set.

    Infinity hands you some staircase; intersecting them all trims it to exactly the numbers.

    Infinity gives an inductive set \(I\). By Separation, \(\mathbb{N} := \{x \in I : x \text{ belongs to every inductive set}\}\) is a set. It contains \(\varnothing\) and is closed under \(S\) (both properties are shared by every inductive set), so it is inductive; and by construction it is contained in every inductive set. \(\blacksquare\)

  • Peano's axioms hold in \(\mathbb{N}\).

    Counting isn't assumed here — it's derived, from bags inside bags.

    \(\varnothing \in \mathbb{N}\) by inductiveness. \(S(n) \ne \varnothing\) since \(n \in S(n)\), so \(0\) is no successor. Injectivity: if \(n \cup \{n\} = m \cup \{m\}\) then \(n \in m \cup \{m\}\) and \(m \in n \cup \{n\}\); Foundation rules out \(n \in m \in n\), leaving \(n = m\). Induction: if \(A \subseteq \mathbb{N}\) contains \(0\) and is closed under \(S\), then \(A\) is inductive, so \(\mathbb{N}\subseteq A\) by minimality, i.e. \(A = \mathbb{N}\). \(\blacksquare\)

  • \(\mathbb{N}\) is well-ordered by \(\in\).

    Every non-empty pile of counting numbers has a smallest — the fact that makes "minimal counterexample" proofs legal.

    Let \(S \subseteq \mathbb{N}\) be non-empty and pick \(n \in S\). If \(n \cap S = \varnothing\) then \(n\) is least. Otherwise \(n \cap S\) is a non-empty subset of the finite set \(n = \{0,\dots,n-1\}\); Foundation applied to \(n \cap S\) yields a member \(m\) with \(m \cap (n\cap S) = \varnothing\), and such an \(m\) is a least element of \(S\). Totality of \(\in\) on \(\mathbb{N}\) follows by induction. \(\blacksquare\)

  • Arithmetic is well defined: \(+\) and \(\times\) exist on \(\mathbb{N}\), obeying associativity, commutativity and distributivity.

    \(m + 0 = m\) and \(m + S(n) = S(m+n)\). Everything you know about addition follows from those two lines.

    The recursion theorem (Chapter 1, Layer 6) turns the two clauses into a genuine function \(+ : \mathbb{N}^2 \to \mathbb{N}\), and likewise \(m \times 0 = 0\), \(m \times S(n) = m\times n + m\) defines \(\times\). Each law is then an induction: e.g. associativity of \(+\) is proved by inducting on the third summand, the base case being \(m + (n+0) = (m+n)+0\) and the step following from \(S\) being applied to both sides. \(\blacksquare\)

  • \(\mathbb{Z}\) is a well-defined ordered ring; \(\mathbb{Q}\) is a well-defined ordered field.

    Subtraction always works in \(\mathbb{Z}\); division (except by 0) always works in \(\mathbb{Q}\). Each is bought by a quotient construction.

    Check \(\sim\) is an equivalence (Layer 4), then define \([(a,b)] + [(c,d)] = [(a+c, b+d)]\) and \([(a,b)]\cdot[(c,d)] = [(ac+bd,\,ad+bc)]\), verifying independence of representatives — if \(a+d' = a'+d\) and similarly for the second pair, substitution shows the results agree. The ring axioms then follow from those of \(\mathbb{N}\). For \(\mathbb{Q}\), the same programme with \((p,q)\sim(r,s) \iff ps = rq\) gives a field: the inverse of \([(p,q)]\), \(p \neq 0\), is \([(q,p)]\). \(\blacksquare\)

  • Division algorithm: for \(a \in \mathbb{Z}\), \(b > 0\), there are unique \(q, r\) with \(a = qb + r\) and \(0 \le r < b\).

    17 sweets among 5 children: 3 each, 2 left over — and there's no other honest answer.

    Existence: the set \(\{a - qb \ge 0 : q \in \mathbb{Z}\}\) is a non-empty set of naturals, so by well-ordering it has a least element \(r = a - qb\). If \(r \ge b\) then \(r - b \ge 0\) would be smaller and still in the set — contradiction, so \(r < b\). Uniqueness: from \(q_1b + r_1 = q_2b+r_2\) we get \(b \mid (r_1 - r_2)\) with \(|r_1 - r_2| < b\), forcing \(r_1 = r_2\) and then \(q_1 = q_2\). \(\blacksquare\)

  • Fundamental theorem of arithmetic: every integer \(> 1\) factors into primes, uniquely up to order.

    \(60 = 2\cdot2\cdot3\cdot5\), and no other bag of primes multiplies to 60.

    Existence by strong induction: \(n\) is prime, or \(n = ab\) with \(1 < a,b < n\), and both factor by hypothesis. Uniqueness uses Euclid's lemma (if \(p \mid ab\) then \(p\mid a\) or \(p \mid b\)), itself from the division algorithm via Bézout. Given two factorisations, \(p_1\) divides the other product, so it equals some \(q_j\); cancel and apply induction on the number of factors. \(\blacksquare\)

  • \(\mathbb{Q}\) is dense in itself: between any two rationals lies another.

    Halfway between any two prices is another price. There is no "next" rational.

    Given \(p < q\), the rational \(\frac{p+q}{2}\) exists (fields allow division by 2) and satisfies \(p < \frac{p+q}{2} < q\), since \(p < q\) gives \(2p < p + q < 2q\). \(\blacksquare\)

  • \(\mathbb{Q}\) has gaps: no rational squares to 2.

    The diagonal of a unit square has no rational length — the discovery that made \(\mathbb{R}\) necessary.

    Suppose \(p^2 = 2q^2\) with \(\gcd(p,q) = 1\). Then \(p^2\) is even, so \(p\) is even (contraposition: odd squared is odd), say \(p = 2k\); substituting gives \(4k^2 = 2q^2\), so \(q^2 = 2k^2\) and \(q\) is even too — contradicting \(\gcd(p,q)=1\). \(\blacksquare\)

Methods

  • Construct by quotient — invent the object you want as classes of pairs.

    Want subtraction? Take pairs and declare "same difference". Want division? Pairs and "same ratio".

  • Define by recursion, prove by induction — the standard pairing.

    Two clauses define \(+\); one induction proves it associative.

  • Descent for irrationality — assume lowest terms, derive a common factor.

    Works for \(\sqrt{2}\), \(\sqrt{3}\), \(\sqrt[3]{2}\) — anywhere unique factorisation applies.

Layer 7 · Sizes

Cardinality

Comparing infinities by pairing things off.

Concepts & Definitions

  • Equinumerous \(A \approx B\) — there is a bijection between them.

    A shepherd with no numbers still knows whether every sheep has a pen: one sheep, one pen.

  • Cardinality \(|A|\) — the size of \(A\), the thing shared by all sets equinumerous with it.

    "Five" is what all five-element sets have in common.

  • Finite — equinumerous with some \(n \in \mathbb{N}\).

    You can count it and stop.

  • Infinite — not finite.

    You start counting and never finish.

  • Dedekind-infinite — equinumerous with a proper subset of itself.

    Hilbert's hotel: every room full, yet the evens alone can host everybody. Only an infinite set can do that.

  • Countably infinite — equinumerous with \(\mathbb{N}\); cardinality \(\aleph_0\).

    Anything you can put in an endless numbered list.

  • Countable — finite or countably infinite.

    Listable, with or without an end.

  • Uncountable — infinite but not countable.

    \(\mathbb{R}\). No list, however clever, can contain them all.

  • Cardinal comparison \(|A| \le |B|\) — there is an injection \(A \to B\).

    Everyone gets their own chair, chairs to spare allowed.

  • The continuum \(\mathfrak{c} = |\mathbb{R}| = 2^{\aleph_0}\).

    The number of ways to answer infinitely many yes/no questions.

  • Continuum hypothesis — there is no cardinality strictly between \(\aleph_0\) and \(\mathfrak{c}\).

    Famously undecidable: ZFC can neither prove it nor refute it. Status is independent, not "open".

Theorems

  • Equinumerosity is an equivalence relation (on any set of sets).

    Same size as yourself; if you match me, I match you; matches chain together.

    \(\mathrm{id}_A\) is a bijection, giving reflexivity. The inverse of a bijection is a bijection (Layer 5), giving symmetry. The composition of bijections is a bijection, giving transitivity. \(\blacksquare\)

  • \(\mathbb{N}\), \(\mathbb{Z}\), \(\mathbb{Q}\) all have cardinality \(\aleph_0\).

    There are exactly as many fractions as counting numbers — even though the fractions look infinitely denser.

    \(\mathbb{Z}\): the map \(0,1,-1,2,-2,\dots\) is a bijection with \(\mathbb{N}\). \(\mathbb{Q}\): list the pairs \((p,q)\) by walking the diagonals of the grid \(\mathbb{Z}\times\mathbb{N}^{+}\), skipping non-reduced fractions; this is a surjection from a countable set onto \(\mathbb{Q}\), and \(\mathbb{Q}\) is infinite, so it is countably infinite. \(\blacksquare\)

  • A countable union of countable sets is countable (uses a weak form of Choice).

    Infinitely many numbered lists can be merged into one numbered list — by walking the diagonals.

    Choose an enumeration \(f_i : \mathbb{N}\to A_i\) for each \(i\) (this choice needs countable AC). Then \((i,n)\mapsto f_i(n)\) is a surjection \(\mathbb{N}\times\mathbb{N} \to \bigcup_i A_i\), and \(\mathbb{N}\times\mathbb{N}\) is countable via the diagonal pairing \((i,n)\mapsto \tfrac{(i+n)(i+n+1)}{2}+n\). A surjective image of a countable set is countable. \(\blacksquare\)

  • Cantor's theorem: \(|A| < |\mathcal{P}(A)|\) for every set \(A\).

    No list of guest lists can contain every guest list — there are always more ways to choose than there are things to choose from.

    \(a \mapsto \{a\}\) is an injection, so \(|A| \le |\mathcal{P}(A)|\). Suppose \(f : A \to \mathcal{P}(A)\) were surjective and set \(D = \{a \in A : a \notin f(a)\}\). If \(D = f(d)\) for some \(d\), then \(d \in D \iff d \notin f(d) = D\) — a contradiction. So no surjection exists, and the inequality is strict. \(\blacksquare\)

  • \(\mathbb{R}\) is uncountable, and \(|\mathbb{R}| = 2^{\aleph_0}\).

    Cantor's diagonal: given any list of decimals, change the \(n\)-th digit of the \(n\)-th number and you have one that's nowhere on the list.

    Suppose \(x_1,x_2,\dots\) listed all reals in \((0,1)\). Define \(y\) whose \(n\)-th decimal digit differs from that of \(x_n\) (avoiding 0 and 9 to dodge the \(0.4999\ldots = 0.5\) ambiguity). Then \(y \in (0,1)\) differs from every \(x_n\) — contradiction. For the cardinality, binary expansions give an injection \(\{0,1\}^{\mathbb{N}} \to \mathbb{R}\) and an injection back via decimal codes, so Cantor–Schröder–Bernstein gives \(|\mathbb{R}| = 2^{\aleph_0}\). \(\blacksquare\)

  • Cantor–Schröder–Bernstein: injections both ways give a bijection.

    Everyone fits in their chairs and every chair fits a person: then a perfect seating exists — and you never had to find it directly.

    Let \(f: A\to B\), \(g : B \to A\) be injections. Call \(a \in A\) an \(A\)-origin point if the backward chain \(a, g^{-1}(a), f^{-1}(g^{-1}(a)),\dots\) terminates in \(A\). Define \(h(a) = f(a)\) if \(a\) is an \(A\)-origin point (or the chain is infinite), and \(h(a) = g^{-1}(a)\) otherwise. Chain by chain, \(h\) is checked to be well defined, injective and surjective — each chain is either a line or a cycle, and \(h\) pairs its elements off exactly. \(\blacksquare\)

  • Cardinal arithmetic for infinite \(\kappa\): \(\kappa + \kappa = \kappa\cdot\kappa = \kappa\) (with AC).

    Hilbert's hotel again: doubling an infinite crowd, or squaring it, doesn't need a bigger hotel.

    Sketch: with AC every infinite cardinal is an aleph, so it suffices to prove \(\aleph_\alpha \cdot \aleph_\alpha = \aleph_\alpha\). Use transfinite induction and the Gödel pairing well-ordering of \(\kappa\times\kappa\), whose initial segments have size \(< \kappa\); this exhibits a bijection \(\kappa\times\kappa \to \kappa\). Then \(\kappa \le \kappa + \kappa \le \kappa\cdot\kappa = \kappa\) squeezes the sum. \(\blacksquare\)

  • Corollary: \(|\mathbb{R}^{n}| = |\mathbb{R}|\) for every \(n \ge 1\).

    The plane has exactly as many points as the line. Dimension is not a matter of how many points there are — Chapters 8 and 18 will say what it really is.

    \(|\mathbb{R}^2| = \mathfrak{c}\cdot\mathfrak{c} = (2^{\aleph_0})^2 = 2^{\aleph_0 + \aleph_0} = 2^{\aleph_0} = \mathfrak{c}\); induction gives every finite \(n\). (Concretely, interleave the binary digits of two reals to make one.) \(\blacksquare\)

  • Dedekind's characterisation: a set is infinite iff it is equinumerous with a proper subset (with countable AC).

    Move every hotel guest from room \(n\) to room \(n+1\) and room 1 is free — with the same guests.

    If \(A\) is finite, no bijection with a proper subset exists (pigeonhole, Chapter 1, Layer 5). If \(A\) is infinite, countable choice extracts a sequence of distinct \(a_0,a_1,\dots \in A\); map \(a_n \mapsto a_{n+1}\) and fix everything else. This is an injection of \(A\) onto \(A \setminus \{a_0\}\). \(\blacksquare\)

Methods

  • Build a bijection — the only way to prove two sets have the same size.

    Pair them off explicitly; the formula is the proof.

  • Diagonalisation — to show no list is complete, build the entry it missed.

    Differ from the \(n\)-th item in the \(n\)-th place. Used again for the halting problem and Gödel.

  • Cantor–Schröder–Bernstein — build two injections instead of one bijection.

    Far easier in practice: squeeze from both sides and let the theorem finish the job.

  • Diagonal enumeration — walk a grid by anti-diagonals to list a product of countable sets.

    \((0,0), (0,1), (1,0), (0,2), (1,1), (2,0),\dots\) — nothing is ever skipped.

Layer 8 · Past infinity

Ordinals & Transfinite Methods

Counting past the end of the counting numbers.

Concepts & Definitions

  • Transitive set — every member is also a subset.

    Open any box inside and its contents were already loose in the outer box.

  • Ordinal — a transitive set well-ordered by \(\in\).

    A position in a queue that may be infinitely long. Each ordinal is the set of ordinals before it.

  • Successor ordinal \(\alpha + 1 = \alpha \cup \{\alpha\}\).

    The next person in the queue.

  • Limit ordinal — non-zero with no immediate predecessor, e.g. \(\omega\).

    \(\omega\) is the position "after all the naturals" — nobody stands directly in front of it.

  • \(\omega\) — the first infinite ordinal; as a set, exactly \(\mathbb{N}\).

    Then \(\omega+1, \omega+2, \dots, \omega\cdot 2, \dots, \omega^2, \dots\) — the queue keeps going.

  • Order type — the unique ordinal order-isomorphic to a given well-order.

    Two queues of the same shape get the same label, however differently the people are named.

  • Cardinal — an ordinal not equinumerous with any smaller ordinal.

    \(\omega\) and \(\omega+1\) are different positions but the same size, so only \(\omega\) counts as a cardinal.

  • Aleph numbers \(\aleph_0, \aleph_1, \aleph_2, \dots\) — the infinite cardinals in order.

    \(\aleph_1\) is the next size up from countable. Whether \(\aleph_1 = \mathfrak{c}\) is the continuum hypothesis.

  • Cumulative hierarchy \(V_0 = \varnothing\), \(V_{\alpha+1} = \mathcal{P}(V_\alpha)\), \(V_\lambda = \bigcup_{\alpha<\lambda} V_\alpha\).

    The universe built in floors. Foundation says every set appears on some floor.

  • Rank — the first level at which a set appears.

    How deeply nested the bags are. \(\varnothing\) has rank 0.

Theorems

  • Ordinals are comparable: for ordinals \(\alpha,\beta\), exactly one of \(\alpha \in \beta\), \(\alpha = \beta\), \(\beta \in \alpha\) holds.

    Any two positions in the great queue can be compared. There are no side-by-side ordinals.

    Sketch: first show \(\alpha \cap \beta\) is an ordinal and is an initial segment of each. If \(\alpha \cap \beta\) were a proper initial segment of both, it would be a member of both, hence a member of itself — impossible by Foundation. So it equals \(\alpha\) or \(\beta\), giving \(\alpha \subseteq \beta\) or \(\beta \subseteq \alpha\); and for ordinals, proper inclusion coincides with membership. Foundation rules out two of the three cases holding at once. \(\blacksquare\)

  • Every well-ordered set is order-isomorphic to a unique ordinal.

    Ordinals are the official rulers for measuring "shape of a queue".

    Sketch: define \(F\) on the well-order \((W,<)\) by transfinite recursion, \(F(w) = \{F(v) : v < w\}\). Replacement makes the image a set; induction shows it is transitive and well-ordered by \(\in\), i.e. an ordinal, and that \(F\) is an order-isomorphism. Uniqueness: an order-isomorphism between ordinals is the identity, since the least point of disagreement would map to itself. \(\blacksquare\)

  • The class of ordinals is not a set (Burali-Forti).

    If you could bag every position in the queue, that bag would be a position after them all — and so inside itself.

    Suppose \(\Omega\) were the set of all ordinals. It is transitive (members of ordinals are ordinals) and well-ordered by \(\in\), hence itself an ordinal, so \(\Omega \in \Omega\) — contradicting Foundation. \(\blacksquare\)

  • Transfinite induction: if a property passes to \(\alpha\) whenever it holds for all \(\beta < \alpha\), it holds for every ordinal.

    Dominoes with extra rules at the "after all of these" points.

    Suppose some ordinal fails the property. Ordinals are well-ordered by \(\in\), so among the ordinals below a fixed failing one there is a least failure \(\alpha\). Every \(\beta < \alpha\) then has the property, so by hypothesis \(\alpha\) does too — contradiction. \(\blacksquare\)

  • Transfinite recursion: a function on all ordinals may be defined by giving its value in terms of earlier values.

    How \(V_\alpha\), ordinal arithmetic and Zorn's proof are all built.

    Sketch: mimic the recursion theorem of Chapter 1. For each \(\alpha\), transfinite induction shows there is a unique function on \(\alpha\) obeying the clause; Replacement collects these approximations, and their union is a class function defined on all ordinals, unique by induction. \(\blacksquare\)

  • Ordinal arithmetic is not commutative: \(1 + \omega = \omega \ne \omega + 1\).

    Adding one person to the front of an infinite queue changes nothing; adding one to the end creates a genuinely new position.

    \(1+\omega\) is the order type of one point followed by \(\mathbb{N}\), which is order-isomorphic to \(\mathbb{N}\) (shift by one), so it equals \(\omega\). But \(\omega + 1\) has a greatest element, and \(\omega\) does not; an order-isomorphism would have to preserve that, so \(\omega + 1 \ne \omega\). \(\blacksquare\)

  • Foundation \(\iff\) every set has a rank: \(V = \bigcup_\alpha V_\alpha\).

    Every set lives on some floor of the tower. Nothing floats free.

    Sketch. If every set has a rank, an \(\in\)-descending chain would give a strictly decreasing sequence of ordinals, impossible; so Foundation holds. Conversely, assume Foundation and suppose some set lay outside every \(V_\alpha\); by Foundation choose one, \(x\), that is \(\in\)-minimal with this defect. Each member of \(x\) then has a rank; Replacement collects those ranks, their supremum \(\alpha\) exists, and \(x \subseteq V_\alpha\) puts \(x \in V_{\alpha+1}\) — contradiction. \(\blacksquare\)

Methods

  • Transfinite induction — prove a statement for all ordinals: zero, successor and limit cases.

    Three cases instead of two — the limit case is where the interesting arguments live.

  • Transfinite recursion — define an object stage by stage, taking unions at limits.

    Build up a basis, a well-ordering, or a maximal object by grabbing one more element at every stage.

  • Rank induction — induct on how deeply a set is nested.

    The standard way to prove something about all sets at once.

Layer 9 · The controversial axiom

The Axiom of Choice

One innocent-looking assumption, and everything it buys and costs.

Concepts & Definitions

  • Choice function — a function picking one member from each set in a family.

    One sweet from each of infinitely many jars — with no rule saying which.

  • Axiom of Choice (AC) — every family of non-empty sets has a choice function.

    Infinitely many pairs of shoes need no axiom (take the left one). Infinitely many pairs of socks do.

  • Countable choice — the same, for countably many sets. Strictly weaker.

    Enough for most of basic analysis; not enough for Zorn.

  • Dependent choice (DC) — you may keep choosing, each step depending on the last.

    Walk forever through a graph where every node has an exit. Strictly between countable choice and full AC.

  • Zorn's lemma — if every chain in a partially ordered set has an upper bound, there is a maximal element.

    A mountain range where every upward path has a top must have at least one peak.

  • Well-ordering principle — every set can be well-ordered.

    Even \(\mathbb{R}\) can be lined up so every subset has a first element — though no one can write that line down.

  • Non-measurable set — a set of reals with no consistent notion of length.

    AC's bill comes due in Chapter 11: it manufactures sets that no "volume" can measure.

  • Independence — neither provable nor refutable from the other axioms.

    AC and the continuum hypothesis are both independent of ZF and ZFC respectively. The axioms simply don't decide.

Theorems

  • AC \(\iff\) Zorn's lemma \(\iff\) well-ordering principle.

    Three costumes, one actor. Choose whichever is easiest for the job in hand.

    Sketch of the cycle. (AC \(\Rightarrow\) Zorn) If a poset had no maximal element, every element would have something strictly above it; a choice function picks such a "next step", and transfinite recursion builds a strictly increasing chain longer than the set itself — impossible. (Zorn \(\Rightarrow\) WO) Order the well-orderings of subsets of \(A\) by "is an initial segment of"; a chain's union is again such a well-ordering, so Zorn gives a maximal one, which must exhaust \(A\) or could be extended. (WO \(\Rightarrow\) AC) Well-order \(\bigcup_i A_i\) and let the choice function take the least element of each \(A_i\). \(\blacksquare\)

  • Corollary — every vector space has a basis (Chapter 4 uses this).

    Even wild infinite-dimensional spaces have a basis. Nobody has ever exhibited one for \(\mathbb{R}\) over \(\mathbb{Q}\).

    Order the linearly independent subsets by inclusion. A chain's union is independent, because any dependency involves finitely many vectors, which already lie in one link of the chain — so every chain is bounded and Zorn gives a maximal independent set \(B\). If some \(v \notin \mathrm{span}(B)\), then \(B \cup \{v\}\) would be independent and strictly larger, contradicting maximality. So \(B\) spans, and is a basis. \(\blacksquare\)

  • Corollary — every surjection splits: if \(f : A \to B\) is onto, there is \(g: B \to A\) with \(f\circ g = \mathrm{id}_B\).

    Pick one representative from each fibre. Obvious-looking, and equivalent to AC.

    The family \(\{f^{-1}[\{b\}] : b \in B\}\) consists of non-empty sets, so AC supplies a choice function; define \(g(b)\) to be the chosen element of \(f^{-1}[\{b\}]\). Then \(f(g(b)) = b\) for all \(b\). Conversely, applying this to the projection \(\bigsqcup_i A_i \to I\) recovers AC. \(\blacksquare\)

  • Corollary — comparability of cardinals: for any \(A, B\), either \(|A| \le |B|\) or \(|B| \le |A|\).

    Any two infinities can be compared — but only because AC says so.

    Well-order both sets (WO principle). Two well-orders are always comparable: one is order-isomorphic to an initial segment of the other (compare them by transfinite recursion). That isomorphism is an injection one way or the other. \(\blacksquare\)

  • Corollary — Tychonoff's theorem: a product of compact spaces is compact (Chapter 8's setting).

    Compactness survives infinite products — a fact equivalent to AC itself.

    Sketch: use Zorn to extend a family of closed sets with the finite intersection property to a maximal such family; maximality forces its projections to converge coordinatewise, and the resulting point lies in every member. Kelley showed the converse: Tychonoff implies AC. \(\blacksquare\)

  • Banach–Tarski paradox: a solid ball can be cut into five pieces and reassembled into two identical balls (with AC).

    The pieces are so shredded they have no volume at all — which is exactly why nothing is conserved. Chapter 11 explains why this is a statement about measurability, not about oranges.

    Sketch: the free group on two generators acts on the sphere by rotations. AC picks one point from each orbit, and the group's paradoxical decomposition transfers to a decomposition of the sphere into finitely many non-measurable pieces which can be rotated to cover it twice. Cones to the centre extend this to the solid ball. \(\blacksquare\)

  • Independence of AC and CH: ZF cannot prove or refute AC; ZFC cannot prove or refute CH.

    Like the parallel postulate: assume it or deny it, and you get a different — equally legal — mathematical world.

    Sketch: Gödel (1938–40) built the constructible universe \(L\), an inner model of ZF satisfying AC and CH, so neither can be refuted. Cohen (1963) invented forcing, adjoining generic sets to a model to make AC fail (in a permutation/symmetric submodel) or to add \(\aleph_2\) new reals so that CH fails. Both halves assume only that ZF is consistent. \(\blacksquare\)

Methods

  • Zorn's lemma — to conjure a maximal object: check every chain has an upper bound.

    The bound is almost always "the union of the chain". Bases, maximal ideals and extensions all come this way.

  • Well-order and recurse — line the set up, then build along it transfinitely.

    How you construct pathological objects — including Chapter 11's non-measurable set.

  • Track your choices — note when a proof needs AC, countable choice, or none.

    Good hygiene: many analysis results need only countable choice, and it's worth knowing which.
