The Rules of the Game

Before there are numbers, or sets, or space, there are statements and the rules for getting from one to the next.

Logic is that rulebook. It says what a claim is, when an argument is valid, and exactly which moves count as a proof.

Everything later in this book — every theorem about distance, volume and dimension — is assembled with the seven layers below and nothing else.

Layer 1 · Ground floor

Propositional Logic

Statements, and the rules for combining them.

Concepts & Definitions

  • Proposition — a statement that is either true (T) or false (F), never both, never neither.

    "It is raining" is a proposition. "Close the door!" is not — it can't be true or false.

  • Truth value — the T or F carried by a proposition.

    A light switch has two positions and no third. So does every statement in this book.

  • Propositional variable \(p, q, r\) — a letter standing in for any proposition.

    Like using \(x\) for "some number", \(p\) means "some statement" — the rules work whatever you plug in.

  • Negation \(\neg p\) — "not \(p\)"; flips the truth value.

    \(p\) = "I'm hungry" \(\Rightarrow\) \(\neg p\) = "I'm not hungry."

  • Conjunction \(p \land q\) — "\(p\) and \(q\)"; true only when both are.

    "It's cold and wet" — true only if both parts are true.

  • Disjunction \(p \lor q\) — "\(p\) or \(q\)", inclusive; true when at least one is.

    "I'll have tea or coffee" — true if you have either one, or both.

  • Exclusive or \(p \oplus q\) — "one or the other, but not both".

    "Soup or salad with your meal" — the waiter means one, not both.

  • Implication \(p \to q\) — "if \(p\) then \(q\)"; false only when \(p\) is true and \(q\) is false.

    "If it rains, the ground gets wet." Only one case breaks the promise: it rains, but the ground stays dry.

  • Antecedent & consequent — in \(p \to q\), the \(p\) is the antecedent (the "if" part), \(q\) the consequent.

    "If you're 18, you can vote": being 18 is the antecedent, voting the consequent.

  • Biconditional \(p \leftrightarrow q\) — "\(p\) if and only if \(q\)" (iff); true when they match.

    "You pass iff you score at least 50." Both happen together, or neither does.

  • NAND \(p \uparrow q\) — "not both"; \(\neg(p \land q)\).

    A two-key safe wired so the alarm sounds unless both keys turn together.

  • NOR \(p \downarrow q\) — "neither"; \(\neg(p \lor q)\).

    "Neither raining nor windy" — true only on the calm, dry day.

  • Well-formed formula — a string built legally from variables, connectives and brackets.

    \((p \land q) \to r\) is legal. "\(p \land \to q\)" is gibberish, like "\(2 + \times\; 3\)".

  • Precedence — \(\neg\) binds tightest, then \(\land\), then \(\lor\), then \(\to\), then \(\leftrightarrow\).

    Same idea as \(\times\) before \(+\): \(\neg p \land q\) means \((\neg p) \land q\), not \(\neg(p \land q)\).

  • Truth table — a table listing the truth value for every combination of inputs.

    For \(p \land q\): \(\text{TT}\mapsto\text{T}\), \(\text{TF}\mapsto\text{F}\), \(\text{FT}\mapsto\text{F}\), \(\text{FF}\mapsto\text{F}\). Four rows, no case forgotten.

  • Tautology — a formula true in every row.

    "Tomorrow it will rain or it won't." Guaranteed true — and tells you nothing.

  • Contradiction — false in every row.

    "I'm taller than you and you're taller than me." Can't both hold.

  • Contingency — true in some rows, false in others.

    "It's raining" — depends on the day. Most real statements are like this.

  • Satisfiable — true in at least one row.

    A puzzle with at least one solution. A contradiction is the puzzle with none.

  • Logical equivalence \(p \equiv q\) — same truth value in every row.

    "It's not the case that it's not raining" \(\equiv\) "it's raining". Different words, same claim.

  • Converse, inverse, contrapositive — of \(p \to q\): converse \(q \to p\), inverse \(\neg p \to \neg q\), contrapositive \(\neg q \to \neg p\).

    "If it's a dog, it's an animal." Converse: "if animal, then dog" — false. Contrapositive: "if not an animal, not a dog" — always true.

  • Literal, clause — a literal is \(p\) or \(\neg p\); a clause is an \(\lor\) of literals.

    Ingredients and recipes: \(\neg p\) is an ingredient, \((p \lor \neg q \lor r)\) a small recipe made of three.

  • Conjunctive normal form (CNF) — an \(\land\) of clauses.

    A checklist of requirements: "(coffee or tea) and (cake or pie) and (not shouting)".

  • Disjunctive normal form (DNF) — an \(\lor\) of \(\land\)-blocks.

    A list of acceptable full orders: "coffee-and-cake, or tea-and-pie".

  • Dual of a formula — swap \(\land \leftrightarrow \lor\) and T \(\leftrightarrow\) F.

    Photo negative: every "and" becomes "or", every true becomes false — and the laws still line up.

  • Functionally complete set — a set of connectives that can express every truth table.

    Like a set of Lego bricks that can build any shape. \(\{\neg, \land, \lor\}\) is such a set — and so is \(\{\uparrow\}\) alone.

Theorems — The Laws of Logic

  • Double negation: \(\neg\neg p \equiv p\).

    "I'm not not going" = "I'm going."

    Truth table: if \(p\) is T then \(\neg p\) is F, so \(\neg\neg p\) is T; if \(p\) is F then \(\neg p\) is T and \(\neg\neg p\) is F. The columns for \(p\) and \(\neg\neg p\) agree in both rows. \(\blacksquare\)

  • De Morgan's laws: \(\neg(p \land q) \equiv \neg p \lor \neg q\) and \(\neg(p \lor q) \equiv \neg p \land \neg q\).

    "He's not rich-and-famous" = "he's not rich, or not famous (or neither)."

    \(\neg(p \land q)\) is F exactly when \(p \land q\) is T, i.e. when \(p\) and \(q\) are both T. And \(\neg p \lor \neg q\) is F exactly when \(\neg p, \neg q\) are both F — again when \(p, q\) are both T. Same single F-row out of four, so the columns agree. Applying this to \(\neg p, \neg q\) and cancelling double negations gives the second law. \(\blacksquare\)

  • Commutativity: \(p \land q \equiv q \land p\); \(p \lor q \equiv q \lor p\).

    "Cold and wet" = "wet and cold."

    \(p \land q\) is T exactly when both letters are T — a condition symmetric in the two letters — so its column equals that of \(q \land p\) row by row. Likewise "at least one is T" is symmetric, giving the \(\lor\) case. \(\blacksquare\)

  • Associativity: \((p \land q) \land r \equiv p \land (q \land r)\); same for \(\lor\).

    "(Cold and wet) and windy" = "cold and (wet and windy)" — grouping doesn't matter.

    Each side is T exactly when all three of \(p, q, r\) are T; the brackets never enter that condition. Dually each \(\lor\)-side is T iff at least one is T. All 8 rows agree. \(\blacksquare\)

  • Distributivity: \(p \land (q \lor r) \equiv (p \land q) \lor (p \land r)\), and \(\lor\) over \(\land\) likewise.

    "Coffee, with cake or pie" = "coffee-and-cake, or coffee-and-pie."

    The left side is T iff \(p\) is T and at least one of \(q, r\) is T. The right side is T iff (\(p\) and \(q\)) or (\(p\) and \(r\)) — the same condition. The dual law follows by taking duals, or by the same 8-row check. \(\blacksquare\)

  • Idempotence: \(p \land p \equiv p \equiv p \lor p\).

    "It's raining and it's raining" — saying it twice adds nothing.

    Two rows only: \(p =\) T gives \(p \land p =\) T and \(p \lor p =\) T; \(p =\) F gives F for both. Identical columns. \(\blacksquare\)

  • Absorption: \(p \lor (p \land q) \equiv p\) and \(p \land (p \lor q) \equiv p\).

    "It's raining, or it's raining-and-cold" boils down to "it's raining."

    If \(p\) is T, the first disjunct already makes \(p \lor (p \land q)\) T, matching \(p\). If \(p\) is F then \(p \land q\) is F too, so the whole is F — again matching \(p\). The second law is its dual. \(\blacksquare\)

  • Identity & domination: \(p \land \text{T} \equiv p\), \(p \lor \text{F} \equiv p\), \(p \lor \text{T} \equiv \text{T}\), \(p \land \text{F} \equiv \text{F}\).

    Adding "and the sky exists" changes nothing; adding "or 1=1" makes any claim true.

    \(p \land \text{T}\) is T iff \(p\) is T; \(p \lor \text{F}\) is T iff \(p\) is T — both columns are \(p\)'s. \(p \lor \text{T}\) has a T disjunct in every row, so it is T throughout; \(p \land \text{F}\) has an F conjunct in every row, so it is F throughout. \(\blacksquare\)

  • Excluded middle: \(p \lor \neg p\) is a tautology.

    "The light is on, or it isn't." No third option.

    Two rows exist. \(p =\) T makes the first disjunct T; \(p =\) F makes \(\neg p\) T. Either way the disjunction is T. \(\blacksquare\)

  • Non-contradiction: \(\neg(p \land \neg p)\) is a tautology.

    The light can't be on and off at the same moment.

    In both rows one of \(p, \neg p\) is F, so \(p \land \neg p\) is always F; its negation is therefore always T. \(\blacksquare\)

  • Implication as disjunction: \((p \to q) \equiv (\neg p \lor q)\).

    "If it rains, I stay home" = "it doesn't rain, or I stay home."

    \(p \to q\) is F only at \(p =\) T, \(q =\) F. And \(\neg p \lor q\) is F only when \(\neg p\) and \(q\) are both F — the very same row. Columns match. \(\blacksquare\)

  • Negated implication: \(\neg(p \to q) \equiv p \land \neg q\).

    To break "if you pay, you get in", you need exactly this: you paid and you didn't get in.

    By the previous law \(p \to q \equiv \neg p \lor q\); negate and apply De Morgan: \(\neg(\neg p \lor q) \equiv \neg\neg p \land \neg q \equiv p \land \neg q\). \(\blacksquare\)

  • Contrapositive law: \((p \to q) \equiv (\neg q \to \neg p)\).

    "Dog \(\to\) animal" says exactly the same as "not animal \(\to\) not dog."

    \(p \to q \equiv \neg p \lor q\) and \(\neg q \to \neg p \equiv \neg\neg q \lor \neg p \equiv q \lor \neg p\). Commutativity of \(\lor\) makes these the same formula. \(\blacksquare\)

  • Exportation: \(\bigl((p \land q) \to r\bigr) \equiv \bigl(p \to (q \to r)\bigr)\).

    "If you have a ticket and ID, you may board" = "if you have a ticket, then if you have ID, you may board."

    Both sides are F exactly when \(p, q\) are T and \(r\) is F: the left fails when \(p \land q\) is T with \(r\) F; the right fails when \(p\) is T and \(q \to r\) is F, i.e. \(q\) T and \(r\) F. Same single failing row. \(\blacksquare\)

  • Biconditional split: \((p \leftrightarrow q) \equiv (p \to q) \land (q \to p)\).

    "Iff" is two promises in one: each side guarantees the other.

    \(p \leftrightarrow q\) is T iff \(p, q\) agree. If they agree, neither implication has a T-antecedent-with-F-consequent, so the conjunction is T. If they disagree, exactly one implication fails, so the conjunction is F. \(\blacksquare\)

  • Exclusive or: \((p \oplus q) \equiv (p \lor q) \land \neg(p \land q) \equiv \neg(p \leftrightarrow q)\).

    "Soup or salad, not both" = "at least one, and not both" = "they differ".

    All three are T exactly in the two rows where \(p\) and \(q\) differ: at least one T rules out FF, "not both" rules out TT, and "\(\neg(p \leftrightarrow q)\)" says precisely that they disagree. \(\blacksquare\)

  • Duality principle: if \(\varphi \equiv \psi\) then their duals are equivalent.

    Every law comes in a matched pair — prove one, and its mirror image is free.

    De Morgan gives \(\neg\varphi(p_1,\dots) \equiv \varphi^{d}(\neg p_1,\dots)\), where \(\varphi^{d}\) is the dual: pushing \(\neg\) inward swaps \(\land\) with \(\lor\) and T with F. If \(\varphi \equiv \psi\) then \(\neg\varphi \equiv \neg\psi\), hence \(\varphi^d(\neg p_i) \equiv \psi^d(\neg p_i)\) for all inputs; since \(p \mapsto \neg p\) is a bijection on truth values, \(\varphi^d \equiv \psi^d\). \(\blacksquare\)

  • Normal form theorem: every formula is equivalent to one in CNF and to one in DNF.

    Any tangle of ands, ors and nots can be flattened into a plain checklist — or a plain menu of allowed cases.

    Read the truth table. For DNF: take each T-row and form the \(\land\)-block that pins every variable to its value in that row (\(p\) if T, \(\neg p\) if F); the \(\lor\) of those blocks is T exactly on the T-rows. For CNF: do the same with the F-rows and negate, or dually build one clause per F-row. Either construction matches the original column for column. \(\blacksquare\)

  • Functional completeness: \(\{\neg, \land, \lor\}\) expresses every truth table; so do \(\{\neg, \land\}\), \(\{\neg, \to\}\), \(\{\uparrow\}\) and \(\{\downarrow\}\).

    Every computer chip is built from NAND gates alone — one brick, all of logic.

    DNF (previous theorem) already writes any table with \(\neg, \land, \lor\). Then \(p \lor q \equiv \neg(\neg p \land \neg q)\) removes \(\lor\), and \(p \land q \equiv \neg(p \to \neg q)\) converts to \(\{\neg,\to\}\). Finally \(\neg p \equiv p \uparrow p\) and \(p \land q \equiv (p \uparrow q) \uparrow (p \uparrow q)\) reduce everything to NAND; the NOR case is dual. \(\blacksquare\)

Methods

  • Truth-table check — verify an equivalence or a tautology by listing all \(2^n\) rows.

    Two variables: 4 rows. Three: 8. Tedious, but it never lies and never needs cleverness.

  • Shortcut refutation — to disprove a tautology claim, try to make the formula false and see if you can.

    Assume the conclusion is F and work backwards. If you reach a consistent row, that row is your counterexample; if every attempt collapses, it's a tautology.

  • Normal-form conversion — push negations inward with De Morgan, then distribute to reach CNF or DNF.

    The way a solver eats a puzzle: rewrite everything as one long checklist of clauses first.

  • Logic gates — read \(\land, \lor, \neg\) as AND, OR, NOT circuits.

    A doorbell that rings when (button pressed) AND NOT (silent mode) is a two-gate proposition.

Layer 2 · The machinery

Formal Deduction

Turning "obviously true" into a chain of legal moves.

Concepts & Definitions

  • Formal system — a language, a set of axioms, and rules for producing new formulas from old.

    Chess: a board, a starting position, and legal moves. Which positions can you reach?

  • Axiom schema — a template that becomes an axiom for any formulas substituted in.

    One rubber stamp, infinitely many stamped documents — substitute anything for \(p\) and \(q\).

  • Inference rule — a licence to write a new line given earlier lines.

    "You may move a pawn forward one square" — a rule about moves, not about the board's truth.

  • Derivation (proof) — a finite list of formulas, each an axiom, an assumption, or a rule applied to earlier lines.

    A recipe you can check step by step without ever tasting the food.

  • Syntactic consequence \(\Gamma \vdash \varphi\) — there is a derivation of \(\varphi\) from the assumptions \(\Gamma\).

    "Reachable by legal moves" — a claim about paper, not about the world.

  • Semantic consequence \(\Gamma \models \varphi\) — every row making all of \(\Gamma\) true also makes \(\varphi\) true.

    "True in every possible world where the assumptions hold" — a claim about meaning.

  • Theorem \(\vdash \varphi\) — derivable from the axioms with no extra assumptions.

    A chess position reachable from the opening with no help from your opponent.

  • Consistency — no formula and its negation are both derivable.

    A rulebook that never lets you prove both "the door is locked" and "the door is unlocked".

  • Soundness — everything derivable is true; \(\vdash\) never overreaches \(\models\).

    The machine never prints a falsehood.

  • Completeness — everything true is derivable; \(\models\) never outruns \(\vdash\).

    The machine eventually prints every truth. Sound + complete = the paper and the world agree exactly.

  • Decidability — an algorithm that answers "is this a theorem?" in finite time, always.

    A vending machine that always returns a yes or no, never spins forever.

  • Hilbert system — many axiom schemas, one rule (modus ponens).

    Long proofs, tiny rulebook — easy to reason about, painful to reason in.

  • Natural deduction — no axioms, but introduction and elimination rules for each connective.

    How people actually argue: "assume this… therefore that… so, discharging the assumption, if-this-then-that."

  • Assumption & discharge — temporarily suppose \(p\), derive \(q\), then conclude \(p \to q\) and drop the supposition.

    "Suppose I miss the train" — you reason inside that world, then step out with a conditional in hand.

Axioms

  • A1: \(p \to (q \to p)\) — a truth stays true whatever else you assume.

    "\(2+2=4\)" is true. So "if pigs fly, then \(2+2=4\)" is also true — extra assumptions can't break a truth.

  • A2: \(\bigl(p \to (q \to r)\bigr) \to \bigl((p \to q) \to (p \to r)\bigr)\) — lets you re-wire chained if-thens.

    The bookkeeping rule for nested "if…then"s: it distributes one assumption across a whole chain.

  • A3: \((\neg q \to \neg p) \to (p \to q)\) — contrapositive reasoning is legal.

    Prove "no smoke \(\to\) no fire", and you've proven "fire \(\to\) smoke."

The One Inference Rule

  • Modus ponens — from \(p\) and \(p \to q\), conclude \(q\).

    "If it rains, streets get wet. It's raining. Therefore: streets are wet."

Theorems — Derived Rules

  • Deduction theorem: \(\Gamma \cup \{p\} \vdash q\) if and only if \(\Gamma \vdash p \to q\).

    Formal permission for "suppose…, therefore…". Every conditional proof you've ever written leans on this.

    (\(\Leftarrow\)) From \(\Gamma \vdash p \to q\) and the assumption \(p\), modus ponens gives \(q\). (\(\Rightarrow\)) Induct on the length of the derivation of \(q\). If \(q\) is an axiom or lies in \(\Gamma\), then A1 gives \(q \to (p \to q)\) and modus ponens yields \(p \to q\). If \(q\) is \(p\) itself, \(\vdash p \to p\) is a theorem (below). If \(q\) came by modus ponens from \(r\) and \(r \to q\), the induction hypothesis gives \(\Gamma \vdash p \to r\) and \(\Gamma \vdash p \to (r \to q)\); A2 plus two applications of modus ponens deliver \(\Gamma \vdash p \to q\). \(\blacksquare\)

  • Identity: \(\vdash p \to p\).

    The most boring true thing — but it has to be earned from the three axioms, not assumed.

    Instantiate A2 with \(q := (p \to p)\) and \(r := p\): \(\bigl(p \to ((p\to p) \to p)\bigr) \to \bigl((p \to (p \to p)) \to (p \to p)\bigr)\). Its antecedent is A1 with \(q := (p\to p)\), so modus ponens leaves \((p \to (p\to p)) \to (p \to p)\). The remaining antecedent is A1 again, so a second modus ponens gives \(p \to p\). \(\blacksquare\)

  • Modus tollens: from \(p \to q\) and \(\neg q\), conclude \(\neg p\).

    "If it rained, the ground would be wet. The ground is dry. So it didn't rain."

    By the contrapositive law, \(p \to q \equiv \neg q \to \neg p\). From \(\neg q\) and \(\neg q \to \neg p\), modus ponens gives \(\neg p\). \(\blacksquare\)

  • Hypothetical syllogism: from \(p \to q\) and \(q \to r\), conclude \(p \to r\).

    "Rain \(\to\) wet roads. Wet roads \(\to\) slippery. Therefore rain \(\to\) slippery."

    Assume \(p\). Modus ponens with \(p \to q\) gives \(q\); modus ponens with \(q \to r\) gives \(r\). Discharging the assumption by the deduction theorem yields \(p \to r\). \(\blacksquare\)

  • Disjunctive syllogism: from \(p \lor q\) and \(\neg p\), conclude \(q\).

    "The keys are in my coat or on the table. Not in my coat. So: on the table."

    \(p \lor q \equiv \neg p \to q\) (implication as disjunction, with \(\neg\neg p \equiv p\)). Modus ponens with \(\neg p\) gives \(q\). \(\blacksquare\)

  • Constructive dilemma: from \(p \to r\), \(q \to r\) and \(p \lor q\), conclude \(r\).

    "Rain or shine, the match is on." You needn't know which — the conclusion is the same either way.

    Suppose \(\neg r\). Modus tollens on \(p \to r\) gives \(\neg p\); disjunctive syllogism with \(p \lor q\) gives \(q\); modus ponens on \(q \to r\) gives \(r\) — contradicting \(\neg r\). Hence \(r\). \(\blacksquare\)

  • Resolution: from \(p \lor q\) and \(\neg p \lor r\), conclude \(q \lor r\).

    The single rule automated provers run on: cancel a letter against its negation and merge what's left.

    Take any row. Either \(p\) is T or F. If T, then \(\neg p\) is F, so \(\neg p \lor r\) forces \(r\); if F, then \(p \lor q\) forces \(q\). Either way \(q \lor r\) is T in every row where both premises are. \(\blacksquare\)

  • Simplification & conjunction: from \(p \land q\) conclude \(p\); from \(p\) and \(q\) conclude \(p \land q\).

    Unpack a pair, or pack two facts into one.

    Semantically both are immediate: any row making \(p \land q\) true makes \(p\) true; any row making \(p\) and \(q\) separately true makes \(p \land q\) true. By completeness (below) each is also derivable. \(\blacksquare\)

  • Addition: from \(p\) conclude \(p \lor q\), for any \(q\).

    "I have a cat" \(\Rightarrow\) "I have a cat or a helicopter." Weaker, but true.

    \(p \lor q\) is F only when both are F; a row with \(p\) true is never such a row. \(\blacksquare\)

  • Ex falso quodlibet: from a contradiction, anything follows: \(p \land \neg p \vdash q\).

    One inconsistency and the whole rulebook is worthless — it now proves everything, so it proves nothing useful.

    From \(p \land \neg p\), simplification gives \(p\) and \(\neg p\). Addition on \(p\) gives \(p \lor q\); disjunctive syllogism with \(\neg p\) gives \(q\). \(\blacksquare\)

  • Reductio ad absurdum: if \(\Gamma \cup \{\neg p\}\) is inconsistent, then \(\Gamma \vdash p\).

    Assume the opposite, hit a wall, and the original claim stands.

    Inconsistency gives \(\Gamma \cup \{\neg p\} \vdash q\) and \(\vdash \neg q\) for some \(q\). The deduction theorem turns the first into \(\Gamma \vdash \neg p \to q\); contraposition gives \(\Gamma \vdash \neg q \to p\), and modus ponens with \(\neg q\) yields \(p\). \(\blacksquare\)

  • Soundness theorem: if \(\Gamma \vdash \varphi\) then \(\Gamma \models \varphi\).

    The machine never prints a lie: every legal move preserves truth.

    Induct on the derivation. Each axiom schema A1–A3 is a tautology (check its truth table), so it is true in every row. Modus ponens preserves truth: in a row where \(p\) and \(p \to q\) are both T, \(q\) must be T, else \(p \to q\) would be F. Every line of the derivation is therefore true in every row satisfying \(\Gamma\) — in particular the last one. \(\blacksquare\)

  • Completeness theorem (propositional): if \(\Gamma \models \varphi\) then \(\Gamma \vdash \varphi\).

    Nothing true is out of reach: if it holds in every possible world, some finite proof gets there.

    Sketch: it suffices to show every consistent set \(\Gamma\) has a satisfying row (then \(\Gamma \nvdash \varphi\) gives a consistent \(\Gamma \cup \{\neg\varphi\}\), hence a row where \(\Gamma\) holds and \(\varphi\) fails, i.e. \(\Gamma \nmodels \varphi\)). Extend \(\Gamma\) by Lindenbaum's construction — run through all formulas, adding each one whose addition keeps consistency — to a maximal consistent \(\Gamma^{*}\). Setting each variable T exactly when it lies in \(\Gamma^{*}\) satisfies every member of \(\Gamma^{*}\), by induction over connectives using maximality. \(\blacksquare\)

  • Compactness (propositional): a set of formulas is satisfiable iff every finite subset is.

    If every finite handful of demands can be met, the whole infinite list can be met at once.

    One direction is trivial. For the other: if \(\Gamma\) is unsatisfiable then \(\Gamma \models \bot\), so by completeness \(\Gamma \vdash \bot\). A derivation is a finite list, so it uses only finitely many members of \(\Gamma\); that finite subset already proves \(\bot\) and is therefore unsatisfiable by soundness. \(\blacksquare\)

  • Decidability (propositional): whether a propositional formula is a tautology is decidable.

    Just build the table. Finitely many rows, so the answer always arrives — eventually.

    A formula with \(n\) variables has exactly \(2^{n}\) rows. Evaluating each row takes finitely many steps, and by soundness plus completeness "tautology" coincides with "theorem". So the table-building algorithm terminates and answers correctly. \(\blacksquare\)

Methods

  • Conditional proof — assume the antecedent, derive the consequent, discharge.

    "Suppose \(n\) is even… then \(n^2\) is even. Hence: if \(n\) is even, \(n^2\) is even."

  • Resolution refutation — negate the goal, convert everything to CNF, resolve until the empty clause appears.

    How a computer proves things: it doesn't find the truth, it shows the opposite explodes.

  • Natural-deduction bookkeeping — introduce and eliminate one connective at a time.

    To prove "A and B", prove A, prove B, staple. To use "A or B", handle both cases.

Layer 3 · Reaching inside

Predicates & Quantifiers

Talking about all and some, not just this and that.

Concepts & Definitions

  • Predicate \(P(x)\) — a statement with a slot; it becomes true or false once the slot is filled.

    "\(x\) is left-handed" is neither true nor false until you name someone.

  • Arity — how many slots a predicate has: \(P(x)\), \(R(x,y)\), \(S(x,y,z)\).

    "is tall" takes one person; "is taller than" takes two.

  • Domain of discourse — the collection the variables range over.

    "Everyone is asleep" is a claim about this house, not the planet. The domain matters.

  • Universal quantifier \(\forall x\,P(x)\) — "\(P\) holds for every \(x\)".

    "All the mugs are clean" — one dirty mug and the claim dies.

  • Existential quantifier \(\exists x\,P(x)\) — "\(P\) holds for at least one \(x\)".

    "Some mug is clean" — one clean mug is enough to make it true.

  • Unique existence \(\exists! x\,P(x)\) — exactly one.

    "There's exactly one key that opens this door." One, no more.

  • Bound and free variables — a quantifier binds its variable; unbound ones are free.

    In "\(\forall x\,(x > y)\)", the \(x\) is spoken for, but \(y\) is still an open question waiting for a value.

  • Scope — the part of the formula a quantifier governs.

    Brackets matter: "everyone has a seat" and "there's a seat everyone has" differ only in where the scope ends.

  • Sentence — a formula with no free variables, so it has a definite truth value.

    "\(x\) is asleep" isn't news. "Everyone is asleep" is.

  • Nested quantifiers — \(\forall x \exists y\) vs \(\exists y \forall x\); the order changes the meaning.

    "Everyone has a mother" (true) vs "someone is everyone's mother" (false). Same words, swapped order.

  • Relativised quantifier — \(\forall x (A(x) \to P(x))\) and \(\exists x (A(x) \land P(x))\).

    "All dogs bark" is really "for every thing: if it's a dog, it barks". Note \(\to\) for "all", \(\land\) for "some" — swapping them is the classic blunder.

  • Vacuous truth — \(\forall x \in \varnothing\, P(x)\) is true, whatever \(P\) says.

    "Every unicorn in my kitchen is purple" — true, because there are none to check.

  • Counterexample — one \(x\) with \(\neg P(x)\), which kills \(\forall x\,P(x)\).

    "All swans are white" needed exactly one black swan.

  • Witness — one \(x\) with \(P(x)\), which establishes \(\exists x\, P(x)\).

    To prove "some student passed", produce one passing student.

  • Substitution \(\varphi[t/x]\) — replace free \(x\) by the term \(t\), avoiding capture.

    Rename first if the new name is already taken — otherwise your \(y\) gets swallowed by someone else's \(\forall y\).

Inference Rules for Quantifiers

  • Universal instantiation — from \(\forall x\, P(x)\), conclude \(P(c)\) for any \(c\) in the domain.

    "All mugs are clean. This is a mug. So this mug is clean."

  • Universal generalisation — if \(P(c)\) is proved for an arbitrary \(c\), conclude \(\forall x\, P(x)\).

    "Take any triangle — call it \(T\)…" and if you never used anything special about \(T\), you've proved it for all.

  • Existential generalisation — from \(P(c)\), conclude \(\exists x\, P(x)\).

    You found one clean mug, so "some mug is clean" is settled.

  • Existential instantiation — from \(\exists x\, P(x)\), name a fresh \(c\) with \(P(c)\).

    "Someone left this note — call them \(c\)." The name must be brand new, or you'd smuggle in facts about a known person.

Theorems — Quantifier Laws

  • Quantifier negation: \(\neg\forall x\, P(x) \equiv \exists x\, \neg P(x)\) and \(\neg \exists x\, P(x) \equiv \forall x\, \neg P(x)\).

    "Not everyone came" = "someone didn't". "Nobody came" = "everyone didn't".

    \(\forall x\,P(x)\) is false in a structure exactly when some element fails \(P\), i.e. exactly when \(\exists x\,\neg P(x)\) holds — so the two formulas have the same truth value in every structure. The second law is the first applied to \(\neg P\), with double negation cancelled. (For finite domains it is literally De Morgan: \(\forall\) is a long \(\land\), \(\exists\) a long \(\lor\).) \(\blacksquare\)

  • Distribution over \(\land\) and \(\lor\): \(\forall x (P \land Q) \equiv \forall x P \land \forall x Q\); \(\exists x (P \lor Q) \equiv \exists x P \lor \exists x Q\).

    "All the mugs are clean and dry" = "all are clean, and all are dry."

    If every element satisfies both \(P\) and \(Q\), then every element satisfies \(P\) and every element satisfies \(Q\), and conversely — so the \(\forall\) law holds. Dually, a witness for \(P \lor Q\) is a witness for \(P\) or a witness for \(Q\), and either kind of witness gives one for \(P \lor Q\). \(\blacksquare\)

  • One-way distribution: \(\forall x P \lor \forall x Q \models \forall x (P \lor Q)\), and \(\exists x (P \land Q) \models \exists x P \land \exists x Q\) — the converses fail.

    Every number is even or odd \(\checkmark\), but it is not the case that all are even or all are odd \(\times\).

    If all elements satisfy \(P\) (or all satisfy \(Q\)) then certainly each satisfies \(P \lor Q\). A single witness of \(P \land Q\) witnesses \(P\) and witnesses \(Q\). For the failures: on the domain \(\{1,2\}\) with \(P = \)"is 1", \(Q = \)"is 2", \(\forall x (P \lor Q)\) is true while neither \(\forall x P\) nor \(\forall x Q\) is; and \(\exists x P \land \exists x Q\) is true while \(\exists x (P \land Q)\) is false. \(\blacksquare\)

  • Quantifier commutation: like quantifiers commute; \(\exists x \forall y\, R \models \forall y \exists x\, R\), never the reverse.

    "Someone loves everyone" \(\Rightarrow\) "everyone is loved by someone". The reverse would make one person love the world.

    Suppose \(\exists x \forall y\, R(x,y)\) and fix such an \(a\), so \(R(a,y)\) holds for every \(y\). Given any \(y\), the element \(a\) witnesses \(\exists x\, R(x,y)\); hence \(\forall y \exists x\, R(x,y)\). For the failure of the converse take the domain \(\mathbb{N}\) with \(R(x,y) := (x > y)\): every \(y\) has some larger \(x\), but no single \(x\) exceeds every \(y\). \(\blacksquare\)

  • Vacuous quantification: if \(x\) is not free in \(\varphi\), then \(\forall x\, \varphi \equiv \varphi \equiv \exists x\, \varphi\) (non-empty domain).

    "For every person, the sky is blue" says only that the sky is blue.

    The truth of \(\varphi\) does not depend on the value assigned to \(x\), so either \(\varphi\) holds for every assignment or for none. In the first case both quantified forms are true, in the second both are false — provided the domain is non-empty, so that "every" and "some" have something to range over. \(\blacksquare\)

  • Renaming bound variables (\(\alpha\)-equivalence): \(\forall x\, P(x) \equiv \forall y\, P(y)\) for a fresh \(y\).

    "Every \(x\) is mortal" and "every \(y\) is mortal" say the same thing — the letter is scaffolding.

    Satisfaction of \(\forall x\,P(x)\) is defined by ranging over all values assigned to the bound slot, and the name of that slot is never consulted. Since \(y\) is fresh, no free occurrence is captured by the rename, so the two formulas are satisfied by exactly the same structures and assignments. \(\blacksquare\)

  • Unique existence unpacked: \(\exists! x\, P(x) \equiv \exists x\bigl(P(x) \land \forall y\,(P(y) \to y = x)\bigr)\).

    "Exactly one key fits" = "this key fits, and any key that fits is this one."

    If exactly one element satisfies \(P\), call it \(a\): then \(P(a)\) holds, and any \(y\) with \(P(y)\) must equal \(a\) — giving the right-hand side. Conversely, the right-hand side supplies an \(a\) with \(P(a)\) (existence) and forces every \(P\)-element to equal \(a\) (uniqueness). \(\blacksquare\)

  • Prenex normal form: every formula is equivalent to one with all quantifiers in front.

    Tidy the sentence so every "for all" and "there exists" lines up at the door, and the plain formula follows behind.

    Rename bound variables so all are distinct (\(\alpha\)-equivalence). Then push quantifiers outward with the equivalences above: \(\neg\forall x\,\varphi \equiv \exists x\,\neg\varphi\), and — when \(x\) is not free in \(\psi\) — \((\forall x\,\varphi) \land \psi \equiv \forall x(\varphi \land \psi)\), \((\forall x \varphi) \to \psi \equiv \exists x(\varphi \to \psi)\), and their duals. Each step strictly reduces the number of connectives sitting above a quantifier, so the process terminates in prenex form. \(\blacksquare\)

Methods

  • Prove \(\forall\) by arbitrary element — "let \(x\) be arbitrary" and never use anything special about it.

    Pick any mug, show it's clean using nothing but "it's a mug".

  • Prove \(\exists\) by exhibiting a witness — hand over one example.

    "There's an even prime." Here: 2. Done.

  • Disprove \(\forall\) by counterexample — one failure is enough.

    "Every prime is odd" dies at 2.

  • Disprove \(\exists\) by proving \(\forall \neg\) — show every candidate fails.

    "No even number above 2 is prime" — because every one has 2 as a factor.

  • Negate a statement mechanically — walk left to right, flipping \(\forall \leftrightarrow \exists\) and negating the tail.

    Negating "\(\forall \varepsilon \exists N \forall n > N: |a_n - L| < \varepsilon\)" gives "\(\exists \varepsilon \forall N \exists n > N: |a_n - L| \ge \varepsilon\)". Pure bookkeeping — and the whole of Chapter 3 runs on it.

Layer 4 · Meaning

First-Order Logic & Models

A language, the worlds it can describe, and the gap between them.

Concepts & Definitions

  • Signature (language) — the chosen constant, function and relation symbols.

    For arithmetic: \(0, 1, +, \times, <\). Nothing else is allowed to appear.

  • Term — a name built from variables, constants and function symbols.

    \(x + (1 \times y)\) is a term. It names something; it doesn't claim anything.

  • Atomic formula — a relation symbol applied to terms, e.g. \(t_1 < t_2\) or \(t_1 = t_2\).

    The smallest complete sentence: "\(2 < 3\)". Everything else is built from these.

  • Structure (model) — a non-empty set plus an actual meaning for every symbol.

    The symbols are a script; a structure is a cast that performs it. \(+\) could mean addition here, and "mix paint" there.

  • Assignment & satisfaction \(\mathcal{M} \models \varphi[a]\) — the structure makes \(\varphi\) true when \(x\) is given the value \(a\).

    Fill in the blanks with real objects, then read the sentence and see if it's true.

  • Theory — a set of sentences, usually the axioms of some subject.

    Group theory is three sentences. Anything satisfying them is a group.

  • Model of a theory — a structure making every sentence of the theory true.

    The integers under \(+\) are a model of the group axioms; the integers under \(\times\) are not.

  • Validity \(\models \varphi\) — true in every structure.

    "Everything equals itself." No cast can perform that badly.

  • Logical consequence \(\Gamma \models \varphi\) — every model of \(\Gamma\) is a model of \(\varphi\).

    If the axioms hold, this holds — in every world, without exception.

  • Elementary equivalence — two structures satisfying exactly the same sentences.

    Two casts giving indistinguishable performances: no line of the script can tell them apart.

  • Isomorphism — a relabelling that matches structures symbol for symbol.

    Same building, different language on the signs. Isomorphic \(\Rightarrow\) elementarily equivalent; not conversely.

  • Cardinality of a model — how many elements the underlying set has.

    A theory can't always control this — as the theorems below show, embarrassingly so.

  • Complete theory — for every sentence, the theory proves it or proves its negation.

    A rulebook with an opinion about everything sayable in its own language.

  • Axiomatisable theory — the axioms form a list a machine can recognise.

    You can hand the axioms to a computer. "All true statements about \(\mathbb{N}\)" is not such a list.

  • Second-order logic — quantifying over properties, not just elements.

    "Every property that holds at 0 and passes from \(n\) to \(n+1\) holds everywhere" — induction, said in one sentence. Powerful, but it loses completeness.

Axioms — Equality

  • Reflexivity: \(\forall x\, (x = x)\).

    Every mug is the same mug as itself. Boring, and required.

  • Substitution (Leibniz): if \(x = y\) then \(\varphi(x) \leftrightarrow \varphi(y)\).

    If Clark Kent is Superman, anything true of one is true of the other.

Theorems — What Models Can and Cannot Do

  • Symmetry & transitivity of equality: \(x = y \to y = x\), and \(x=y \land y=z \to x=z\).

    If the keys are the ones on the table, the ones on the table are the keys.

    For symmetry, apply substitution to \(\varphi(z) := (z = x)\): from \(x=y\) and \(\varphi(x)\) (which is \(x=x\), reflexivity) we get \(\varphi(y)\), i.e. \(y = x\). For transitivity, apply substitution to \(\varphi(z) := (z = w)\) — from \(x=y\) and \(y=z\) rewriting \(y\) as \(x\) inside \(y = z\) gives \(x = z\). \(\blacksquare\)

  • Gödel's completeness theorem: \(\Gamma \models \varphi\) if and only if \(\Gamma \vdash \varphi\), for first-order logic.

    Anything true in every world has a finite, checkable proof. Logic itself is not the bottleneck.

    Sketch: soundness is the easy direction (induct on derivations, as in Layer 2). For the converse it suffices to show every consistent theory has a model. Extend the language with infinitely many new constants and add a Henkin witness \(\exists x\,\varphi(x) \to \varphi(c_\varphi)\) for each existential sentence, keeping consistency; extend to a maximal consistent set. Build a structure whose elements are the closed terms modulo provable equality, interpreting each symbol by itself. Induction on formula complexity shows this structure satisfies exactly the sentences in the maximal set — in particular all of \(\Gamma\). \(\blacksquare\)

  • Compactness theorem: if every finite subset of \(\Gamma\) has a model, so does \(\Gamma\).

    Satisfy every finite handful of demands and you can satisfy them all at once — which is how "infinitely large" objects get conjured up.

    If \(\Gamma\) had no model, then \(\Gamma \models \bot\), so by completeness \(\Gamma \vdash \bot\). A derivation is a finite object and uses only finitely many premises, so some finite \(\Gamma_0 \subseteq \Gamma\) already has \(\Gamma_0 \vdash \bot\); by soundness \(\Gamma_0\) has no model — contradicting the hypothesis. \(\blacksquare\)

  • Corollary — non-standard models: any theory with arbitrarily large finite models has an infinite model.

    Arithmetic cannot rule out extra "infinitely large" numbers hiding beyond every ordinary one.

    Add sentences \(\lambda_n\) saying "there exist at least \(n\) distinct elements", for every \(n\). Any finite subset of \(\Gamma \cup \{\lambda_n\}\) mentions only finitely many \(\lambda_n\), so a sufficiently large finite model of \(\Gamma\) satisfies it. Compactness then gives a model of the whole set, which must be infinite. \(\blacksquare\)

  • Löwenheim–Skolem (downward): a theory with an infinite model has a countable model.

    Set theory itself has a countable model — even though it proves uncountable sets exist. (Skolem's paradox: "uncountable" is judged from inside.)

    Sketch: the Henkin construction in the completeness proof builds its model out of closed terms of a language enlarged by countably many constants; there are only countably many such terms, so the resulting model is countable. Alternatively, take an elementary substructure generated by countably many elements using Skolem functions. \(\blacksquare\)

  • Löwenheim–Skolem (upward): a theory with an infinite model has models of every larger cardinality.

    No first-order theory can pin down "how many things there are", once there are infinitely many.

    Add a fresh constant \(c_i\) for each \(i\) in a set of the desired size, plus the sentences \(c_i \neq c_j\) for \(i \neq j\). Every finite subset mentions finitely many constants and can be satisfied inside the given infinite model by interpreting them as distinct elements. Compactness yields a model of the whole set, which therefore has at least that many elements. \(\blacksquare\)

  • Corollary — no categorical first-order theory of \(\mathbb{N}\): arithmetic has models not isomorphic to \(\mathbb{N}\).

    You can write down the rules of counting, but not a description that only the real counting numbers fit.

    By upward Löwenheim–Skolem the theory of \(\mathbb{N}\) has uncountable models, and \(\mathbb{N}\) is countable, so those cannot be isomorphic to it. (Even countably, compactness applied to \(\{c > \underline{n} : n \in \mathbb{N}\}\) produces a model with an element exceeding every numeral.) \(\blacksquare\)

  • Undecidability of first-order validity (Church–Turing): no algorithm decides whether an arbitrary first-order sentence is valid.

    Proofs can always be checked mechanically. Finding them cannot always be mechanised.

    Sketch: encode the run of a Turing machine as a first-order sentence \(\sigma_M\) whose validity is equivalent to "\(M\) halts on empty input". A decision procedure for validity would then decide the halting problem, which is impossible (Layer 7). Validity is however semi-decidable: by completeness, enumerate all derivations and you will eventually find one if it exists. \(\blacksquare\)

Methods

  • Build a counter-model — to show \(\varphi\) is not a consequence, exhibit one structure where the premises hold and \(\varphi\) fails.

    Two elements and a well-chosen relation usually suffice to kill a false-looking claim.

  • Compactness argument — describe the impossible object with finitely-satisfiable sentences, then let compactness deliver it.

    The standard trick for producing infinite or non-standard objects out of thin air.

  • Formalise, then check — write the claim in symbols before arguing about it.

    "Everyone loves someone" is ambiguous in English and razor-sharp in \(\forall x \exists y\, L(x,y)\).

Layer 5 · The craft

Methods of Proof

Every standard way a mathematician actually gets from assumption to conclusion.

Concepts & Definitions

  • Theorem — a proved statement of importance.

    The headline result. Pythagoras gets one; "2 is even" doesn't.

  • Proposition — a proved statement of ordinary importance.

    Useful, true, not famous. Most of a textbook is propositions.

  • Lemma — a small result proved to serve a larger one.

    The stepladder you build to reach the shelf; sometimes (Zorn's lemma) the ladder outlives the shelf.

  • Corollary — a result that falls out of a theorem with little extra work.

    The change left on the counter after the big purchase.

  • Conjecture — believed but unproved; not a takeaway.

    Goldbach's: every even number above 2 is a sum of two primes. Checked past \(4 \times 10^{18}\), still not proved.

  • Axiom — assumed without proof, the starting point.

    The rules of the game. You may change them, but not skip them.

  • Hypothesis & conclusion — the "if" and the "then" of the statement being proved.

    Always write both down before starting. Half of all stuck proofs are proofs of the wrong statement.

  • Converse error — proving \(q \to p\) when \(p \to q\) was asked.

    "All dogs are animals" doesn't give "all animals are dogs" — and it's the most common slip in a hurry.

  • Circular reasoning — using the conclusion, or something equivalent to it, as a step.

    "The bus is late because it hasn't arrived." True, useless.

Methods — Direct Approaches

  • Direct proof — assume the hypothesis, deduce the conclusion by legal steps.

    \(n\) even means \(n = 2k\), so \(n^2 = 4k^2 = 2(2k^2)\) — even. Straight line, no tricks.

  • Proof by contraposition — prove \(\neg q \to \neg p\) instead of \(p \to q\).

    To show "\(n^2\) even \(\Rightarrow\) \(n\) even", show instead "\(n\) odd \(\Rightarrow\) \(n^2\) odd". Far easier, and logically identical.

  • Proof by contradiction (reductio) — assume \(\neg p\), derive an absurdity, conclude \(p\).

    Suppose \(\sqrt{2} = a/b\) in lowest terms; you find \(a\) and \(b\) are both even. Lowest terms broken — so no such fraction exists.

  • Proof by cases (exhaustion) — split into finitely many possibilities and settle each.

    Every integer is even or odd. Prove it for both, and you've proved it for all.

  • Trivial proof — the conclusion is true regardless of the hypothesis.

    "If it rains, \(1 = 1\)." No work needed on the "if".

  • Vacuous proof — the hypothesis is never satisfied, so the implication holds.

    "Every element of the empty set is purple." Nothing to check, nothing to fail.

  • Biconditional proof — prove both directions of an "iff" separately.

    Two one-way streets make a two-way street. Skip one and you've proved half a theorem.

  • Chain of equivalences — transform the statement by reversible steps until it is obviously true.

    Every step must be an \(\iff\), not a \(\Rightarrow\) — squaring both sides is the classic way to break the chain.

  • Cyclic proof of equivalences — for "(i), (ii), (iii) are equivalent", prove (i)\(\Rightarrow\)(ii)\(\Rightarrow\)(iii)\(\Rightarrow\)(i).

    Three implications instead of six. Chapter 2's Choice–Zorn–Well-ordering cycle is exactly this.

  • Forward–backward method — work forward from the hypothesis and backward from the goal until the two meet.

    Digging a tunnel from both ends. Most real proofs are found this way and written up as if they were found forward.

  • Reduction to a known theorem — massage the problem until an existing result applies.

    Most of mathematics is recognising an old friend wearing a new hat.

Methods — Existence & Uniqueness

  • Constructive existence proof — build the object, or give an algorithm that does.

    "There's a number whose square is 16." Here: 4.

  • Non-constructive existence proof — show that "no such object" leads to absurdity, without producing one.

    Proving somebody in the room shares your birthday, without ever finding out who.

  • Proof by construction — define the object explicitly and verify it has the required properties.

    Chapter 2 builds \(\mathbb{Z}\) out of pairs of naturals and then checks the arithmetic works.

  • Uniqueness proof — assume two objects \(a, b\) both work, then show \(a = b\).

    "Suppose two keys open the door…" and grind until they turn out to be the same key.

  • Counterexample — one instance that kills a universal claim.

    "All primes are odd" — 2. Nothing more is required.

  • Probabilistic method — show a random choice succeeds with positive probability, so a successful one exists.

    If more than zero percent of lottery tickets win, a winning ticket exists — even if you never find it.

  • Averaging argument — some element is at least as good as the average.

    If the class average is 60, somebody scored 60 or more. Guaranteed.

Methods — Counting & Structure

  • Pigeonhole principle — \(n+1\) objects in \(n\) boxes force a shared box.

    13 people, 12 months: two share a birth month. No cleverness, no exceptions.

  • Generalised pigeonhole — \(N\) objects in \(k\) boxes force a box with at least \(\lceil N/k \rceil\).

    100 socks, 3 drawers: one drawer holds at least 34.

  • Double counting — count one set two ways and equate the answers.

    Count handshakes per person, then per handshake: the totals must agree, and an identity pops out.

  • Bijective proof — exhibit a one-to-one pairing to prove two counts are equal.

    Every chair taken, nobody standing: the crowd and the chairs match without counting either.

  • Diagonalisation — build an object differing from every item on a supposed complete list.

    Take everyone's list and answer differently from the \(n\)-th person on the \(n\)-th question. Your answers are on nobody's list.

  • Extremal principle — take the largest, smallest or first object with a property and squeeze it.

    "Take the shortest path…" — if it could be shortened, it wasn't the shortest.

  • Invariant argument — find a quantity no legal move changes, then show the target differs.

    A move always flips two lights at once, so the parity of "lights on" never changes — an odd target is unreachable.

  • Monovariant argument — find a quantity that only ever decreases, so the process must stop.

    Every swap moves the biggest book one shelf left; there are finitely many shelves, so the shuffling ends.

  • Parity argument — track odd/even.

    A knight always moves from a white square to a black one, so it can't return home in an odd number of moves.

  • Symmetry & "without loss of generality" — treat one case, noting the others are relabellings.

    "WLOG \(a \le b\)" — legitimate only when swapping the names really does leave the problem unchanged.

  • Duality — prove one statement, get its mirror image free.

    Layer 1's duality principle: every \(\land\)-law comes with an \(\lor\)-law you never had to prove.

  • Generalisation & specialisation — prove a stronger, cleaner statement, then read off the case you wanted.

    Often the general theorem is easier: the extra letters stop you leaning on accidental features of one case.

  • Computer-assisted exhaustion — reduce to finitely many cases and check them mechanically.

    The four-colour theorem: 1,834 configurations, checked by machine. Still a proof — just not one you can read over coffee.

Theorems — Two Method Guarantees

  • Pigeonhole principle: if \(f : A \to B\) with \(|A| > |B|\) finite, then \(f\) is not injective.

    Ten letters, nine pigeonholes: some hole has two letters. The whole content is that you can't fit ten into nine.

    Suppose \(f\) were injective. Then \(f\) is a bijection from \(A\) onto \(f(A) \subseteq B\), so \(|A| = |f(A)| \le |B|\), contradicting \(|A| > |B|\). Hence some \(b \in B\) has two distinct preimages. For the generalised form: if every one of the \(k\) boxes held fewer than \(\lceil N/k\rceil\) items, the total would be at most \(k(\lceil N/k \rceil - 1) < N\). \(\blacksquare\)

  • Validity of contradiction and contraposition: both methods are logically legitimate.

    Reassurance that the two most-used tricks in the book aren't cheating.

    Contraposition: \((p \to q) \equiv (\neg q \to \neg p)\) by Layer 1, so a proof of one is a proof of the other. Contradiction: if \(\Gamma \cup \{\neg p\}\) proves some \(q\) and \(\neg q\), then by Layer 2's reductio \(\Gamma \vdash p\); semantically, no row satisfies \(\Gamma\) and \(\neg p\) at once, so every row satisfying \(\Gamma\) satisfies \(p\), i.e. \(\Gamma \models p\). \(\blacksquare\)

Layer 6 · Infinitely many cases

Induction & Recursion

Proving and defining over an endless list — one domino at a time. (\(\mathbb{N}\) itself is built in Chapter 2; here we record the shape of the argument.)

Concepts & Definitions

  • Base case — the statement checked at the starting value.

    Tipping the first domino. Skip it and the whole line just stands there.

  • Inductive step — the proof that each case forces the next.

    "Every domino is close enough to knock over the one after it."

  • Inductive hypothesis — the assumed case \(P(n)\) inside the step.

    You're allowed to assume it — that's not circular, because you only use it to reach the next case.

  • Well-ordering — every non-empty set of naturals has a least element.

    Any pile of whole numbers has a smallest one. There's no infinite staircase going down.

  • Recursive definition — define \(f(0)\) outright and \(f(n+1)\) in terms of \(f(n)\).

    \(0! = 1\) and \((n+1)! = (n+1)\cdot n!\). Two lines define infinitely many values.

  • Structural induction — induction over how an object was built rather than over a number.

    Prove something about every legal formula by checking the atoms and each way of gluing formulas together.

  • Infinite descent — no strictly decreasing infinite sequence of naturals exists.

    You can't keep taking a smaller whole number forever — the floor at 0 stops you.

  • Transfinite induction — the same idea run along the ordinals, with an extra limit case.

    Dominoes past the end of the line: at each "after all of these" point you must start the chain again. Chapter 2 has the details.

Axiom

  • Principle of mathematical induction — if \(P(0)\) and \(\forall n\,(P(n) \to P(n+1))\), then \(\forall n\, P(n)\).

    First domino falls, each knocks the next — so they all fall. This is an axiom of \(\mathbb{N}\), not a trick.

Theorems

  • Induction \(\iff\) well-ordering: the two principles are equivalent over the other axioms of \(\mathbb{N}\).

    "Dominoes all fall" and "every pile has a smallest" are the same fact wearing two hats.

    (WO \(\Rightarrow\) Ind) Suppose \(P(0)\) and \(P(n) \to P(n+1)\), but the set \(S\) of counterexamples is non-empty. By well-ordering it has a least element \(m\). Since \(P(0)\) holds, \(m \neq 0\), so \(m = k+1\) for some \(k < m\); by minimality \(P(k)\) holds, and the step gives \(P(k+1) = P(m)\) — contradiction. (Ind \(\Rightarrow\) WO) Let \(S\) be non-empty with no least element, and let \(Q(n)\) say "no element of \(S\) is \(\le n\)". \(Q(0)\) holds (else 0 would be least), and \(Q(n) \Rightarrow Q(n+1)\) (else \(n+1\) would be least). Induction gives \(Q\) everywhere, so \(S\) is empty. \(\blacksquare\)

  • Strong induction: if \(\bigl(\forall k < n\, P(k)\bigr) \to P(n)\) for every \(n\), then \(\forall n\, P(n)\).

    Every domino is knocked over by all the ones before it, not just its neighbour — handy when a case depends on a much earlier one.

    Apply ordinary induction to \(Q(n) := \forall k \le n\, P(k)\). \(Q(0)\) is \(P(0)\), which the hypothesis gives (vacuously, as there is no \(k < 0\)). If \(Q(n)\) holds then \(P(k)\) holds for all \(k \le n\), so the hypothesis applied at \(n+1\) yields \(P(n+1)\), hence \(Q(n+1)\). Ordinary induction gives \(Q(n)\) for all \(n\), and \(P(n)\) follows. \(\blacksquare\)

  • Induction from any base: if \(P(b)\) and \(P(n) \to P(n+1)\) for \(n \ge b\), then \(P(n)\) for all \(n \ge b\).

    "\(2^n > n^2\) for \(n \ge 5\)" — start the dominoes at 5 and ignore the earlier ones, which are false anyway.

    Define \(Q(m) := P(b+m)\). Then \(Q(0) = P(b)\) holds, and \(Q(m) \to Q(m+1)\) is exactly the given step at \(n = b+m \ge b\). Ordinary induction gives \(Q(m)\) for all \(m\), i.e. \(P(n)\) for every \(n \ge b\). \(\blacksquare\)

  • Recursion theorem: given \(a\) and a function \(g\), there is exactly one \(f\) with \(f(0)=a\) and \(f(n+1) = g(n, f(n))\).

    The licence to write "define \(f\) by recursion" — someone had to prove such an \(f\) exists and is unique.

    Existence: call a finite function \(t\) an attempt if its domain is \(\{0,\dots,k\}\), \(t(0)=a\), and \(t(i+1)=g(i,t(i))\) throughout. Induction on \(k\) shows an attempt of each length exists, and induction shows any two attempts agree wherever both are defined. Let \(f\) be the union of all attempts; it is a function, satisfies both clauses, and is defined at every \(n\). Uniqueness: if \(f, f'\) both satisfy the clauses, then \(f(0)=a=f'(0)\), and \(f(n)=f'(n)\) forces \(f(n+1)=g(n,f(n))=g(n,f'(n))=f'(n+1)\); induction gives \(f=f'\). \(\blacksquare\)

  • Structural induction is valid: a property holding of the atoms and preserved by each construction rule holds of every object built.

    How you prove anything about "all formulas" — including the theorems of Layer 1.

    Every constructed object has a finite build history; let \(n\) be its number of construction steps. Strong induction on \(n\): if \(n = 0\) the object is an atom and the base case applies; otherwise it is produced by a rule from objects with fewer steps, which satisfy the property by the inductive hypothesis, so the preservation clause transfers it. \(\blacksquare\)

  • Infinite descent: if every solution yields a strictly smaller one, there are no solutions.

    Fermat's trick: any counterexample would spawn a smaller counterexample forever — impossible among whole numbers.

    Suppose a solution exists. The set of natural numbers arising as "sizes" of solutions is non-empty, so by well-ordering it has a least element \(m\) with a corresponding solution. The hypothesis produces a solution of size strictly less than \(m\), contradicting minimality. Hence no solution exists. \(\blacksquare\)

Methods

  • Ordinary induction — check the base, assume \(P(n)\), prove \(P(n+1)\).

    \(1+2+\cdots+n = \tfrac{n(n+1)}{2}\): true at \(n=1\), and adding \(n+1\) to both sides carries it forward.

  • Strong induction — assume all smaller cases at once.

    "Every \(n \ge 2\) is a product of primes": either \(n\) is prime, or \(n = ab\) with both factors smaller — and you already have them.

  • Minimal counterexample ("minimal criminal") — assume a smallest failure exists and derive an absurdity.

    Well-ordering wearing a disguise; often the shortest way to write an induction.

  • Double induction — induct on two variables, or on their sum.

    For a claim about \(m\) and \(n\), run the argument on \(m+n\) so every step lands in an already-proved case.

  • Definition by recursion — define the first value, then each from the last.

    Fibonacci: \(F_0 = 0\), \(F_1 = 1\), \(F_{n+2} = F_{n+1} + F_n\).

Layer 7 · The ceiling

The Limits of Logic

What no rulebook — however clever — can do.

Concepts & Definitions

  • Effective (computable) procedure — a finite set of instructions a machine can follow without insight.

    A recipe with no step reading "and here, be clever".

  • Turing machine — the standard formal model of such a procedure.

    An endless paper tape, one symbol read at a time, a tiny table of rules. Everything a computer can do, it can do.

  • Church–Turing thesis — "computable" means exactly "computable by a Turing machine". A definition, not a theorem.

    Every honest attempt to define "mechanical" landed on the same class. So the name was settled by agreement.

  • Gödel numbering — coding formulas and proofs as numbers, so a system can talk about itself.

    Number every sentence in the library. Now "sentence 4711 is provable" is a fact about numbers.

  • Recursively enumerable — a set whose members can be listed by a machine, possibly forever.

    You'll eventually see every member on the list — but if something's absent you'll wait forever to find out.

  • \(\omega\)-consistency — a technical strengthening of consistency used in Gödel's original argument.

    The system never proves "something has property \(P\)" while also proving "0 doesn't, 1 doesn't, 2 doesn't…" for every numeral. Rosser later weakened this to plain consistency.

Theorems — Metamathematics

  • Halting problem is undecidable: no program decides whether an arbitrary program halts.

    Ask a "will it finish?" oracle about a program built to do the opposite of whatever the oracle says. The oracle can't exist.

    Suppose \(H(P, x)\) decides whether program \(P\) halts on input \(x\). Define \(D(P)\): if \(H(P,P)\) says "halts", loop forever; otherwise halt. Now run \(D\) on itself. If \(D(D)\) halts, then \(H(D,D)\) said "halts", so \(D\) loops — contradiction. If \(D(D)\) loops, then \(H(D,D)\) said "loops", so \(D\) halts — contradiction. So \(H\) does not exist. \(\blacksquare\)

  • Diagonal (fixed-point) lemma: for any property \(\Phi\) of formulas there is a sentence \(G\) with \(\vdash G \leftrightarrow \Phi(\ulcorner G \urcorner)\).

    Any sentence can be made to talk about itself — the engine behind everything below.

    Sketch: substitution of a numeral into a formula is itself a computable operation on Gödel numbers, so it is representable in arithmetic by some formula \(\mathrm{sub}\). Let \(\theta(x) := \exists y\,(\mathrm{sub}(x,x,y) \land \Phi(y))\) and let \(G := \theta(\ulcorner \theta \urcorner)\). Unwinding the definition, \(G\) is provably equivalent to \(\Phi\) applied to its own Gödel number. \(\blacksquare\)

  • Gödel's first incompleteness theorem: any consistent, effectively axiomatised system containing arithmetic has true statements it cannot prove.

    A sentence engineered to say "I am not provable in this system." If it were provable it would be false; so it is true — and unprovable.

    Sketch: Gödel-number the syntax so that "\(y\) is a proof of \(x\)" is a computable — hence representable — relation, giving a formula \(\mathrm{Prov}(x)\). By the fixed-point lemma choose \(G\) with \(\vdash G \leftrightarrow \neg\mathrm{Prov}(\ulcorner G\urcorner)\). If the system proved \(G\), a proof would exist, so \(\mathrm{Prov}(\ulcorner G \urcorner)\) would be provable, hence \(\neg G\) too — inconsistency. If it proved \(\neg G\), it would prove \(\mathrm{Prov}(\ulcorner G\urcorner)\) while no actual proof exists, contradicting consistency (Rosser's refinement removes the need for \(\omega\)-consistency). So \(G\) is undecided — and, read in the standard model, true. \(\blacksquare\)

  • Gödel's second incompleteness theorem: such a system cannot prove its own consistency.

    A witness vouching "I never lie" proves nothing. Mathematics can't certify its own sanity from the inside.

    Sketch: the whole first-theorem argument can be formalised inside the system, yielding \(\vdash \mathrm{Con} \to G\), where \(\mathrm{Con}\) says "\(0=1\) is not provable". If the system also proved \(\mathrm{Con}\), modus ponens would give \(\vdash G\) — which the first theorem forbids for a consistent system. Hence \(\mathrm{Con}\) is unprovable. \(\blacksquare\)

  • Tarski's undefinability theorem: arithmetical truth cannot be defined inside arithmetic.

    "This sentence is false" isn't just a puzzle — it's a proof that no language can contain its own notion of truth.

    Suppose a formula \(\mathrm{True}(x)\) satisfied \(\mathcal{N} \models \varphi \leftrightarrow \mathrm{True}(\ulcorner\varphi\urcorner)\) for every sentence \(\varphi\). The fixed-point lemma applied to \(\neg\mathrm{True}\) produces \(L\) with \(L \leftrightarrow \neg\mathrm{True}(\ulcorner L \urcorner)\) — the liar sentence. Combining the two equivalences gives \(L \leftrightarrow \neg L\), which is false in \(\mathcal{N}\). So no such formula exists, although "provable" is definable — truth and provability come apart. \(\blacksquare\)

  • Corollary — provability is weaker than truth: no effective list of axioms captures all truths of arithmetic.

    Add the missing sentence as a new axiom and the same argument immediately produces another one. The gap never closes.

    If an effectively axiomatised consistent theory \(T\) proved exactly the true sentences of arithmetic, it would be complete — contradicting the first incompleteness theorem. Adding \(G\) as an axiom yields a new effective, consistent theory, to which the theorem applies again, producing a fresh undecided sentence. \(\blacksquare\)

  • Compactness has a price: no first-order theory has exactly the finite models, nor pins down \(\mathbb{N}\) up to isomorphism.

    First-order logic is complete and provable-in-practice, but it cannot see the difference between the counting numbers and a stretched imitation. You get one or the other, never both.

    If a theory had exactly the finite models, it would have arbitrarily large finite models, so by Layer 4's corollary it would have an infinite model — a contradiction. The \(\mathbb{N}\) claim is Layer 4's non-categoricity corollary. The trade-off is genuine: second-order logic can pin down \(\mathbb{N}\), and correspondingly has no sound, complete, effective proof system. \(\blacksquare\)

Methods

  • Self-reference by diagonalisation — feed a machine or formula its own description.

    One trick, three theorems: Cantor's uncountability, the halting problem, and Gödel's sentence.

  • Reduction — show a new problem is undecidable by turning the halting problem into it.

    "If I could solve yours, I could solve halting. Halting is unsolvable, so yours is too."

  • Arithmetisation — encode syntax as numbers so a theory can reason about its own proofs.

    Turn the rulebook into a number and hand it to the rulebook.
