One Dimension First

\(\mathbb{R}\) is the first space in this book: a set with arithmetic, an order, and — crucially — no gaps.

Every idea in the later chapters is a copy of something here. Distance is \(|x-y|\); volume is length; a limit in \(\mathbb{R}^n\) is \(n\) limits on the line.

Prerequisites: Chapters 1–2. \(\mathbb{Q}\) was built in Chapter 2, Layer 6; here it gets completed and then used.

Layer 1 · Arithmetic and order

Ordered Fields

The rules of \(+\), \(\times\) and \(<\), written down once and for all.

Concepts & Definitions

  • Field — a set with \(+\) and \(\times\) obeying the usual algebra, with \(0 \neq 1\) and inverses for everything except \(0\).

    \(\mathbb{Q}\) and \(\mathbb{R}\) are fields; \(\mathbb{Z}\) is not, because \(2\) has no integer reciprocal.

  • Ordered field — a field with a relation \(<\) compatible with \(+\) and with multiplication by positives.

    You may add the same amount to both sides of an inequality; multiplying by a negative flips it.

  • Positive cone \(P = \{x : x > 0\}\) — closed under \(+\) and \(\times\), and each \(x\) is in \(P\), is \(0\), or has \(-x \in P\).

    Everything is a gain, a loss, or nothing. Two gains make a gain.

  • Absolute value \(|x| = x\) if \(x \ge 0\), else \(-x\).

    Distance from home, ignoring which way you walked.

  • Distance on the line \(d(x,y) = |x-y|\).

    The first metric in this book. Chapter 7 turns its three properties into axioms.

  • Interval — \([a,b]\), \((a,b)\), \([a,b)\), \((a,\infty)\) and the rest.

    Square bracket = endpoint included. That one detail decides half the theorems in Layer 5.

  • Bounded set — contained in some \([-M, M]\).

    Fits inside a big enough box. In \(\mathbb{R}^n\) (Chapter 8) this becomes half of compactness.

  • Maximum & minimum — a largest or smallest member of the set itself.

    \((0,1)\) has neither: whatever you nominate, something is closer to the edge.

  • Integer part \(\lfloor x \rfloor\) — the greatest integer \(\le x\).

    \(\lfloor 3.7 \rfloor = 3\), \(\lfloor -3.7 \rfloor = -4\). Rounding down, not towards zero.

Axioms — An Ordered Field

  • Associativity, commutativity, distributivity for \(+\) and \(\times\).

    The bookkeeping everyone learned at school, finally written as assumptions rather than facts.

  • Identities and inverses — \(0\), \(1\), \(-x\), and \(x^{-1}\) for \(x \ne 0\).

    Every debt can be cancelled; every non-zero scaling can be undone.

  • Trichotomy — exactly one of \(x < y\), \(x = y\), \(y < x\).

    Any two prices can be compared, and there's no tie-and-also-cheaper.

  • Compatibility — \(x < y \Rightarrow x + z < y + z\), and \(x < y,\ z > 0 \Rightarrow xz < yz\).

    Give both runners a 10-metre head start and the same one still leads.

Theorems

  • Uniqueness of identities and inverses.

    There is only one zero and only one way to undo \(+5\).

    If \(0\) and \(0'\) are both additive identities, \(0 = 0 + 0' = 0'\). If \(y, y'\) are both inverses of \(x\), then \(y = y + 0 = y + (x + y') = (y+x) + y' = 0 + y' = y'\). The multiplicative cases are identical with \(1\) and \(x^{-1}\). \(\blacksquare\)

  • \(x \cdot 0 = 0\), and \((-x)y = -(xy)\).

    Multiplying by nothing gives nothing — a consequence of distributivity, not a separate rule.

    \(x\cdot 0 = x(0+0) = x\cdot 0 + x \cdot 0\); adding \(-(x\cdot 0)\) to both sides gives \(0 = x \cdot 0\). Then \((-x)y + xy = ((-x)+x)y = 0\cdot y = 0\), so \((-x)y\) is the additive inverse of \(xy\). \(\blacksquare\)

  • No zero divisors: \(xy = 0\) implies \(x = 0\) or \(y = 0\).

    Why "factorise and set each bracket to zero" is legal.

    Suppose \(xy = 0\) and \(x \ne 0\). Multiply by \(x^{-1}\): \(y = 1\cdot y = (x^{-1}x)y = x^{-1}(xy) = x^{-1}\cdot 0 = 0\). \(\blacksquare\)

  • Squares are non-negative: \(x^{2} \ge 0\), and \(1 > 0\).

    Which is why \(\mathbb{C}\) cannot be ordered: \(i^2 = -1\) would have to be \(\ge 0\).

    If \(x > 0\) then \(x\cdot x > 0\) by compatibility. If \(x < 0\) then \(-x > 0\), so \(x^2 = (-x)(-x) > 0\). If \(x = 0\) then \(x^2 = 0\). Taking \(x = 1\) and noting \(1 \ne 0\) gives \(1 = 1^2 > 0\). \(\blacksquare\)

  • Multiplying by a negative reverses the order.

    \(2 < 3\), but \(-2 > -3\). The classic sign slip.

    Let \(x < y\) and \(z < 0\), so \(-z > 0\). Then \(x(-z) < y(-z)\), i.e. \(-xz < -yz\); adding \(xz + yz\) to both sides gives \(yz < xz\). \(\blacksquare\)

  • Triangle inequality: \(|x + y| \le |x| + |y|\).

    A detour is never shorter than going straight. It reappears as an axiom in Chapter 7 and as a theorem in Chapter 6.

    For every \(t\), \(-|t| \le t \le |t|\). Adding the two chains gives \(-(|x|+|y|) \le x + y \le |x|+|y|\), which is exactly \(|x+y| \le |x| + |y|\). \(\blacksquare\)

  • Reverse triangle inequality: \(\bigl||x| - |y|\bigr| \le |x - y|\).

    Two people's distances from home differ by at most the distance between them.

    \(|x| = |(x-y) + y| \le |x-y| + |y|\), so \(|x|-|y| \le |x-y|\). Swapping \(x\) and \(y\) gives \(|y|-|x| \le |x-y|\). Together they bound the absolute value of the difference. \(\blacksquare\)

  • \(|xy| = |x||y|\), and \(|x| < \varepsilon \iff -\varepsilon < x < \varepsilon\).

    The second is the "\(\varepsilon\)-band" reading: \(|x - a| < \varepsilon\) means \(x\) sits within \(\varepsilon\) of \(a\).

    Multiplicativity is a four-case check on the signs of \(x\) and \(y\), each case immediate from \((-x)y = -(xy)\). For the band: if \(|x| < \varepsilon\) then both \(x \le |x| < \varepsilon\) and \(-x \le |x| < \varepsilon\); conversely \(-\varepsilon < x < \varepsilon\) bounds whichever of \(x, -x\) equals \(|x|\). \(\blacksquare\)

  • Bernoulli's inequality: \((1+x)^{n} \ge 1 + nx\) for \(x \ge -1\), \(n \in \mathbb{N}\).

    Compound interest always beats simple interest. Used constantly to force sequences to grow.

    Induction on \(n\). True at \(n=0\). If \((1+x)^n \ge 1+nx\), then since \(1 + x \ge 0\), \((1+x)^{n+1} \ge (1+nx)(1+x) = 1 + (n+1)x + nx^2 \ge 1 + (n+1)x\). \(\blacksquare\)

  • AM–GM (two terms): \(\frac{a+b}{2} \ge \sqrt{ab}\) for \(a, b \ge 0\).

    A rectangle of given perimeter has most area when it's a square.

    \((\sqrt a - \sqrt b)^2 \ge 0\) expands to \(a - 2\sqrt{ab} + b \ge 0\), i.e. \(a + b \ge 2\sqrt{ab}\). Equality exactly when \(\sqrt a = \sqrt b\). \(\blacksquare\)

Methods

  • Prove an inequality by moving everything to one side and recognising a square.

    Nearly every elementary inequality is "\(\text{something}^2 \ge 0\)" in disguise.

  • Case split on signs — handle \(x \ge 0\) and \(x < 0\) separately when absolute values appear.

    Two short cases beat one clever manipulation, and you can't get the sign wrong.

  • The \(\varepsilon\)-band reading — read \(|x - a| < \varepsilon\) as "\(x\) is within \(\varepsilon\) of \(a\)".

    Every limit in this book is a statement about such bands.

Layer 2 · No gaps

Completeness

The single axiom that separates \(\mathbb{R}\) from \(\mathbb{Q}\).

Concepts & Definitions

  • Upper bound — \(M\) with \(x \le M\) for all \(x \in S\).

    A ceiling above the tallest object. There are many; the interesting one is the lowest.

  • Supremum \(\sup S\) — the least upper bound.

    \(\sup (0,1) = 1\), even though \(1\) is not in the set. That's the whole point.

  • Infimum \(\inf S\) — the greatest lower bound.

    The highest floor under everything.

  • Complete ordered field — an ordered field in which every non-empty bounded-above set has a supremum.

    \(\mathbb{Q}\) fails: \(\{x : x^2 < 2\}\) is bounded above but its least bound, \(\sqrt2\), is missing.

  • Dense subset — a set meeting every interval.

    \(\mathbb{Q}\) is dense in \(\mathbb{R}\): however small the window, a fraction is visible in it.

  • Nested intervals — \(I_1 \supseteq I_2 \supseteq \cdots\), each closed and bounded.

    Russian dolls of intervals. Completeness says the innermost point exists.

  • Irrational number — a real that is not rational.

    \(\sqrt2, \pi, e\). They vastly outnumber the fractions (Chapter 2, Layer 7).

  • Decimal expansion — writing \(x\) as \(a_0.a_1a_2a_3\ldots\), i.e. as a limit of finite decimals.

    \(0.999\ldots = 1\) — not "nearly", exactly. The two expressions name the same supremum.

  • Extended reals \(\overline{\mathbb{R}} = \mathbb{R}\cup\{\pm\infty\}\) — a convenience, not a field.

    Lets us write \(\sup S = +\infty\) for unbounded \(S\). Measure theory (Chapter 11) lives here.

Axiom

  • Completeness (least upper bound) axiom — every non-empty subset of \(\mathbb{R}\) with an upper bound has a supremum in \(\mathbb{R}\).

    The line has no holes. Every other theorem in this chapter is this axiom in a costume.

Theorems

  • Characterisation of the supremum: \(s = \sup S\) iff \(s\) is an upper bound and for every \(\varepsilon > 0\) some \(x \in S\) has \(x > s - \varepsilon\).

    Nothing sits above \(s\), and you can always find members as close to \(s\) as you like.

    If \(s = \sup S\) and some \(\varepsilon\) admitted no such \(x\), then \(s - \varepsilon\) would be an upper bound smaller than \(s\) — contradicting leastness. Conversely, if the condition holds, any upper bound \(M < s\) would fail at \(\varepsilon = s - M\), so \(s\) is least. \(\blacksquare\)

  • Infima exist: every non-empty set bounded below has an infimum.

    One axiom buys both ends of the line — just look at the reflection.

    Let \(S\) be bounded below by \(m\) and set \(-S = \{-x : x \in S\}\), which is bounded above by \(-m\). Then \(\sup(-S)\) exists, and \(-\sup(-S)\) is a lower bound for \(S\) greater than every other, i.e. \(\inf S\). \(\blacksquare\)

  • Archimedean property: \(\mathbb{N}\) is unbounded in \(\mathbb{R}\); for every \(x\) there is \(n\) with \(n > x\).

    No real number is bigger than every counting number — so there are no "infinitely large" reals, and no infinitesimals either.

    If \(\mathbb{N}\) were bounded above, it would have a supremum \(s\). Then \(s - 1\) is not an upper bound, so some \(n \in \mathbb{N}\) has \(n > s-1\), whence \(n + 1 > s\) with \(n+1 \in \mathbb{N}\) — contradicting that \(s\) bounds \(\mathbb{N}\). \(\blacksquare\)

  • Corollary: for every \(\varepsilon > 0\) there is \(n\) with \(1/n < \varepsilon\).

    You can always chop a quantity finely enough. Every \(\varepsilon\)-argument in the book uses this line.

    By the Archimedean property choose \(n > 1/\varepsilon > 0\). Multiplying the inequality by \(\varepsilon/n > 0\) gives \(\varepsilon > 1/n\). \(\blacksquare\)

  • Density of \(\mathbb{Q}\): between any two reals lies a rational.

    However fine the gap, a fraction slips in — which is why decimal approximation works at all.

    Let \(x < y\) and pick \(n\) with \(1/n < y - x\). Let \(m = \lfloor nx \rfloor + 1\), so \(m - 1 \le nx < m\). Then \(x < m/n\) and \(m/n \le x + 1/n < x + (y-x) = y\). \(\blacksquare\)

  • Density of the irrationals: between any two reals lies an irrational.

    Both kinds of number are everywhere, arbitrarily finely mixed.

    Apply density of \(\mathbb{Q}\) to \(x/\sqrt2 < y/\sqrt2\), obtaining a rational \(q\) strictly between them with \(q \neq 0\) (shrink the interval if necessary). Then \(q\sqrt2\) lies strictly between \(x\) and \(y\), and is irrational: were \(q\sqrt2 = p \in \mathbb{Q}\), we would get \(\sqrt2 = p/q \in \mathbb{Q}\). \(\blacksquare\)

  • Existence of \(n\)-th roots: every \(a > 0\) has a unique positive \(n\)-th root.

    \(\sqrt2\) exists — the completeness axiom is what puts it on the line.

    Let \(S = \{t > 0 : t^{n} < a\}\), non-empty and bounded above by \(1 + a\), and set \(s = \sup S\). If \(s^n < a\), one checks \((s+\delta)^n < a\) for small \(\delta > 0\) (expand and bound the extra terms), contradicting that \(s\) is an upper bound. If \(s^n > a\), similarly \((s - \delta)^n > a\) for small \(\delta\), making \(s-\delta\) a smaller upper bound. So \(s^n = a\). Uniqueness: \(t \mapsto t^n\) is strictly increasing on \((0,\infty)\). \(\blacksquare\)

  • Nested interval theorem: a nested sequence of closed bounded intervals has a common point.

    Squeeze from both sides forever and something is caught. Fails for open intervals: \(\bigcap (0, 1/n) = \varnothing\).

    Write \(I_k = [a_k, b_k]\) with \(a_k\) increasing and \(b_k\) decreasing. Every \(b_j\) is an upper bound for \(\{a_k\}\), so \(a := \sup_k a_k\) exists and satisfies \(a_k \le a \le b_j\) for all \(k, j\). Hence \(a \in \bigcap_k I_k\). If additionally \(b_k - a_k \to 0\), that point is unique. \(\blacksquare\)

  • Uniqueness of \(\mathbb{R}\): any two complete ordered fields are isomorphic.

    However you build the reals — Dedekind cuts, Cauchy sequences, infinite decimals — you get the same object.

    Sketch: both fields contain a copy of \(\mathbb{Q}\) (generated by \(1\)), and by the Archimedean property — itself a consequence of completeness — that copy is dense. Map each element to the supremum of the rationals below it; the field and order axioms make this map well defined, additive, multiplicative, order-preserving, and bijective by density plus completeness on both sides. \(\blacksquare\)

  • Existence of \(\mathbb{R}\): a complete ordered field exists — e.g. Dedekind cuts of \(\mathbb{Q}\).

    A real number is the set of rationals below it. \(\sqrt2\) is literally "all fractions whose square is under 2".

    Sketch: a cut is a non-empty proper downward-closed \(A \subseteq \mathbb{Q}\) with no greatest element. Order cuts by \(\subseteq\); define \(A + B = \{a+b\}\) and handle multiplication by cases on sign. The field and order axioms are routine checks. Completeness is the punchline: given a non-empty family of cuts bounded above, its union is again a cut, and it is exactly the least upper bound. \(\blacksquare\)

Methods

  • Sup/inf argument — to prove something exists, define it as a supremum and prove the two inequalities.

    How roots, limits, integrals and dimensions all get their existence in this book.

  • Approximate from below — use "\(\exists x \in S,\ x > s - \varepsilon\)".

    The supremum's defining trick, and the source of most \(\varepsilon\)'s.

  • Bisection — halve the interval, keep the half that still works, repeat.

    Builds nested intervals converging on the answer — used again for Bolzano–Weierstrass and the IVT.

Layer 3 · Approaching

Sequences & Limits

What it means to get arbitrarily close, made exact.

Concepts & Definitions

  • Sequence \((a_n)\) — a function \(\mathbb{N}\to\mathbb{R}\).

    An endless numbered list of readings, one per day.

  • Convergence — \(a_n \to L\) means: for every \(\varepsilon > 0\) there is \(N\) with \(|a_n - L| < \varepsilon\) for all \(n > N\).

    Name any tolerance; after some point, every reading is inside it. Chapters 7–9 copy this definition verbatim.

  • Divergence — failing to converge; possibly to \(\pm\infty\), possibly by oscillating.

    \(a_n = n\) runs away; \(a_n = (-1)^n\) just refuses to settle.

  • Bounded sequence — all terms inside some \([-M,M]\).

    Convergent sequences must be bounded; bounded ones need not converge.

  • Monotone sequence — non-decreasing or non-increasing.

    A savings balance that only grows. If it's also capped, it must approach something.

  • Subsequence \((a_{n_k})\) — keep some terms, in order.

    Read only the Monday entries of the diary.

  • Cauchy sequence — terms eventually all within \(\varepsilon\) of each other.

    The crowd bunches up, without you needing to know where. This is the definition that generalises to any metric space.

  • Limit superior & inferior \(\limsup a_n = \lim_{N}\sup_{n>N} a_n\), similarly \(\liminf\).

    The highest and lowest values the sequence keeps returning near. They always exist in \(\overline{\mathbb{R}}\), even when the limit doesn't.

  • Cluster point — a value approached by some subsequence.

    \((-1)^n\) has two: \(+1\) and \(-1\).

  • Euler's number \(e = \lim (1 + 1/n)^{n}\).

    Interest compounded ever more often; the payout tops out at \(e\).

Theorems

  • Limits are unique.

    A sequence can't settle down in two places at once.

    Suppose \(a_n \to L\) and \(a_n \to L'\) with \(L \ne L'\). Put \(\varepsilon = |L - L'|/2 > 0\) and take \(n\) beyond both thresholds. Then \(|L - L'| \le |L - a_n| + |a_n - L'| < 2\varepsilon = |L-L'|\) — impossible. \(\blacksquare\)

  • Convergent \(\Rightarrow\) bounded.

    If the readings settle near 7, they were never at a million.

    Take \(\varepsilon = 1\) and the corresponding \(N\): for \(n > N\), \(|a_n| < |L| + 1\). The finitely many earlier terms have a largest absolute value, so \(M = \max\{|a_1|,\dots,|a_N|, |L|+1\}\) bounds them all. \(\blacksquare\)

  • Algebra of limits: limits respect \(+\), \(-\), \(\times\), and \(\div\) (when the denominator's limit is non-zero).

    You may take limits term by term — the reason nobody computes with \(\varepsilon\)'s in practice.

    For sums: given \(\varepsilon\), choose \(N\) making both \(|a_n - A| < \varepsilon/2\) and \(|b_n - B| < \varepsilon/2\); the triangle inequality gives \(|(a_n+b_n)-(A+B)| < \varepsilon\). For products write \(a_nb_n - AB = a_n(b_n - B) + B(a_n - A)\) and use boundedness of \((a_n)\). For quotients, first show \(1/b_n \to 1/B\) by bounding \(|b_n| \ge |B|/2\) eventually. \(\blacksquare\)

  • Order is preserved: if \(a_n \le b_n\) for all large \(n\), then \(\lim a_n \le \lim b_n\).

    Weak inequalities survive limits; strict ones do not — \(1/n > 0\) but the limit is \(0\).

    Suppose \(A > B\) and put \(\varepsilon = (A-B)/2\). For large \(n\), \(a_n > A - \varepsilon = B + \varepsilon > b_n\), contradicting \(a_n \le b_n\). \(\blacksquare\)

  • Squeeze theorem: \(a_n \le c_n \le b_n\) with \(a_n, b_n \to L\) forces \(c_n \to L\).

    Trapped between two convergent walls, the middle has nowhere else to go.

    Given \(\varepsilon\), take \(N\) beyond both thresholds. Then \(L - \varepsilon < a_n \le c_n \le b_n < L + \varepsilon\), so \(|c_n - L| < \varepsilon\). \(\blacksquare\)

  • Monotone convergence theorem: a bounded monotone sequence converges — to its supremum (or infimum).

    Always rising, never above the ceiling: it must approach the ceiling's lowest position.

    Let \((a_n)\) be non-decreasing and bounded above, and \(s = \sup_n a_n\). Given \(\varepsilon > 0\), some \(a_N > s - \varepsilon\) by the supremum characterisation. Monotonicity gives \(s - \varepsilon < a_N \le a_n \le s\) for all \(n \ge N\), so \(|a_n - s| < \varepsilon\). \(\blacksquare\)

  • Bolzano–Weierstrass: every bounded sequence has a convergent subsequence.

    Infinitely many points in a finite room must pile up somewhere. This is compactness, in its first appearance.

    Bisect the bounding interval and keep a half containing infinitely many terms; repeat. This yields nested intervals of halving length, whose common point is \(L\) by the nested interval theorem. Choosing one term from each interval, with increasing indices, gives a subsequence with \(|a_{n_k} - L| \le\) the \(k\)-th length \(\to 0\). \(\blacksquare\)

  • Convergent \(\iff\) Cauchy in \(\mathbb{R}\).

    You can certify convergence without knowing the limit — the property Chapter 7 promotes to the definition of "complete".

    (\(\Rightarrow\)) If \(a_n \to L\), then \(|a_n - a_m| \le |a_n - L| + |L - a_m| < \varepsilon\) for \(n,m\) large. (\(\Leftarrow\)) A Cauchy sequence is bounded (take \(\varepsilon = 1\)), so Bolzano–Weierstrass gives a subsequence \(a_{n_k} \to L\). Then for large \(n\) and a large chosen \(n_k\), \(|a_n - L| \le |a_n - a_{n_k}| + |a_{n_k} - L| < \varepsilon\). \(\blacksquare\)

  • Subsequences inherit limits: if \(a_n \to L\), every subsequence \(\to L\).

    Reading only Mondays still shows the same trend.

    Since \(n_k \ge k\), any threshold \(N\) for the sequence is also passed by \(n_k\) once \(k > N\), so the same \(\varepsilon\) bound applies. \(\blacksquare\)

  • \(\limsup\) and \(\liminf\) always exist in \(\overline{\mathbb{R}}\), and \(a_n \to L\) iff \(\limsup = \liminf = L\).

    The top and bottom of the eventual band. When they meet, the sequence converges.

    The tail suprema \(s_N = \sup_{n>N}a_n\) form a non-increasing sequence, so they converge in \(\overline{\mathbb{R}}\) by monotone convergence; that limit is \(\limsup a_n\), and dually for \(\liminf\). If both equal \(L\), then for large \(N\) every tail lies in \((L-\varepsilon, L+\varepsilon)\), giving convergence; conversely convergence forces both tail bounds to \(L\). \(\blacksquare\)

  • \(e\) exists: \((1+1/n)^{n}\) is increasing and bounded above by 3.

    Compounding more often always helps a little, but never beyond \(e \approx 2.71828\).

    By the binomial theorem, \((1+1/n)^n = \sum_{k=0}^{n}\binom{n}{k}n^{-k} = \sum_{k=0}^n \frac{1}{k!}\prod_{j<k}(1 - j/n)\). Each factor \(1 - j/n\) increases with \(n\) and a new positive term appears, so the sequence increases; and each term is at most \(1/k! \le 2^{-(k-1)}\), so the sum is under \(1 + \sum_{k\ge1}2^{-(k-1)} = 3\). Monotone convergence finishes. \(\blacksquare\)

Methods

  • The \(\varepsilon\)–\(N\) proof — given \(\varepsilon\), produce \(N\) explicitly.

    Work backwards from \(|a_n - L| < \varepsilon\) to find how big \(n\) must be, then write it forwards.

  • Squeeze — bound the awkward sequence between two easy ones.

    \(|\sin n / n| \le 1/n \to 0\), so the limit is 0 without touching \(\sin\).

  • Monotone + bounded — the standard existence proof for a limit.

    Used for \(e\), for recursively defined sequences, and for the integral in Layer 7.

  • Cauchy criterion — prove convergence without naming the limit.

    Essential when the limit is the thing being constructed.

  • Extract a subsequence — use Bolzano–Weierstrass to get convergence, then identify the limit.

    The standard opening move in compactness arguments throughout Chapters 8–9.

Layer 4 · Infinite sums

Series

Adding infinitely many numbers, carefully.

Concepts & Definitions

  • Series \(\sum_{n=1}^{\infty} a_n\) — the limit of the partial sums \(s_N = \sum_{n\le N}a_n\).

    An infinite sum is not an act of adding; it is a limit of finite additions.

  • Convergent & divergent series — according as \((s_N)\) converges.

    \(1 + \tfrac12 + \tfrac14 + \cdots = 2\). But \(1+1+1+\cdots\) has nowhere to go.

  • Geometric series \(\sum ar^{n}\) — converges iff \(|r| < 1\), to \(\frac{a}{1-r}\).

    Walk half the remaining distance each step: you cover the whole metre and no more.

  • Harmonic series \(\sum 1/n\) — diverges, very slowly.

    Terms shrink to zero, and the total still runs to infinity. The standard warning against wishful thinking.

  • \(p\)-series \(\sum 1/n^{p}\) — converges iff \(p > 1\).

    The reference ruler every comparison test is measured against.

  • Absolute convergence — \(\sum |a_n|\) converges.

    Robust: you may reorder freely, multiply series, and swap sums. Chapter 12's Fubini is the grown-up version.

  • Conditional convergence — converges, but not absolutely.

    \(1 - \tfrac12 + \tfrac13 - \cdots = \ln 2\). Fragile: rearranging it changes the answer.

  • Power series \(\sum c_n (x-a)^{n}\), with a radius of convergence \(R\).

    A polynomial of infinite degree; inside its radius it behaves like one.

Theorems — Convergence Tests

  • Term test: if \(\sum a_n\) converges then \(a_n \to 0\). The converse is false.

    Only ever useful for proving divergence. The harmonic series is why.

    If \(s_N \to s\) then \(a_N = s_N - s_{N-1} \to s - s = 0\). The harmonic series shows the converse fails. \(\blacksquare\)

  • Geometric series formula: \(\sum_{n=0}^{\infty} r^{n} = \frac{1}{1-r}\) for \(|r| < 1\).

    The one closed form everything else is compared to.

    \((1-r)s_N = 1 - r^{N+1}\), so \(s_N = \frac{1-r^{N+1}}{1-r}\). For \(|r| < 1\), \(r^{N+1}\to 0\) (since \(|r|^{N+1} \le \frac{1}{1 + N\delta}\to 0\) by Bernoulli with \(1/|r| = 1+\delta\)), giving the limit. For \(|r|\ge1\) the terms do not tend to 0. \(\blacksquare\)

  • Cauchy criterion for series: \(\sum a_n\) converges iff tails \(\bigl|\sum_{n=m}^{k}a_n\bigr|\) are eventually small.

    The same "bunching up" idea, applied to blocks of terms.

    The partial sums converge iff they are Cauchy (Layer 3), and \(s_k - s_{m-1} = \sum_{n=m}^{k}a_n\). \(\blacksquare\)

  • Comparison test: \(0 \le a_n \le b_n\); then \(\sum b_n\) convergent \(\Rightarrow\) \(\sum a_n\) convergent, and \(\sum a_n\) divergent \(\Rightarrow\) \(\sum b_n\) divergent.

    Smaller than something finite is finite. Bigger than something infinite is infinite.

    With non-negative terms the partial sums are non-decreasing. If \(\sum b_n\) converges, the sums of \(a_n\) are bounded above by \(\sum b_n\), so by monotone convergence they converge. The second statement is the contrapositive. \(\blacksquare\)

  • Integral test: for positive decreasing \(f\), \(\sum f(n)\) converges iff \(\int_1^{\infty} f\) does.

    Compare the staircase of terms with the area under the curve — the fastest proof that \(\sum 1/n\) diverges.

    Since \(f\) decreases, \(f(n+1) \le \int_n^{n+1}f \le f(n)\). Summing from \(1\) to \(N\) gives \(s_{N+1} - f(1) \le \int_1^{N+1}f \le s_N\), so the partial sums and the integrals are bounded in terms of one another; both being monotone, they converge or diverge together. \(\blacksquare\)

  • \(p\)-series: \(\sum 1/n^{p}\) converges exactly for \(p > 1\).

    \(p = 1\) is the exact tipping point — infinitely slowly divergent.

    Apply the integral test to \(f(x) = x^{-p}\): \(\int_1^{M}x^{-p}dx = \frac{M^{1-p}-1}{1-p}\) for \(p\ne1\), which converges as \(M\to\infty\) iff \(p > 1\); and \(\int_1^M x^{-1}dx = \ln M \to \infty\). \(\blacksquare\)

  • Ratio test: if \(\limsup |a_{n+1}/a_n| < 1\) the series converges absolutely; if \(\liminf > 1\) it diverges.

    Terms shrinking geometrically fast: compare with a geometric series and you're done.

    If the \(\limsup\) is \(L < 1\), pick \(r\) with \(L < r < 1\); for \(n \ge N\), \(|a_{n+1}| \le r|a_n|\), so \(|a_n| \le |a_N| r^{n-N}\). Comparison with the convergent geometric series gives absolute convergence. If the ratios eventually exceed 1, the terms do not tend to 0. \(\blacksquare\)

  • Root test: if \(\limsup |a_n|^{1/n} < 1\) it converges absolutely; if \(>1\) it diverges.

    Strictly stronger than the ratio test, and the one that computes the radius of a power series.

    If \(\limsup|a_n|^{1/n} = L < 1\), choose \(L < r < 1\); then \(|a_n| \le r^n\) for all large \(n\), and comparison applies. If \(L > 1\) then \(|a_n| > 1\) infinitely often, so the terms do not tend to 0. \(\blacksquare\)

  • Alternating series test: if \(b_n \downarrow 0\) then \(\sum(-1)^{n}b_n\) converges, with error under the first omitted term.

    Steps alternate direction and shrink: the walk closes in on a point, and you always know how close.

    The even partial sums increase, the odd ones decrease, and every even one is below every odd one; both are monotone and bounded, so both converge, and \(s_{2n+1}-s_{2n} = b_{2n+1}\to0\) forces the limits to coincide. The remainder is trapped between consecutive partial sums, hence bounded by the next term. \(\blacksquare\)

  • Absolute \(\Rightarrow\) convergent.

    Taking absolute values only makes cancellation harder, so if that still converges, the original does.

    \(\bigl|\sum_{n=m}^k a_n\bigr| \le \sum_{n=m}^{k}|a_n|\), so the Cauchy criterion for \(\sum|a_n|\) transfers immediately to \(\sum a_n\). \(\blacksquare\)

  • Riemann rearrangement theorem: a conditionally convergent series can be rearranged to sum to any value, or to diverge.

    Order of addition matters, once cancellation is doing the work. The single best reason to care about absolute convergence.

    Sketch: split into positive and negative parts. Conditional convergence forces both \(\sum a_n^{+}\) and \(\sum a_n^{-}\) to diverge while \(a_n \to 0\). To reach a target \(t\), add positive terms until the running total first exceeds \(t\), then negatives until it drops below, and repeat. Because the terms tend to zero, the overshoot at each turn tends to zero, so the rearranged partial sums converge to \(t\). \(\blacksquare\)

  • Rearrangement is safe when absolute: an absolutely convergent series has the same sum in every order.

    Why you may add up a doubly-indexed family in any order you like — the discrete Fubini.

    Given \(\varepsilon\), choose \(N\) with \(\sum_{n>N}|a_n| < \varepsilon\). Any rearrangement's partial sums eventually include all of \(a_1,\dots,a_N\); beyond that point they differ from \(\sum_{n\le N}a_n\) by at most \(\varepsilon\), as does the original sum. Hence both limits lie within \(2\varepsilon\) of each other for every \(\varepsilon\). \(\blacksquare\)

  • Cauchy product: the product of two absolutely convergent series converges to the product of the sums.

    Multiplying infinite sums works exactly like multiplying polynomials — provided both converge absolutely.

    Let \(c_n = \sum_{k=0}^{n}a_kb_{n-k}\). The double family \((a_ib_j)\) is absolutely summable, since \(\sum_{i,j}|a_ib_j| = (\sum|a_i|)(\sum|b_j|) < \infty\). By the rearrangement theorem for absolutely convergent series, summing it by diagonals (giving \(\sum c_n\)) or by rows (giving \((\sum a_i)(\sum b_j)\)) produces the same value. \(\blacksquare\)

  • Radius of convergence: \(\sum c_n(x-a)^n\) converges absolutely for \(|x-a| < R\) and diverges for \(|x-a| > R\), where \(1/R = \limsup|c_n|^{1/n}\).

    A power series has a disc of health and nothing to say at its rim, where anything can happen.

    Apply the root test to \(a_n = c_n(x-a)^n\): \(\limsup|a_n|^{1/n} = |x-a|\limsup|c_n|^{1/n} = |x-a|/R\). This is \(<1\) exactly when \(|x-a| < R\) and \(>1\) when \(|x-a| > R\). \(\blacksquare\)

Methods

  • Compare with a \(p\)-series or a geometric series — the two reference families.

    Estimate the term's size, match it to \(1/n^p\) or \(r^n\), and quote the test.

  • Test the terms first — if \(a_n \not\to 0\), stop; it diverges.

    Ten seconds of work that saves a page.

  • Telescoping — write \(a_n = b_n - b_{n+1}\) so the sum collapses.

    \(\sum \frac{1}{n(n+1)} = \sum(\frac1n - \frac{1}{n+1}) = 1\).

  • Prove absolute convergence when you can — it licenses reordering and multiplying.

    The difference between a formula you can manipulate and one you must handle with tongs.

Layer 5 · Unbroken

Limits & Continuity of Functions

Functions with no sudden jumps, and what that guarantees.

Concepts & Definitions

  • Limit of a function — \(\lim_{x\to a}f(x) = L\): for all \(\varepsilon > 0\) there is \(\delta > 0\) with \(0 < |x-a| < \delta \Rightarrow |f(x)-L| < \varepsilon\).

    Get the output as close to \(L\) as demanded by keeping the input close enough to \(a\) — without ever using \(a\) itself.

  • One-sided limits \(\lim_{x\to a^{\pm}}\).

    A price that jumps at midnight has one value approaching from before and another from after.

  • Continuity at a point — \(f(a)\) is defined and \(\lim_{x\to a}f(x) = f(a)\).

    The pencil never leaves the paper, and it lands where the function says it should.

  • Continuity on a set — continuous at each of its points.

    Chapter 8 restates this using open sets, and the definition survives into any dimension.

  • Removable, jump, essential discontinuity — the three ways continuity can fail.

    A hole you could plug; a step; and \(\sin(1/x)\), which oscillates forever at the origin.

  • Uniform continuity — one \(\delta\) works for every point at once.

    \(x^2\) on \(\mathbb{R}\) is continuous but not uniformly: far from the origin, tiny input changes cause big output changes.

  • Lipschitz condition — \(|f(x)-f(y)| \le K|x-y|\).

    A speed limit on the graph. Lipschitz \(\Rightarrow\) uniformly continuous, and it powers Chapter 7's fixed-point theorem.

  • Monotone function — order-preserving or order-reversing.

    Monotone functions can only ever have jump discontinuities, and at most countably many.

  • Pointwise vs uniform convergence of a sequence of functions.

    Pointwise: each \(x\) settles eventually. Uniform: the whole graph settles together — and only then is the limit guaranteed continuous.

Theorems

  • Sequential characterisation: \(f\) is continuous at \(a\) iff \(x_n \to a\) implies \(f(x_n)\to f(a)\).

    Turns every continuity question into a sequence question — often much easier.

    (\(\Rightarrow\)) Given \(\varepsilon\), take \(\delta\) from continuity and \(N\) with \(|x_n - a| < \delta\) for \(n > N\); then \(|f(x_n)-f(a)| < \varepsilon\). (\(\Leftarrow\)) If continuity failed, some \(\varepsilon_0\) admits, for each \(n\), a point \(x_n\) with \(|x_n - a| < 1/n\) but \(|f(x_n)-f(a)| \ge \varepsilon_0\). Then \(x_n \to a\) while \(f(x_n)\not\to f(a)\). \(\blacksquare\)

  • Algebra of continuity: sums, products, quotients (non-zero denominator) and compositions of continuous functions are continuous.

    Every polynomial and rational function is continuous where defined — no \(\varepsilon\) required.

    Immediate from the algebra of limits (Layer 3) via the sequential characterisation: if \(x_n \to a\) then \(f(x_n)\to f(a)\) and \(g(x_n)\to g(a)\), so \((f+g)(x_n)\to (f+g)(a)\), and likewise for products and quotients. For composition, \(x_n \to a \Rightarrow g(x_n)\to g(a) \Rightarrow f(g(x_n))\to f(g(a))\). \(\blacksquare\)

  • Intermediate value theorem: a continuous \(f\) on \([a,b]\) attains every value between \(f(a)\) and \(f(b)\).

    Walk from a valley to a peak and you cross every altitude on the way. Chapter 9 generalises it to connected sets.

    Say \(f(a) < c < f(b)\), and let \(S = \{x \in [a,b] : f(x) < c\}\), non-empty and bounded; put \(s = \sup S\). If \(f(s) < c\), continuity keeps \(f < c\) on a neighbourhood, so points slightly right of \(s\) lie in \(S\) — contradicting the supremum. If \(f(s) > c\), continuity keeps \(f > c\) nearby, so \(s - \delta\) would already be an upper bound. Hence \(f(s) = c\). \(\blacksquare\)

  • Boundedness theorem: a continuous function on a closed bounded interval is bounded.

    No continuous temperature curve blows up over a finite closed day.

    If \(f\) were unbounded, pick \(x_n \in [a,b]\) with \(|f(x_n)| > n\). Bolzano–Weierstrass gives \(x_{n_k}\to x^{*} \in [a,b]\) (closedness keeps the limit inside), and continuity gives \(f(x_{n_k})\to f(x^{*})\) — contradicting \(|f(x_{n_k})| \to \infty\). \(\blacksquare\)

  • Extreme value theorem: such a function attains a maximum and a minimum.

    The hottest moment of the day really occurs; it isn't just approached.

    By boundedness, \(M = \sup_{[a,b]}f\) exists. Choose \(x_n\) with \(f(x_n) > M - 1/n\). Bolzano–Weierstrass gives \(x_{n_k}\to x^{*}\in[a,b]\), and continuity gives \(f(x^{*}) = \lim f(x_{n_k}) = M\). The minimum follows by applying this to \(-f\). \(\blacksquare\)

  • Heine–Cantor: continuity on a closed bounded interval is automatically uniform.

    Compactness upgrades a local promise to a global one. The template for Chapter 9.

    If not, some \(\varepsilon_0\) has, for each \(n\), points \(x_n, y_n\) with \(|x_n-y_n| < 1/n\) but \(|f(x_n)-f(y_n)| \ge \varepsilon_0\). Bolzano–Weierstrass gives \(x_{n_k}\to x^{*}\), and then \(y_{n_k}\to x^{*}\) too. Continuity at \(x^{*}\) forces \(|f(x_{n_k}) - f(y_{n_k})| \to 0\), a contradiction. \(\blacksquare\)

  • Continuous image of an interval is an interval.

    Continuity cannot tear a connected piece into two.

    Let \(u < w\) lie in \(f[I]\), say \(u = f(p)\), \(w = f(q)\), and let \(u < c < w\). The intermediate value theorem applied to \(f\) on the interval between \(p\) and \(q\) produces \(x\) with \(f(x) = c\), so \(c \in f[I]\). A set containing every value between any two of its members is an interval. \(\blacksquare\)

  • Continuous inverse: a continuous strictly monotone function on an interval has a continuous, strictly monotone inverse.

    \(\sqrt{\ }\), \(\ln\), \(\arcsin\) — all continuous, and this is why.

    Strict monotonicity gives injectivity, and the image is an interval \(J\) by the previous result, so \(f^{-1}: J\to I\) exists and is strictly monotone. A monotone function whose image is an interval has no jumps: a jump would leave a gap in the image. Hence \(f^{-1}\) is continuous. \(\blacksquare\)

  • Uniform limit theorem: a uniform limit of continuous functions is continuous.

    Pointwise is not enough: \(x^{n}\) on \([0,1]\) has a discontinuous limit.

    The \(\varepsilon/3\) argument. Given \(\varepsilon\), pick \(n\) with \(\sup_x|f_n(x)-f(x)| < \varepsilon/3\), then \(\delta\) from continuity of \(f_n\) at \(a\). For \(|x-a| < \delta\), \(|f(x)-f(a)| \le |f(x)-f_n(x)| + |f_n(x)-f_n(a)| + |f_n(a)-f(a)| < \varepsilon\). \(\blacksquare\)

  • Monotone functions have at most countably many discontinuities.

    A staircase can have infinitely many steps, but never uncountably many.

    At each discontinuity of an increasing \(f\), the jump interval \((\lim_{x\to a^-}f, \lim_{x\to a^+}f)\) is non-empty, and for different discontinuities these intervals are disjoint by monotonicity. Each contains a rational, and distinct intervals give distinct rationals, so the set of discontinuities injects into \(\mathbb{Q}\) — hence is countable. \(\blacksquare\)

Methods

  • \(\varepsilon\)–\(\delta\) — given \(\varepsilon\), produce \(\delta\), usually by solving the target inequality.

    For \(f(x)=3x\): \(|3x-3a| < \varepsilon\) needs \(\delta = \varepsilon/3\). Write the discovery backwards.

  • Use sequences instead — prove or disprove continuity by choosing a clever sequence.

    To kill continuity of \(\sin(1/x)\) at 0, take \(x_n\) with \(\sin(1/x_n)\) alternating.

  • Compactness upgrade — on a closed bounded interval, continuous gives bounded, attained and uniform for free.

    Always check whether your domain is closed and bounded before working hard.

  • Bisection for roots — apply the IVT and halve.

    Sign change over an interval, halve, repeat: an algorithm and a proof at once.

Layer 6 · Rates

Differentiation

Best linear approximation — the idea Chapter 10 lifts into \(n\) dimensions.

Concepts & Definitions

  • Derivative \(f'(a) = \lim_{h\to0}\frac{f(a+h)-f(a)}{h}\).

    Speed at an instant: the average speed over ever-shorter intervals.

  • Differentiability as linear approximation — \(f(a+h) = f(a) + f'(a)h + o(h)\).

    Zoom in far enough and the graph looks straight. This — not the quotient — is the definition that survives into \(\mathbb{R}^n\).

  • Tangent line \(y = f(a) + f'(a)(x-a)\).

    The straight line that agrees with the curve to first order.

  • Higher derivatives \(f'', f''', f^{(n)}\).

    Position, speed, acceleration — each the rate of the one before.

  • Critical point — where \(f' = 0\) or \(f'\) fails to exist.

    The only places an interior maximum can hide.

  • Convexity — the chord lies above the graph; equivalently \(f'' \ge 0\) for smooth \(f\).

    A bowl, not a dome. Convexity is Chapter 19's whole subject.

  • Taylor polynomial \(T_n(x) = \sum_{k\le n}\frac{f^{(k)}(a)}{k!}(x-a)^{k}\).

    The best polynomial fit at a point: matches value, slope, curvature, and so on.

  • Analytic function — equal to its Taylor series near every point.

    Smooth is not enough: \(e^{-1/x^{2}}\) has every derivative zero at 0, yet isn't zero.

Theorems

  • Differentiable \(\Rightarrow\) continuous.

    A graph with a tangent line can't have a jump. The converse fails at \(|x|\).

    \(f(a+h)-f(a) = h\cdot\frac{f(a+h)-f(a)}{h} \to 0 \cdot f'(a) = 0\) as \(h \to 0\), by the algebra of limits. So \(f(a+h)\to f(a)\). \(\blacksquare\)

  • Rules: linearity, product rule, quotient rule, chain rule.

    \((fg)' = f'g + fg'\): two things changing at once, each contributing its share.

    Product: \(\frac{f(a+h)g(a+h)-f(a)g(a)}{h} = f(a+h)\frac{g(a+h)-g(a)}{h} + g(a)\frac{f(a+h)-f(a)}{h} \to f(a)g'(a)+g(a)f'(a)\), using continuity of \(f\) at \(a\). Chain rule: write \(f(y) - f(y_0) = (f'(y_0)+\eta(y))(y-y_0)\) with \(\eta \to 0\); substitute \(y = g(a+h)\), divide by \(h\) and let \(h\to0\). Quotient follows from product plus the derivative of \(1/x\). \(\blacksquare\)

  • Fermat's interior extremum theorem: at an interior extremum with \(f\) differentiable, \(f'=0\).

    At the top of the hill the ground is momentarily level.

    At an interior maximum \(a\), the difference quotient is \(\le 0\) for \(h > 0\) and \(\ge 0\) for \(h < 0\). Taking one-sided limits gives \(f'(a) \le 0\) and \(f'(a)\ge0\), so \(f'(a)=0\). \(\blacksquare\)

  • Rolle's theorem: if \(f\) is continuous on \([a,b]\), differentiable inside, and \(f(a)=f(b)\), then \(f'(c)=0\) somewhere.

    Leave and return to the same altitude: at some moment you were going neither up nor down.

    By the extreme value theorem \(f\) attains a maximum and minimum on \([a,b]\). If both occur at endpoints then \(f\) is constant and \(f' \equiv 0\). Otherwise an extremum is interior, and Fermat's theorem gives \(f'(c)=0\) there. \(\blacksquare\)

  • Mean value theorem: \(f(b)-f(a) = f'(c)(b-a)\) for some \(c \in (a,b)\).

    Average 90 km/h over a journey and at some instant your speedometer read exactly 90.

    Apply Rolle to \(g(x) = f(x) - f(a) - \frac{f(b)-f(a)}{b-a}(x-a)\), which is continuous on \([a,b]\), differentiable inside, and satisfies \(g(a)=g(b)=0\). Then \(g'(c)=0\) gives the claim. \(\blacksquare\)

  • Corollary: \(f' = 0\) on an interval \(\Rightarrow\) \(f\) is constant; \(f' > 0 \Rightarrow\) strictly increasing.

    Never moving means never having moved — the fact that makes antiderivatives unique up to a constant.

    For \(x < y\) in the interval, the MVT gives \(f(y)-f(x) = f'(c)(y-x)\). If \(f' \equiv 0\) this is 0, so \(f\) is constant; if \(f' > 0\) it is positive, so \(f(y) > f(x)\). \(\blacksquare\)

  • Cauchy mean value theorem and l'Hôpital's rule.

    \(0/0\) forms can be resolved by comparing the two rates of change instead of the two values.

    Cauchy MVT: apply Rolle to \(h(x) = (f(b)-f(a))g(x) - (g(b)-g(a))f(x)\), giving \((f(b)-f(a))g'(c) = (g(b)-g(a))f'(c)\). For l'Hôpital with \(f(a)=g(a)=0\): \(\frac{f(x)}{g(x)} = \frac{f(x)-f(a)}{g(x)-g(a)} = \frac{f'(c_x)}{g'(c_x)}\) with \(c_x\) between \(a\) and \(x\); as \(x\to a\), \(c_x \to a\) and the limit follows. \(\blacksquare\)

  • Darboux's theorem: a derivative has the intermediate value property, even when it isn't continuous.

    Derivatives can't jump, even though they can be wild.

    Let \(f'(a) < c < f'(b)\) and set \(g(x) = f(x)-cx\), so \(g'(a) < 0 < g'(b)\). By the extreme value theorem \(g\) attains a minimum on \([a,b]\); the sign of \(g'\) at each endpoint rules out both endpoints, so the minimum is interior, and Fermat gives \(g'(x_0)=0\), i.e. \(f'(x_0)=c\). \(\blacksquare\)

  • Taylor's theorem with Lagrange remainder: \(f(x) = T_n(x) + \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}\).

    The polynomial fit, plus an exact honest error term. Chapter 10's second-derivative test is its two-term version.

    Fix \(x\) and choose \(M\) so that \(F(t) = f(x) - T_n^{(t)}(x) - M(x-t)^{n+1}\) vanishes at \(t=a\), where \(T_n^{(t)}\) is the Taylor polynomial expanded at \(t\). Then \(F(x) = F(a) = 0\), so Rolle gives \(\xi\) with \(F'(\xi)=0\). Differentiating, the telescoping Taylor terms cancel and leave \(\frac{f^{(n+1)}(\xi)}{n!}(x-\xi)^n = M(n+1)(x-\xi)^{n}\), i.e. \(M = \frac{f^{(n+1)}(\xi)}{(n+1)!}\). \(\blacksquare\)

  • Second derivative test: \(f'(a) = 0\) and \(f''(a) > 0\) give a local minimum.

    Flat and curving upward: a valley floor.

    Taylor with \(n=1\) gives \(f(a+h) = f(a) + \tfrac12 f''(\xi)h^{2}\) for some \(\xi\) between \(a\) and \(a+h\). Continuity of \(f''\) keeps it positive near \(a\), so \(f(a+h) > f(a)\) for all small \(h \ne 0\). \(\blacksquare\)

  • Convexity criterion: \(f'' \ge 0\) on an interval iff \(f\) is convex there.

    Curving upward everywhere means every chord sits above the curve.

    If \(f''\ge0\) then \(f'\) is non-decreasing; for \(x < z < y\), the MVT on \([x,z]\) and \([z,y]\) gives slopes \(f'(c_1)\le f'(c_2)\), so the chord slope from \(x\) to \(z\) is at most that from \(z\) to \(y\) — which is exactly convexity. Conversely, convexity makes difference quotients monotone, so \(f'\) is non-decreasing and \(f'' \ge 0\) where it exists. \(\blacksquare\)

Methods

  • Differentiate by rules, not by limits — build from a handful of known derivatives.

    The limit definition is used to establish the rules once, then never again.

  • Mean value argument — to compare \(f\) at two points, write the difference as \(f'(c)\cdot\) gap.

    The single most useful one-line trick in analysis.

  • Optimisation — find critical points, check endpoints, compare values.

    Chapter 10 repeats this with gradients and Lagrange multipliers.

  • Taylor approximation with error control.

    Approximate, then bound the remainder — never approximate and hope.

Layer 7 · Area, first attempt

The Riemann Integral

Length and area by exhaustion — and where the method runs out.

Concepts & Definitions

  • Partition of \([a,b]\) — finitely many points \(a = x_0 < \cdots < x_n = b\).

    Chop the interval into strips. Everything follows from making them thin.

  • Upper & lower sums \(U(f,P) = \sum M_i \Delta x_i\), \(L(f,P) = \sum m_i \Delta x_i\).

    Boxes drawn to just cover the region, and boxes drawn to just fit inside it.

  • Riemann integrability — \(\inf_P U = \sup_P L\); that common value is \(\int_a^b f\).

    Squeeze the true area from above and below until the two estimates meet.

  • Riemann sum \(\sum f(t_i)\Delta x_i\) with sample points \(t_i\).

    The practical version: measure the height somewhere in each strip.

  • Antiderivative \(F\) with \(F' = f\).

    Running total of a rate. Distance is the antiderivative of speed.

  • Improper integral — a limit of integrals over growing or shrinking ranges.

    \(\int_1^{\infty}x^{-2}dx = 1\): an infinitely long region with finite area.

  • Content zero — coverable by finitely many intervals of arbitrarily small total length.

    The forerunner of "measure zero" (Chapter 11), where "finitely" becomes "countably" and everything gets better.

Theorems

  • Riemann criterion: \(f\) is integrable iff for every \(\varepsilon\) there is a partition with \(U - L < \varepsilon\).

    You never need the exact value — just that the gap between over- and under-estimate can be closed.

    Refining a partition raises \(L\) and lowers \(U\), so \(\sup_P L \le \inf_P U\) always. If some partition has \(U-L < \varepsilon\) for every \(\varepsilon\), the two must be equal. Conversely if they are equal, choose partitions with \(L > I - \varepsilon/2\) and \(U < I + \varepsilon/2\) and take their common refinement. \(\blacksquare\)

  • Continuous \(\Rightarrow\) integrable on \([a,b]\).

    Uniform continuity makes every strip's height nearly constant, so the two estimates converge.

    By Heine–Cantor, \(f\) is uniformly continuous: given \(\varepsilon\), take \(\delta\) with \(|f(x)-f(y)| < \frac{\varepsilon}{b-a}\) whenever \(|x-y| < \delta\). For any partition of mesh \(< \delta\), \(M_i - m_i \le \frac{\varepsilon}{b-a}\) on each strip, so \(U - L \le \frac{\varepsilon}{b-a}\sum\Delta x_i = \varepsilon\). \(\blacksquare\)

  • Monotone \(\Rightarrow\) integrable.

    Even with infinitely many jumps, a staircase has a well-defined area.

    For increasing \(f\) and the uniform partition of mesh \(h\), \(U - L = h\sum_i (f(x_i)-f(x_{i-1})) = h\,(f(b)-f(a))\) by telescoping, which is \(< \varepsilon\) once \(h\) is small. \(\blacksquare\)

  • Linearity, additivity and monotonicity of the integral.

    Split the region, scale it, compare it — all behave exactly as area should.

    Each follows by proving the corresponding statement for upper and lower sums on a common refinement and passing to the infimum/supremum. E.g. \(U(f+g,P)\le U(f,P)+U(g,P)\) and the reverse for \(L\), squeezing \(\int(f+g) = \int f + \int g\); additivity over \([a,c]\cup[c,b]\) comes from partitions containing \(c\); monotonicity from \(f \le g\) giving \(M_i(f)\le M_i(g)\). \(\blacksquare\)

  • Fundamental theorem of calculus, part I: if \(f\) is continuous, \(F(x) = \int_a^x f\) satisfies \(F' = f\).

    Accumulating a rate and then measuring the rate of accumulation gets you back where you started.

    \(\frac{F(x+h)-F(x)}{h} = \frac1h\int_x^{x+h}f\). Since \(f\) is continuous at \(x\), for small \(h\) the values of \(f\) on \([x,x+h]\) lie within \(\varepsilon\) of \(f(x)\), so the average lies within \(\varepsilon\) of \(f(x)\). Letting \(h \to 0\) gives \(F'(x) = f(x)\). \(\blacksquare\)

  • Fundamental theorem of calculus, part II: \(\int_a^b f = F(b)-F(a)\) for any antiderivative \(F\).

    The reason integration is ever computed rather than approximated.

    Take any partition and apply the mean value theorem on each strip: \(F(x_i)-F(x_{i-1}) = f(t_i)\Delta x_i\) for some \(t_i\). Summing telescopes to \(F(b)-F(a) = \sum f(t_i)\Delta x_i\), a Riemann sum lying between \(L(f,P)\) and \(U(f,P)\). As those squeeze to \(\int_a^b f\), the constant \(F(b)-F(a)\) must equal it. \(\blacksquare\)

  • Integration by parts and by substitution.

    The product rule and the chain rule, read backwards.

    Parts: integrate \((uv)' = u'v + uv'\) over \([a,b]\) and apply part II. Substitution: if \(g\) is \(C^{1}\) and \(F' = f\), then \((F\circ g)' = f(g(x))g'(x)\) by the chain rule; integrating and applying part II gives \(\int_a^b f(g(x))g'(x)dx = F(g(b))-F(g(a)) = \int_{g(a)}^{g(b)}f\). \(\blacksquare\)

  • Mean value theorem for integrals: \(\int_a^b f = f(c)(b-a)\) for some \(c\), when \(f\) is continuous.

    The average of a continuous quantity is actually achieved at some instant.

    Let \(m, M\) be the minimum and maximum of \(f\) on \([a,b]\) (extreme value theorem). Monotonicity gives \(m(b-a) \le \int_a^b f \le M(b-a)\), so the average \(\frac{1}{b-a}\int_a^b f\) lies in \([m,M]\); the intermediate value theorem supplies \(c\) attaining it. \(\blacksquare\)

  • Lebesgue's criterion: \(f\) is Riemann integrable iff it is bounded and its set of discontinuities has measure zero.

    Exactly how broken a function may be. Chapter 11 supplies the word "measure".

    Sketch: define the oscillation \(\omega(x)\) of \(f\) at \(x\); the discontinuity set is \(\bigcup_k\{\omega \ge 1/k\}\). If each such set has measure zero, cover it by small intervals and use uniform smallness of oscillation on the compact remainder to make \(U-L\) small. Conversely, if some \(\{\omega\ge1/k\}\) has positive measure, every partition keeps \(U - L \ge \frac{1}{k}\cdot(\text{that measure})\), so integrability fails. \(\blacksquare\)

  • Where Riemann fails: the indicator of \(\mathbb{Q}\cap[0,1]\) is not Riemann integrable, and Riemann integrals do not survive pointwise limits.

    Every upper sum is 1 and every lower sum is 0, forever. Chapter 12 replaces the whole machine to fix this.

    Every subinterval contains both a rational and an irrational (density, Layer 2), so \(M_i = 1\) and \(m_i = 0\) for every partition, giving \(U = 1\), \(L = 0\). Moreover this function is the pointwise limit of the integrable functions \(f_k\) = indicator of the first \(k\) rationals, each with integral 0 — so pointwise limits do not preserve Riemann integrability. \(\blacksquare\)

Methods

  • Upper/lower sum squeeze — prove integrability by making \(U - L\) small.

    Choose the partition after seeing \(\varepsilon\); mesh \(< \delta\) is the usual answer.

  • Antidifferentiate and evaluate — the fundamental theorem in action.

    Find \(F\), subtract the endpoints. Everything else is technique for finding \(F\).

  • Substitution and parts — the two workhorse transformations.

    Substitution becomes the change-of-variables formula with \(|\det J|\) in Chapter 12.

  • Estimate rather than evaluate — bound the integrand and integrate the bound.

    \(\bigl|\int f\bigr| \le \int |f| \le M(b-a)\) settles more questions than exact evaluation ever does.
