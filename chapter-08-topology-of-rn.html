Topology of \(\mathbb{R}^{n}\)

❮ Chapter 7 — Metric Spaces Start Learning ❯

Shape Without Distance

Chapter 7 kept the distance. This chapter keeps only which sets are open — and finds that almost every theorem survives.

Two properties do the heavy lifting: compactness (nothing escapes) and connectedness (nothing is torn). Between them they prove the extreme value theorem, the intermediate value theorem, and uniform continuity.

These are also the properties Chapters 11–18 need before they can talk about volume, surface and dimension.

Layer 1 · Inside and edge

Open & Closed Sets

The vocabulary of position, built from balls.

Concepts & Definitions

  • Open set — every point has a ball around it inside the set.

    A field with no fence: from anywhere inside, you can still step in any direction.

  • Closed set — the complement is open; equivalently, it contains all its limit points.

    \([0,1]\) is closed, \((0,1)\) is open, \([0,1)\) is neither. "Closed" is not "not open".

  • Clopen set — both open and closed.

    In \(\mathbb{R}^{n}\) only \(\varnothing\) and the whole space. That fact is connectedness.

  • Neighbourhood of \(x\) — any set containing an open set containing \(x\).

    "Somewhere around here", with the edges left vague on purpose.

  • Interior \(A^{\circ}\) — the largest open set inside \(A\).

    The field without its fence.

  • Closure \(\overline{A}\) — the smallest closed set containing \(A\).

    The field with its fence added back.

  • Boundary \(\partial A = \overline{A}\setminus A^{\circ}\).

    The fence itself. \(\partial\mathbb{Q} = \mathbb{R}\) — a warning that boundaries can be enormous.

  • Limit point & isolated point.

    Approached by the set from outside; or standing alone with elbow room.

  • Dense set — closure is everything.

    \(\mathbb{Q}^{n}\) in \(\mathbb{R}^{n}\): countably many points, yet nowhere to hide from them.

  • Nowhere dense set — closure has empty interior.

    A line in the plane, or the Cantor set on the line.

  • Box (rectangle) \([a_1,b_1]\times\cdots\times[a_n,b_n]\).

    The basic brick of \(\mathbb{R}^{n}\). Chapter 11 defines volume by chopping everything into these.

Theorems

  • Unions and finite intersections of open sets are open; intersections and finite unions of closed sets are closed.

    \(\bigcap_n(-1/n,1/n) = \{0\}\) — infinitely many open sets can intersect in a closed one, which is why "finite" is not decorative.

    If \(x \in \bigcup_iU_i\) it lies in some \(U_i\), which supplies a ball. If \(x\in\bigcap_{i=1}^{k}U_i\), take the smallest of the \(k\) radii; that ball works for all of them. The closed statements follow by De Morgan (Chapter 2, Layer 3). \(\blacksquare\)

  • Interior and closure characterised: \(A^{\circ}\) is the union of all open subsets of \(A\); \(\overline A\) is the intersection of all closed supersets.

    Squeeze from inside and from outside; both are well defined by the previous theorem.

    The union of open subsets of \(A\) is open and contained in \(A\), and it contains every such set — so it is the largest. Dually, the intersection of closed supersets is closed, contains \(A\), and is contained in every closed superset. \(\blacksquare\)

  • Duality: \(\overline{A^{c}} = (A^{\circ})^{c}\) and \((\overline A)^{c} = (A^{c})^{\circ}\).

    Inside and outside swap when you take complements. Every fact here comes in a pair.

    \(x \notin A^{\circ}\) means no ball around \(x\) fits inside \(A\), i.e. every ball meets \(A^{c}\), i.e. \(x \in \overline{A^{c}}\). The second identity is this one applied to \(A^{c}\). \(\blacksquare\)

  • \(A\) is closed iff \(A = \overline A\), and open iff \(A = A^{\circ}\).

    Closed means "already contains its fence"; open means "contains none of it".

    \(\overline A\) is closed and contains \(A\), so if \(A = \overline A\) then \(A\) is closed; conversely a closed \(A\) is one of the sets being intersected, so \(\overline A \subseteq A\). The open statement is dual. \(\blacksquare\)

  • Sequential closure: \(x \in \overline A\) iff some sequence in \(A\) tends to \(x\).

    Metric spaces let you replace every topological statement by a statement about sequences.

    Chapter 7, Layer 2 — the argument used only the metric, so it applies verbatim in \(\mathbb{R}^{n}\). \(\blacksquare\)

  • Open sets in \(\mathbb{R}^{n}\) are countable unions of boxes, and in \(\mathbb{R}\) countable disjoint unions of intervals.

    Any open region can be tiled by dyadic cubes — the fact Chapter 11 needs to define measure.

    For each \(x\) in the open set \(U\), choose a dyadic cube (side \(2^{-k}\), corners at multiples of \(2^{-k}\)) containing \(x\) and contained in \(U\); there are only countably many dyadic cubes, so the union of those selected is a countable union equal to \(U\). In \(\mathbb{R}\), take maximal intervals inside \(U\); these are disjoint, each contains a rational, so there are countably many. \(\blacksquare\)

  • \(\mathbb{R}^{n}\) is separable: \(\mathbb{Q}^{n}\) is a countable dense subset.

    Every point in space is approximable by points with fractional coordinates — the reason computers can do geometry.

    \(\mathbb{Q}^{n}\) is countable as a finite product of countable sets (Chapter 2, Layer 7). Given \(x\) and \(\varepsilon\), density of \(\mathbb{Q}\) in \(\mathbb{R}\) (Chapter 3, Layer 2) supplies rationals within \(\varepsilon/\sqrt n\) of each coordinate, giving a rational point within \(\varepsilon\). \(\blacksquare\)

Methods

  • Prove openness by producing a radius — given \(x\), exhibit \(r\).

    The radius almost always comes from the slack in a strict inequality.

  • Prove closedness via sequences or complements.

    "Take a convergent sequence in \(A\) and show the limit is in \(A\)" is usually the shortest route.

  • Use preimages — \(\{x : f(x) < c\}\) is open when \(f\) is continuous.

    A one-line proof that most sets you meet are open or closed.

Layer 2 · The abstraction

Topological Spaces

Forget the metric; keep the open sets.

Concepts & Definitions

  • Topology — a family of "open" subsets closed under arbitrary unions and finite intersections, containing \(\varnothing\) and \(X\).

    The two rules of Layer 1, promoted to the definition.

  • Metrisable space — one whose topology comes from a metric.

    Not all are. But everything in this book is.

  • Base — a family whose unions give all open sets.

    The balls form a base for \(\mathbb{R}^{n}\); so do the boxes with rational corners.

  • Subbase — a family whose finite intersections form a base.

    The half-lines \((a,\infty)\) and \((-\infty,b)\) generate the whole topology of \(\mathbb{R}\).

  • Subspace topology — open sets of \(A\) are \(A \cap U\) for \(U\) open in \(X\).

    \([0,1)\) is open in \([0,2]\), though not in \(\mathbb{R}\). Openness is always relative to a container.

  • Product topology — generated by the boxes \(U_1\times\cdots\times U_n\).

    Exactly the usual topology on \(\mathbb{R}^{n}\), assembled from \(n\) copies of \(\mathbb{R}\).

  • Quotient topology — the finest topology making the quotient map continuous.

    Glue the ends of an interval and get a circle; the topology comes along for free.

  • Hausdorff space — distinct points have disjoint neighbourhoods.

    Every metric space is Hausdorff (Chapter 7). Without it, limits need not be unique.

  • Second countable — has a countable base.

    \(\mathbb{R}^{n}\) does: boxes with rational corners. This is what makes Lindelöf's theorem work.

  • Homeomorphism — a bijection, continuous both ways.

    A coffee mug and a doughnut. Topological properties are exactly those preserved by these.

  • Topological property — one preserved by homeomorphism.

    Compactness and connectedness are; being bounded, or having a certain diameter, are not.

Theorems

  • Metric topologies satisfy the axioms, and equivalent metrics give the same topology.

    Everything Chapter 7 proved about open sets was really about topology.

    Layer 1's first theorem is exactly the closure under unions and finite intersections, and \(\varnothing, X\) are trivially open. Equivalent metrics have mutually nested balls (Chapter 7, Layer 2), so they generate the same unions. \(\blacksquare\)

  • Continuity = open preimages, and compositions of continuous maps are continuous.

    The definition that needs neither distance nor sequences.

    In a metric space this is equivalent to the \(\varepsilon\)–\(\delta\) definition (Chapter 7, Layer 2), so adopting it loses nothing. Composition: \((g\circ f)^{-1}(W) = f^{-1}(g^{-1}(W))\), open as a preimage of an open set. \(\blacksquare\)

  • A map into a product is continuous iff each coordinate is.

    Curves in space are continuous exactly when their \(x\), \(y\) and \(z\) components are.

    Projections are continuous, so continuity of \(f\) gives continuity of \(\pi_i\circ f\). Conversely, preimages of the generating boxes are \(\bigcap_i(\pi_i\circ f)^{-1}(U_i)\), a finite intersection of open sets — hence open; a base's preimages being open suffices. \(\blacksquare\)

  • Lindelöf's theorem: in a second countable space, every open cover has a countable subcover.

    You can always thin an unmanageable cover down to a list. Half of measure theory relies on it.

    Let \(\{B_k\}\) be a countable base and \(\mathcal{U}\) an open cover. For each \(k\) such that \(B_k \subseteq U\) for some \(U \in\mathcal U\), pick one such \(U_k\). Given \(x\), it lies in some \(U\in\mathcal U\), and the base supplies \(B_k\) with \(x\in B_k\subseteq U\); then \(x \in U_k\). So \(\{U_k\}\) is a countable subcover. \(\blacksquare\)

  • Homeomorphisms preserve openness, closure, compactness and connectedness.

    These are the properties that describe shape rather than measurement.

    If \(h\) is a homeomorphism, \(h(U) = (h^{-1})^{-1}(U)\) is open whenever \(U\) is, and likewise in reverse; so the open sets correspond exactly. Every property defined purely from the open sets — including those in Layers 3 and 4 — is therefore preserved. \(\blacksquare\)

  • Invariance of dimension (stated): \(\mathbb{R}^{m}\) and \(\mathbb{R}^{n}\) are homeomorphic only if \(m=n\).

    The plane really is different from the line — even though Chapter 2 showed they have equally many points, and there is even a continuous surjection from \([0,1]\) onto the square.

    Sketch: a homeomorphism would induce isomorphisms on the homology (or homotopy) groups of punctured spaces, but \(\mathbb{R}^{n}\setminus\{0\}\) has the homotopy type of \(S^{n-1}\), whose homology distinguishes the dimensions. No proof using only the tools of this book is known to be short; the result is due to Brouwer. \(\blacksquare\)

Methods

  • Work with a base — check statements on basic open sets only.

    Continuity, for instance, needs checking only on a base or subbase.

  • Relativise — remember that "open" always means "open in what".

    The single most common source of confusion in this subject.

  • Prove things are not homeomorphic by finding an invariant.

    Remove a point from a line and it falls apart; remove one from a circle and it doesn't.

Layer 3 · Nothing escapes

Compactness

The property that turns local promises into global ones.

Concepts & Definitions

  • Open cover — a family of open sets whose union contains the set.

    Beer mats scattered to hide the table: they may overlap, they just have to leave no wood showing.

  • Compact set — every open cover has a finite subcover.

    However you scatter the mats, finitely many of them already do the job.

  • Sequentially compact — every sequence has a convergent subsequence with limit in the set.

    Infinitely many points in a finite room must pile up. In metric spaces this is equivalent to compactness.

  • Totally bounded — finitely many \(\varepsilon\)-balls cover it, for every \(\varepsilon\).

    Stronger than bounded once you leave \(\mathbb{R}^{n}\); the unit ball of an infinite-dimensional space is bounded but not totally bounded.

  • Finite intersection property — every finite subfamily has non-empty intersection.

    The dual way of saying compactness, and the form Tychonoff's proof uses.

  • Locally compact — every point has a compact neighbourhood.

    \(\mathbb{R}^{n}\) is: a closed ball around each point. Infinite-dimensional spaces are not.

  • Lebesgue number — a \(\delta\) such that every \(\delta\)-ball lies inside some member of a given cover.

    A single scale at which the cover works everywhere. The engine behind uniform continuity.

  • Cantor set — remove middle thirds forever.

    Compact, uncountable, of length zero, and nowhere dense. Chapter 18 gives it dimension \(\log2/\log3\).

Theorems

  • Compact \(\Rightarrow\) closed and bounded (in any metric space).

    The easy half. The converse is what needs \(\mathbb{R}^{n}\).

    Boundedness: the cover by balls \(B(x_0,k)\), \(k\in\mathbb{N}\), has a finite subcover, so one ball suffices. Closedness: if \(y \notin K\), the sets \(\{z : d(z,y) > 1/k\}\) cover \(K\); a finite subcover leaves a ball around \(y\) disjoint from \(K\), so \(K^{c}\) is open. \(\blacksquare\)

  • Closed subsets of compact sets are compact.

    Compactness is inherited downward, provided you don't cut open edges.

    Let \(F \subseteq K\) be closed and \(\mathcal U\) an open cover of \(F\). Then \(\mathcal U \cup \{F^{c}\}\) covers \(K\); extract a finite subcover and discard \(F^{c}\). What remains is a finite subcover of \(F\). \(\blacksquare\)

  • Heine–Borel: in \(\mathbb{R}^{n}\), compact \(\iff\) closed and bounded.

    The theorem that makes compactness usable: you can recognise it at a glance.

    One direction is above. For the converse it suffices to prove a box \(Q\) is compact, since a closed bounded set is a closed subset of a box. Suppose an open cover of \(Q\) had no finite subcover. Bisect \(Q\) into \(2^{n}\) sub-boxes; at least one has no finite subcover. Repeat, producing nested boxes with diameters \(\to0\), whose common point \(x\) (Chapter 7, Layer 3) lies in some cover member \(U\). But then a small enough box of the sequence lies inside \(U\) — a finite subcover of one element. Contradiction. \(\blacksquare\)

  • Compact \(\iff\) sequentially compact \(\iff\) complete and totally bounded, in metric spaces.

    Three descriptions of the same idea. Use whichever is easiest to verify.

    Sketch. Compact \(\Rightarrow\) sequentially compact: a sequence with no cluster point would give each point a ball containing only finitely many terms; a finite subcover then contains only finitely many terms — absurd. Sequentially compact \(\Rightarrow\) complete and totally bounded: Cauchy sequences have convergent subsequences hence converge (Chapter 7), and failure of total boundedness produces an \(\varepsilon\)-separated sequence with no convergent subsequence. Complete + totally bounded \(\Rightarrow\) compact: given a cover with no finite subcover, bisect repeatedly using total boundedness to get nested sets of shrinking diameter, and complete the argument as in Heine–Borel. \(\blacksquare\)

  • Bolzano–Weierstrass in \(\mathbb{R}^{n}\): every bounded sequence has a convergent subsequence.

    The one-dimensional theorem, applied to each coordinate in turn.

    The sequence lies in a box, which is compact by Heine–Borel and hence sequentially compact. Directly: extract a subsequence convergent in the first coordinate, then a further subsequence convergent in the second, and so on — \(n\) extractions suffice. \(\blacksquare\)

  • Continuous images of compact sets are compact.

    Compactness survives every continuous map — the single most useful thing about it.

    Let \(\mathcal V\) cover \(f(K)\). The preimages \(f^{-1}(V)\) are open and cover \(K\); take a finite subcover \(f^{-1}(V_1),\dots,f^{-1}(V_k)\). Then \(V_1,\dots,V_k\) cover \(f(K)\). \(\blacksquare\)

  • Extreme value theorem: a continuous real function on a compact set attains its maximum and minimum.

    Chapter 3's theorem, now in any number of dimensions and on any compact shape.

    \(f(K)\) is compact in \(\mathbb{R}\), hence closed and bounded, so \(\sup f(K)\) is finite and belongs to \(f(K)\) (a closed set contains its supremum). Any preimage of it is a maximiser; apply the same to \(-f\) for the minimum. \(\blacksquare\)

  • Lebesgue number lemma, and Heine–Cantor: continuity on a compact set is uniform.

    Compactness converts a promise made point by point into one promise for the whole set.

    Lemma: for each \(x\) choose \(r_x\) with \(B(x,2r_x)\) inside a cover member; finitely many \(B(x_i,r_{x_i})\) cover \(K\), and \(\delta = \min_i r_{x_i}\) works. Heine–Cantor: given \(\varepsilon\), the sets \(f^{-1}(B(f(x),\varepsilon/2))\) form an open cover; a Lebesgue number \(\delta\) for it makes any two points within \(\delta\) land in a common such preimage, so their images are within \(\varepsilon\). \(\blacksquare\)

  • Finite intersection property: \(K\) is compact iff every family of closed subsets with the FIP has non-empty intersection.

    Compactness, said with complements. Nested non-empty compact sets always meet.

    Take complements: a family of closed sets with empty intersection corresponds to an open cover, and "some finite subfamily has empty intersection" corresponds to "some finite subcover exists". \(\blacksquare\)

  • Tychonoff's theorem (stated): an arbitrary product of compact spaces is compact — equivalent to the Axiom of Choice.

    Finite products are easy; infinite products need Choice, and in fact are Choice.

    Sketch: extend a family of closed sets with the finite intersection property to a maximal such family using Zorn's lemma (Chapter 2, Layer 9). Maximality forces the projections into each factor to have the FIP there, so compactness of the factors supplies a point in each coordinate; the resulting point lies in every member of the family. \(\blacksquare\)

  • The Cantor set is compact, uncountable, nowhere dense and of total length 0.

    Every intuition about "small" fails on it — which is exactly why Chapters 11 and 18 need it.

    It is an intersection of closed sets, hence closed, and bounded — so compact. Its points are exactly those with a base-3 expansion using only 0 and 2, giving a bijection with \(\{0,2\}^{\mathbb{N}}\) and hence cardinality \(\mathfrak c\). It contains no interval, since at stage \(k\) every remaining interval has length \(3^{-k}\), so it is nowhere dense; and the removed lengths sum to \(\sum_k \frac{2^{k-1}}{3^{k}} = 1\), leaving total length 0. \(\blacksquare\)

Methods

  • Check closed and bounded — in \(\mathbb{R}^{n}\), that is compactness.

    The single most-used test in analysis.

  • Extract a convergent subsequence — the standard opening move.

    "Let \(x_n\) be a sequence in \(K\); by compactness a subsequence converges to \(x\in K\)…"

  • Cover, then take a finite subcover — to make finitely many local choices at once.

    Then take a minimum or maximum over that finite list — the trick that produces uniformity.

  • Bisect — halve repeatedly and pass to the limit.

    Proves Heine–Borel and Bolzano–Weierstrass, and finds roots numerically.

Layer 4 · In one piece

Connectedness

Sets that cannot be split — and the theorems that follow.

Concepts & Definitions

  • Disconnection — a split into two non-empty disjoint relatively open pieces.

    Two islands with clear water between them, each open in the set.

  • Connected set — one admitting no disconnection.

    A single landmass. \([0,1]\cup[2,3]\) is not.

  • Path — a continuous \(\gamma : [0,1]\to X\).

    A walk from \(a\) to \(b\), never jumping.

  • Path-connected — any two points are joined by a path.

    Stronger than connected in general; equivalent for open subsets of \(\mathbb{R}^{n}\).

  • Connected component — a maximal connected subset.

    The separate islands of an archipelago. Components are always closed.

  • Convex set — contains the segment between any two of its points.

    A disc, a box, a half-space. Convex \(\Rightarrow\) path-connected \(\Rightarrow\) connected. Chapter 19 is devoted to these.

  • Domain (region) — an open connected set.

    The standard setting for Chapter 10's calculus: open so derivatives exist, connected so "constant" means something.

  • Totally disconnected — every component is a single point.

    \(\mathbb{Q}\), and the Cantor set. Connected and compact are quite independent.

Theorems

  • \(X\) is connected iff its only clopen subsets are \(\varnothing\) and \(X\).

    The working definition — and the one used in almost every proof.

    A clopen \(A\) with \(\varnothing \ne A \ne X\) gives the disconnection \(A, A^{c}\), both open and non-empty. Conversely a disconnection \(U,V\) makes each of them clopen, since each is the complement of the other. \(\blacksquare\)

  • Intervals are exactly the connected subsets of \(\mathbb{R}\).

    Being in one piece, on the line, means having no missing middle.

    If \(A\) is not an interval, there are \(a < c < b\) with \(a,b\in A\), \(c\notin A\); then \(A\cap(-\infty,c)\) and \(A\cap(c,\infty)\) disconnect it. If \(I\) is an interval and \(U,V\) disconnect it, pick \(u\in U, v\in V\) with \(u<v\) and let \(s = \sup(U\cap[u,v])\). Then \(s\) lies in \(I\) but can be in neither \(U\) nor \(V\) without contradicting openness or the definition of the supremum. \(\blacksquare\)

  • Continuous images of connected sets are connected.

    A continuous map cannot tear. This is the whole content of the intermediate value theorem.

    If \(U,V\) disconnected \(f(X)\), their preimages would be open, disjoint, non-empty and cover \(X\) — disconnecting \(X\). \(\blacksquare\)

  • Intermediate value theorem (general form): a continuous real function on a connected set attains every value between any two of its values.

    Walk across a connected country and you cross every altitude between start and finish.

    \(f(X)\) is a connected subset of \(\mathbb{R}\), hence an interval; an interval containing \(f(a)\) and \(f(b)\) contains everything between them. \(\blacksquare\)

  • Unions with a common point are connected, and closures of connected sets are connected.

    Islands joined by a shared bridgehead form one landmass.

    Let \(A_i\) be connected with \(p \in \bigcap_iA_i\), and let \(U,V\) disconnect the union. Say \(p \in U\); then each \(A_i\), being connected, lies wholly in \(U\), so \(V\) is empty. For closures: a disconnection of \(\overline A\) restricts to one of \(A\) unless \(A\) lies entirely in one piece — and then the other piece is disjoint from \(A\) yet open, so it misses \(\overline A\) too. \(\blacksquare\)

  • Components partition the space and are closed.

    Every point belongs to exactly one island.

    Define \(x\sim y\) iff some connected subset contains both. This is an equivalence relation — transitivity uses the union theorem with a common point — so its classes partition \(X\), and each class is connected (a union of connected sets sharing a point) and maximal. Closedness follows since the closure of a component is connected and contains it. \(\blacksquare\)

  • Path-connected \(\Rightarrow\) connected; the converse fails.

    The topologist's sine curve \(\{(x,\sin(1/x))\}\cup(\{0\}\times[-1,1])\) is connected, but no path reaches the segment.

    If \(U,V\) disconnected a path-connected \(X\), take \(u\in U\), \(v\in V\) and a path \(\gamma\) between them; then \(\gamma^{-1}(U), \gamma^{-1}(V)\) would disconnect \([0,1]\), which is connected. The counterexample's connectedness follows from the closure theorem, as the curve's closure adds the segment. \(\blacksquare\)

  • For open subsets of \(\mathbb{R}^{n}\), connected \(\iff\) path-connected — indeed polygonally connected.

    Inside an open region you can always get anywhere by a chain of straight segments.

    Fix \(x\) in an open connected \(U\) and let \(A\) be the set of points reachable from \(x\) by a polygonal path in \(U\). \(A\) is open (a ball around any reachable point is reachable) and so is \(U\setminus A\) (by the same argument). Since \(A \ne\varnothing\) and \(U\) is connected, \(A = U\). \(\blacksquare\)

  • Corollary: a differentiable function with zero derivative on a domain is constant.

    Chapter 3's corollary, promoted to \(n\) dimensions — and it genuinely needs connectedness, or each piece could take its own value.

    Join any two points by a polygonal path inside the domain. Along each segment, the one-variable mean value theorem applied to \(t \mapsto f(a + t(b-a))\) gives equal endpoint values, since the derivative vanishes. Chaining the segments equates the values at the two original points. \(\blacksquare\)

Methods

  • Find a clopen set — to prove connectedness, show the only ones are trivial.

    The "open and closed and non-empty, therefore everything" argument.

  • Build a path — usually straight segments will do.

    In an open set, polygonal paths are always enough.

  • Use a continuous invariant to disconnect.

    If a continuous function takes only two values on a set, the set is disconnected.

  • Compact + connected — the standard hypotheses for a "nice region".

    Everything in Chapters 14–17 assumes some version of this.
