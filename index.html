Mathematics, Bottom-Up

Every chapter is a topic broken into layers, ordered so that each layer uses only what came before it.

Nothing appears before the thing it depends on — the whole book is built from the empty set upward.

Definitions, axioms, theorems and methods, each in one plain line.

How to Use This Book

Inside a chapter, every list item hides a short, plain-language example.

Tap any item to slide its example open. Tap another item to switch. Tap anywhere else to close.

Math is rendered in proper book notation, e.g. \(\forall x\, \exists y\; (x \in y)\).
